# AI Personal Computer (V2)

คอมพิวเตอร์ผู้ช่วย AI บน Raspberry Pi 5 (RAM 8GB) ที่เปิดเครื่องแล้วเข้าหน้าจอของระบบทันที
ใช้ภาษาไทยเป็นหลัก รองรับหลายผู้ใช้ และทำงานแบบ local-first — ปริญญานิพนธ์ของ Pakon

> ไฟล์นี้ไม่บอกสถานะ · อะไรเสร็จแล้วแค่ไหนดูที่ [`docs/STATUS.md`](docs/STATUS.md) ที่เดียว

## เครื่องที่ใช้

| เครื่อง | บทบาท | ใช้เป็นหลักฐานระดับไหน |
|---|---|---|
| เครื่องวินโดวส์ | เขียนโค้ด + unit test | ระดับ 3 เท่านั้น |
| Raspberry Pi 4 4GB | เครื่องทดสอบ | ความถูกต้องบน Linux/ARM จริง — **ไม่ใช่** ระดับ 4 และตัวเลขความเร็ว/RAM ใช้ไม่ได้ |
| Raspberry Pi 5 8GB | เครื่องจริง | ระดับ 4 และตัวเลขประสิทธิภาพทุกตัว |

## เริ่มใช้ (เครื่องพัฒนา)

ต้องมี Python 3.11 ขึ้นไป

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m unittest discover -s tests -t . -v
```

บน Raspberry Pi ใช้ `./.venv/bin/python` แทน · รายละเอียดใน [`docs/TESTING.md`](docs/TESTING.md)

## กติกาที่ต้องจำ (เต็ม ๆ อยู่ใน BRIEF หัวข้อ 11)

1. ตรวจของจริงก่อนเสนอหรือแก้
2. ตัวเลขประสิทธิภาพต้องมาจาก Pi 5 หรือบอกชัดว่าเป็นค่าประมาณ/อ้างอิงภายนอก
3. เทสต์ผ่านไม่ได้แปลว่าพร้อม — สถานะขึ้นตามระดับหลักฐานใน BRIEF หัวข้อ 9
4. ไม่มีความลับในโค้ด เทสต์ หรือ log
5. **ไม่ทำขั้นตอนที่เสี่ยงทำ Pi หรือ microSD พัง** โดยไม่ถามก่อน — สคริปต์ที่แตะระบบต้องเริ่มในโหมดตรวจอย่างเดียว
