# การ์ดออกแบบ 0078: จัดการสกิลครบวงจร (เปลี่ยนชื่อ · แก้เอง · ส่ง Claude แก้ · ดูว่าใช้ได้จริง · สร้างอีกทาง)

- **สถานะ:** **อนุมัติแล้ว (2026-11-07, Pakon "อนุมัติ")** · ลำดับในแผน: ช่วง 3 ข้อแรก (พึ่งด่านของการ์ด 0074)
- **ข้อกำหนดที่อ้าง:** คำแนะนำอาจารย์และกรรมการข้อ 6 (Pakon ยืนยันความหมาย 2026-11-05: "ส่งให้ Claude แก้สกิลแล้วสร้างใหม่ และเราเข้าไปแก้สกิลเองได้ด้วย") และข้อ 3 · การ์ด 0017 0067 0074 · ADR-011

## 1. ปัญหาที่แก้

สกิลที่ Claude สร้างอาจไม่ตรงใจหรือแก้ปัญหาไม่ได้จริง · ตอนนี้ผู้ใช้ทำได้: ลบ · ปิด/เปิด · ย้อนรุ่น · ส่งออก/นำเข้า · ให้ Claude แก้ตามคำติ (`reviseSkill`) ·
**ยังทำไม่ได้:** เปลี่ยนชื่อ · แก้เนื้อหาเอง · จัดหมวดเอง · บอกว่า "ใช้ได้จริง/ไม่ได้" · สร้างใหม่ทั้งตัว (regenerate) · สร้างแบบกรอกฟอร์มโดยไม่ต้องพูด
