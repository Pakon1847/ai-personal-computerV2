## 1. ปัญหาที่แก้ และใครใช้

ถามเครื่องด้วยเสียง เช่น "ตอนนี้กี่โมง" · "พรุ่งนี้มีนัดอะไร" · "อีกกี่วันถึงปีใหม่" · "เครื่องร้อนไหม" · "หาไฟล์รายงาน" → ตอนนี้ได้ "ไม่รู้จักคำสั่ง" (0027) ·
ทั้งที่แอปมีคำตอบแบบโค้ดล้วนอยู่แล้วในแชท (นาฬิกาเครื่อง สมุดนัด ค้นไฟล์ สุขภาพเครื่อง) · ผู้ใช้: คนที่ใช้เสียงแทนคีย์บอร์ด · วันสอบ: ถามด้วยเสียงแล้วได้คำตอบที่ถูกแน่นอนทันที

## 5. รอยต่อ

- **ใหม่** `SkillsController.voiceAnswer(text) -> card | {}`: ลองตามลำดับเดียวกับแชท — ตารางนัด → นาฬิกา → นับวัน → ยกเลิกนัด (การ์ดยืนยัน) → นัดถัดไป → เลื่อนนัด (บอกว่าเลื่อนเองไม่ได้) →
  ไฟล์ตามช่วงเวลา/ค้นไฟล์ → สุขภาพเครื่อง (กฎเสียง: มีคำว่า "เครื่อง" + อาการ [ช้า อืด ค้าง ร้อน] หรือมีคำ [อุณหภูมิ แรม ram หน่วยความจำ พื้นที่เหลือ พัดลม]) · ไม่ตรงเลย = {}
- QML `voiceCommand`: ทาง `unknown` → `voiceAnswer` ก่อน `voiceConfirm` (0028) → ได้การ์ด = แสดง + อ่านออกเสียง (`speakLastCard`) · ไม่ได้ = ทางเดิม

## 6. กรณีที่ต้องคิดไว้ก่อน

- **ยกเลิกนัดด้วยเสียง:** การ์ดยืนยันแสดงนัดที่จะลบ · ไม่ลบจนตอบ "ใช่"
- **ค้นไฟล์จากเสียงที่ถอดเพี้ยน:** ผลอาจไม่เจอ = บอกตามจริง (อ่านอย่างเดียว ไม่เสียหาย)
- **ประโยคที่เดิมเป็นทางอื่น:** ทางเว็บ/คำสั่งเครื่อง/สกิลมาก่อนเหมือนเดิม (0027–0028) · เปลี่ยนเฉพาะประโยคที่เดิมได้ "ไม่รู้จักคำสั่ง"
- **ตาราง 22 ข้อของ 0027:** ข้อ 16 "ตอนนี้กี่โมงแล้ว" จะได้เวลา (เดิมคาด "ไม่รู้จักคำสั่ง") · ข้อ 18 "หาแว่นไม่เจอ…" ต้องไม่กลายเป็นค้นไฟล์ (วัดในข้อ 8.2)
