## 1. ปัญหาที่แก้ และใครใช้

กดคีย์ลัดแล้วพูด ประโยคที่ไม่ใช่คำสั่งเว็บถูกส่งเข้าแชท (`WorkspacePage.qml` `voiceCommand` → `sendText`) → AI ในเครื่องตอบแทนการทำงาน ·
และ "เปิดเบราว์เซอร์" เปิด Chromium ธรรมดา (สกิลสั่งงานเครื่อง `open_app`) ที่เสียงคุมไม่ได้ → "เลื่อนลง" ต่อจากนั้นหลุดไปแชท (พบบน Pi 5 22:38) ·
ผู้ใช้: คนที่ใช้เสียงแทนเมาส์/คีย์บอร์ด

## 5. รอยต่อ

- **ใหม่** `aipc.ui.handsfree.route(text, browser_running) -> str` (Python ล้วน · เทสต์ได้โดยไม่ต้องมีจอ) คืนหนึ่งใน 5 ทาง ตามลำดับ:
  1. `browse.parse` ได้คำสั่ง และ (เบราว์เซอร์ของผู้ช่วยเปิดอยู่ หรือคำสั่งไม่ต้องมีหน้าเว็บ เช่น ค้นหา/เปิดเว็บ) → `"browser"`
  2. `command.parse` = เปิดเบราว์เซอร์ และมั่นใจ (ไม่ต้องยืนยัน) → `"open_browser"` (เปิดเบราว์เซอร์ของผู้ช่วยที่หน้า Google แทนตัวธรรมดา)
  3. `command.parse` ได้คำสั่งเครื่อง → `"command"` (ส่งทางเดิม `sendText` → `router.command_route` ทำทันที ไม่ผ่าน LLM · ยืนยันตามกติกาเดิม)
  4. `browse.parse` ได้ แต่ต้องมีหน้าเว็บ และยังไม่ได้เปิดเบราว์เซอร์ของผู้ช่วย → `"needs_browser"` (บอก "พูดว่า 'เปิดเบราว์เซอร์' ก่อน")
  5. อื่น ๆ → `"unknown"` (บอก "ไม่รู้จักคำสั่ง «คำที่ได้ยิน» · คุยกับผู้ช่วยให้พิมพ์หรือกดปุ่มไมค์ในแชท")
- `BrowserController.route(text)` (เรียกจาก QML) · `BrowserController.openHome()` (ใช้คำสั่งเปิดเว็บ Google ตัวเดิมของ 0024)
- QML `voiceCommand`: ตอบ "ใช่/ไม่" ของการ์ดที่รอ (เดิม) → เบราว์เซอร์ยังทำงานอยู่ = ให้รอ (เดิม) → ทำตาม `route` · **ไม่มีทางไหนส่งให้ AI ในเครื่องคุย**

## 6. กรณีที่ต้องคิดไว้ก่อน

- **ถอดเสียงได้ข้อความว่าง:** ทางเดิม (พูด "ไม่ได้ยินเสียงพูด")
- **เป็นทั้งคำสั่งเว็บและคำสั่งเครื่อง** ("เปิดยูทูบ"): เบราว์เซอร์ของผู้ช่วย (เหมือนเดิม)
- **ตั้งเตือน / ถามเวลา / คุยทั่วไปผ่านคีย์ลัด:** เปลี่ยนจากเดิม → "ไม่รู้จักคำสั่ง" · ทำได้ทางแชท (พิมพ์หรือปุ่มไมค์) · ตั้งใจเปลี่ยนตาม BRIEF 5.6 ข้อ 1
- **"เปิดเบราว์เซอร์" สะกด/ได้ยินใกล้เคียง** (ความมั่นใจ < 0.9): ทางที่ 3 = การ์ดยืนยันเดิม → กด/พูด "ใช่" แล้วเปิด**ตัวธรรมดา** · ข้อจำกัดที่ยอมรับ
- **Chromium ธรรมดาที่เปิดอยู่แล้ว:** เสียงยังคุมไม่ได้ (0026 ข้อ 11) · "เลื่อนลง" → ทางที่ 4 บอกให้เปิดเบราว์เซอร์ของผู้ช่วย
- **หลายผู้ใช้ / ออฟไลน์ / ออกจากระบบ:** ไม่ต่างจากเดิม (ไม่มีข้อมูลใหม่)
