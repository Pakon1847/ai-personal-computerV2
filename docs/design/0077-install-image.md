# การ์ดออกแบบ 0077: ให้คนอื่นติดตั้งใช้ได้ · image สำหรับแจก + ตัวติดตั้งคำสั่งเดียว

- **สถานะ:** **อนุมัติแล้ว (2026-11-07, Pakon "อนุมัติ")** · ยังไม่มีการ์ด microSD เปล่า → **ทำตัวติดตั้งก่อน** (เริ่มโหมดตรวจอย่างเดียว) · image รอมีการ์ด · โมเดลโหลดตอนติดตั้ง ไม่ใส่ใน image (Pakon เลือก) · รัน `--apply` บน Pi ยังต้องถามก่อนทุกครั้ง
- **ข้อกำหนดที่อ้าง:** คำแนะนำอาจารย์และกรรมการข้อ 9 และ 11 ([บันทึก](../reviews/2026-11-05-committee-advice.md)) · Pakon ตัดสิน 2026-11-05: แจกเป็น image ของ Pi + เขียนในเล่มว่าไม่รองรับ Windows/Mac
- **สาขา:** `feature/0077-install-image` (แตกจาก `feature/0072-gmail-api`)

## 1. ปัญหาที่แก้ และใครใช้

ตอนนี้ติดตั้งได้แค่คนที่รู้ขั้นตอน (สคริปต์ 10 ตัวใน `scripts/pi/install-*.sh` · runbook หลายไฟล์) · image ที่มี ([pi5-image-and-restore](../runbooks/pi5-image-and-restore.md)) เป็น**สำเนาสำรองที่มีข้อมูลส่วนตัวทุกบัญชี** แจกไม่ได้ ·
ผู้ใช้: คนที่มี Pi 5 8GB อยากลองระบบ · กรรมการถามว่า "ให้คนอื่นใช้ยังไง"

## 2. ทางเลือก (ผู้ช่วยฟันธงข้อ ก)

| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| **ก. image สะอาดที่สร้างจากสคริปต์** (Raspberry Pi OS Lite ใหม่ → ตัวติดตั้งรวม → ล้างข้อมูล → อ่านเป็น .img) | แฟลชแล้วใช้ได้ · ทำซ้ำได้จากสคริปต์ · ไม่มีข้อมูลใคร | ไฟล์ใหญ่ (โมเดล 3 GB) · ต้องมีการ์ดเปล่า + เวลา ~3 ชม. ต่อครั้ง |
| ข. ตัวติดตั้งคำสั่งเดียวบน Pi OS ที่ผู้ใช้ลงเอง | ไฟล์เล็ก · อัปเดตง่าย | ผู้ใช้ต้องใช้ SSH/เทอร์มินัล · พังกลางทาง = เครื่องครึ่ง ๆ กลาง ๆ |
| ค. pi-gen (เครื่องมือสร้าง image ทางการ) | สะอาดที่สุด | ต้องใช้ Linux/Docker · เรียนรู้นาน · อธิบายกรรมการยากกว่า |

**ข้อ ก ใช้ ข เป็นทางทำ:** เขียนตัวติดตั้งรวม `scripts/pi/install-all.sh` (เรียกสคริปต์เดิมตามลำดับ · dry-run ก่อนเสมอ) → ใช้ทำ image สะอาด → แจก image ·
คนที่อยากลงเองใช้ตัวติดตั้งรวมได้ (ข้อ ข) · ไม่รองรับ Windows/Mac (ระบบแทนหน้าเข้าสู่ระบบ + หน้าจอทั้งหมด ผูกกับ Linux · greetd · PAM · labwc)

## 3. ออกแบบ (ร่าง)

1. **`install-all.sh`** — ลำดับเดียวกับที่ติดตั้งจริงบน Pi 5 (อ่านจาก runbook `pi5-setup.md`) · แต่ละขั้นตรวจก่อน ทำ แล้วตรวจหลัง · หยุดทันทีที่ขั้นไหนไม่ผ่าน พร้อมบอกว่าทำถึงไหน · รันซ้ำได้ (ขั้นที่เสร็จแล้วข้าม)
2. **การเปิดเครื่องครั้งแรก (first boot):** ไม่มีบัญชีผู้ใช้ใน image → หน้า Login แสดง "สมัครบัญชีแรก" · ตั้ง Wi-Fi จากหน้าจอได้ (มีแล้ว: Wi-Fi popup) · ไม่มี SSH เปิดไว้ (ปลอดภัยกว่า · ผู้ดูแลเปิดเองได้)
3. **ล้างก่อนอ่าน image:** `prepare-image.sh` ลบ home ทุกบัญชีที่ไม่ใช่ระบบ · log · SSH host key (สร้างใหม่ตอนบูต) · ประวัติ shell · Wi-Fi ที่จำไว้ → ตรวจด้วยรายการไฟล์ที่ต้องไม่มี
4. **อัปเดต/ย้อนรุ่น:** ใช้ `update-app.sh` เดิม (มีย้อนรุ่นแล้ว) · เขียนวิธีในคู่มือผู้ใช้
5. **คู่มือ 1 หน้า** (ไทย/อังกฤษ): ต้องมีอะไร (Pi 5 8GB · การ์ด ≥ 64 GB · กล้อง/ไมค์) · แฟลชด้วย Raspberry Pi Imager · เปิดเครื่อง · สมัครบัญชี

## 4. ต้นทุน

ไม่มีต้นทุนตอนใช้งาน · image ~10–15 GB หลังบีบอัด (ประมาณจากที่ใช้จริง 32 GB ซึ่งมีโมเดลทดสอบหลายตัว · **ยังไม่ได้วัด**) · เวลาทำ ~3 ชม. ต่อรุ่น

## 5. เกณฑ์ผ่าน (ร่าง)

| # | เกณฑ์ |
|---|---|
| I1 | การ์ดเปล่า + image → เปิดเครื่องถึงหน้า Login ≤ 3 นาที · สมัครบัญชีแรก · ถามแชท 1 ข้อ · เปิดกล้องสมัครหน้าได้ (Pi 5) |
| I2 | image ไม่มีข้อมูลส่วนตัว: สคริปต์ตรวจ 0 ไฟล์จากรายการต้องห้าม (home ผู้ใช้ · แม่แบบหน้า · Claude login · Wi-Fi · SSH key) |
| I3 | `install-all.sh` บน Raspberry Pi OS ใหม่ (Pi 4 ได้ สำหรับความถูกต้อง) จบโดยไม่ต้องแก้มือ · รันซ้ำแล้วไม่พัง |
| I4 | คนที่ไม่เคยเห็นระบบ (เพื่อน 1 คน) ทำตามคู่มือจนใช้ได้ โดย Pakon ไม่ช่วย (Pakon จดเวลา + จุดที่ติด) |

## 6. ต้องถาม Pakon ก่อนเริ่ม

1. อนุมัติทาง ก + ข ไหม · 2. มีการ์ด microSD เปล่า ≥ 64 GB สำหรับทำ image ไหม · 3. ใส่โมเดลใน image เลย (ไฟล์ใหญ่ แต่ใช้ได้ทันทีแบบออฟไลน์) หรือให้โหลดตอนติดตั้ง

## 7. ไม่ทำในรอบนี้
