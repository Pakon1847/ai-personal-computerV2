- **สถานะ:** ร่าง 2026-10-28 (Pakon ~09:40: "เพิ่มปุ่มในหน้าตั้งค่าให้ออกจาก claude ได้ด้วย" · "ให้ logout claude ได้เลยในปุ่มนั้น") ·
  สาขา `feature/0070-claude-logout` (ต่อจาก 0069) · **อนุมัติ + ให้ติดตั้งเมื่อเสร็จ (Pakon ~09:50: "ทำเสร็จแล้วติดตั้งมาเลย")**
- **ข้อกำหนดที่อ้าง:** การ์ด 0021 (เชื่อมต่อ Claude ที่เครื่องนี้) · 0061 (การ์ด Claude ในหน้าตั้งค่า) · H2 H3 H5 H7

## 1. ปัญหาที่แก้ และใครใช้

ผู้ใช้เข้าสู่ระบบ Claude ไว้ในบัญชีของตัวเอง (การ์ด 0021) แต่ไม่มีทางออกจากหน้าจอ · ต้องใช้ SSH/เทอร์มินัล ·
อยากเปลี่ยนบัญชี Claude หรือเลิกใช้ = ทำเองไม่ได้

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไง |
|---|---|
| H7 | ปุ่มเรียก backend · backend รันคำสั่งตายตัว `claude auth logout` (ไม่ผ่าน shell · ไม่รับข้อความจากผู้ใช้) |
| H2 | กดสองครั้ง (ยืนยัน) · ออกแล้วบอกผลตามจริง · ปิด "ให้ถาม Claude" ให้เอง จะได้ไม่มีคำถามส่งไปแล้วล้ม |

## 3. ทำอะไร

1. การ์ด Claude ในหน้าตั้งค่า (มี Claude แล้วเท่านั้น): ปุ่ม **"ออกจาก Claude"** → กดครั้งแรกขึ้น "กดอีกครั้งเพื่อออก" →
   กดซ้ำ = `CloudUsage.logout()` รัน `claude auth logout` (หมดเวลา 20 วินาที)
2. สำเร็จ: ปิด "ให้ถาม Claude" · ขึ้น "ออกจาก Claude แล้ว · จะใช้อีกกด เชื่อมต่อ Claude" และแสดงปุ่มวิธีเชื่อมต่อเดิม (การ์ด 0021)
3. ไม่สำเร็จ: ขึ้น "ออกจาก Claude ไม่สำเร็จ" + ข้อความจากคำสั่ง (ตัดสั้น) · ไม่เปลี่ยนค่าอื่น

## 4–6. ข้อมูล · รอยต่อ · กรณีพิเศษ

ไม่เก็บข้อมูลใหม่ · ไม่ลบตัวโปรแกรม claude (เข้าใหม่ได้ด้วยปุ่มเชื่อมต่อเดิม) · สมุดบันทึกสิ่งที่ส่งออก (ความเป็นส่วนตัว) ไม่ลบ ·
ไม่มีโปรแกรม claude = ไม่แสดงปุ่ม · กดระหว่างกำลังถาม Claude = คำถามนั้นอาจล้ม (บอกตามผลเดิม)

## 7. ต้นทุนบน Pi 5

RAM/ดิสก์ไม่เพิ่ม · รันโปรเซส claude ครั้งเดียวตอนกด (ไม่กี่วินาที)

## 8. เกณฑ์ผ่าน (ประกาศก่อนสร้าง)

- **L1 (เทสต์ · วินโดวส์):** ตัวรันคำสั่งปลอม: argv = `[claude, "auth", "logout"]` · สำเร็จ = ข้อความออกแล้ว · ล้ม/หมดเวลา = ไม่สำเร็จ ·

- **L2:** เทสต์ทั้งชุดผ่าน วินโดวส์และ Pi 5
