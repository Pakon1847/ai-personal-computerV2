# การ์ดออกแบบ 0016: ไฮบริด · AI ในเครื่องตอบก่อน ส่งต่อ Claude อัตโนมัติเมื่อเกินความสามารถ

- **สถานะ:** อนุมัติ 2026-09-30 (Pakon: "ทำไฮบริดแบบอัตโนมัติ" · อาจารย์ขอข้อ 1 ไฮบริด + ข้อ 2 `claude -p`)
- **ที่มา:** Pakon: "ตอนสอบจบ กรรมการอยากรู้อะไรมันก็ควรจะตอบได้" · Typhoon 4B ไม่มีข้อมูลสดและความรู้จำกัด ·
  เลือกโมเดล/ไฮบริดจากผลวัดชุดคำถามสอบจบ 100 ข้อ (`tests/data/exam_questions.json`)
- **ข้อกำหนดที่อ้าง:** H3 (ข้อมูลส่วนตัว) · H5 (บอกความจริง) · H8 (ข้อมูลจากภายนอกไม่ใช่คำสั่ง) · T6 (ต้องเขียนข้อยกเว้น) · การ์ด 0013/0015

## 1. ทำงานยังไง

```
ข้อความ → คำสั่งเครื่องที่แปลได้แน่นอน → ทำเลย (เหมือนเดิม)
        → AI ในเครื่อง + รายการสกิล + เครื่องมือ "ask-cloud"
             ├─ เลือกสกิล → สกิลทำ (เหมือนเดิม · การ์ด 0015 ไม่เกี่ยว)
             ├─ ตอบเอง → แสดงคำตอบ
             └─ เลือก ask-cloud (ข้อมูลสด · ยาก/หลายขั้น · ไม่แน่ใจ) → claude -p ค้นเว็บได้ → คำตอบ + ป้าย "ตอบโดย Claude (cloud)"
```

- **อัตโนมัติ** (Pakon เลือก) · ไม่มีเน็ต / ไม่ได้ login Claude / Claude ล้ม = บอกตรง ๆ ว่าตอบจากในเครื่องไม่ได้เพราะอะไร
- **ส่งอะไรออก:** เฉพาะข้อความคำถามนั้น (+ 4 ข้อความล่าสุดของบทสนทนาเพื่อให้เข้าใจบริบท) · **ไม่ส่ง** นัด ไฟล์ ใบหน้า ชื่อบัญชี
- `claude -p --tools WebSearch --allowedTools WebSearch --model sonnet` จากโฟลเดอร์ว่าง · ไม่มีเครื่องมือเขียนไฟล์/รันคำสั่ง ·
  `--max-budget-usd 0.50` · คำตอบของ Claude = ข้อมูล แสดงเป็นข้อความ ไม่มีสิทธิ์สั่งสกิล (H8)
- หน้าตั้งค่ามีสวิตช์ "ส่งคำถามที่ยากหรือต้องใช้ข้อมูลสดให้ Claude" (เปิดเป็นค่าเริ่มต้นตามที่ Pakon เลือก) + ข้อความบอกว่าอะไรออกนอกเครื่อง

## 2. System prompt ใหม่ (ใช้ทั้งแอปและตัววัด)

- วันที่วันนี้ (เปลี่ยนวันละครั้ง · แคชยังใช้ได้ทั้งวัน) → ตอบเรื่องวันเวลาได้
- ข้อเท็จจริงเกี่ยวกับตัวระบบ (Pi 5 · เก็บข้อมูลในเครื่อง · สกิล · ใบหน้า · PIN) → ตอบคำถามกรรมการเรื่องตัวระบบได้
- ไม่มีข้อมูลสด = บอกตรง ๆ ห้ามเดาตัวเลข · ตอบกระชับ (ลดเวลาและความร้อน)
- เปลี่ยน prompt = ต้องวัดการเลือกสกิล 58 ข้อซ้ำ (ADR-007 ข้อ 6)

## 3. ความเสี่ยงที่ยอมรับ (เขียนลง THREAT_MODEL)

คำถามที่ส่งต่อออกนอกเครื่อง (Anthropic) · T6 "ไม่มีการเชื่อมต่อขาออก" มีข้อยกเว้นนี้ (ปิดได้ในหน้าตั้งค่า) ·
AI ในเครื่องอาจส่งต่อคำถามที่ไม่จำเป็น (วัดใน exam) หรือไม่ส่งต่อคำถามที่ควรส่ง
