## 4. ทำอะไร

1. หน้าตั้งค่า หมวด AI: การ์ด "Gmail" · ไม่มีไฟล์ client = บอกตรง ๆ · "เชื่อมต่อ Gmail" → หน้าขออนุญาตของ Google ในเบราว์เซอร์ → อนุญาต →
   เก็บโทเค็น · "เลิกเชื่อมต่อ Gmail" (กดสองครั้ง)
2. เสียง: "สรุปเมล" / "สรุปเมลใหม่" → ดึง 3 ฉบับ (เนื้อหาตัดเหลือ 1,500 ตัวอักษร/ฉบับ · ตัดแท็ก สคริปต์ ลิงก์) → AI ในเครื่องสรุป → อ่านออกเสียง
3. เชื่อมแล้ว "อ่านเมลล่าสุด" / "มีเมลใหม่ไหม" / "มีเมลจาก … ไหม" ใช้ API (ผู้ส่ง หัวเรื่อง เวลา · ไม่ดึงเนื้อหา) · ยังไม่เชื่อม = ทาง 0071 เดิม
4. AI ในเครื่องสรุปไม่ได้ = บอกตามจริง แล้วอ่านหัวเรื่องแทน · สิทธิ์หมด/ถูกยกเลิก = บอกให้เชื่อมต่อใหม่

## 6. ความเสี่ยงที่ต้องรู้ (ยังไม่ได้ยืนยัน)

- OAuth client ใน `google_credentials.json` เป็นของโปรเจกต์ Google Cloud ไหน (ยังไม่รู้) · ถ้าโปรเจกต์อยู่ในโหมดทดสอบ บัญชีที่ใช้ต้องเป็นผู้ทดสอบ ·
  Google แสดงหน้า "แอปยังไม่ได้รับการยืนยัน" · โทเค็นของโหมดทดสอบอาจหมดอายุใน 7 วัน (ต้องตรวจเอกสาร Google ก่อนเขียนเล่ม)
- `gmail.readonly` อ่านได้ทั้งกล่อง (ไม่ใช่แค่หัวเรื่อง) · คำขอสรุปจึงดึงเนื้อหาเฉพาะ 3 ฉบับที่ถาม
