# การ์ดออกแบบ 0053: แชท 2 แบบ — "ทั่วไป" (AI ในเครื่อง) และ "งาน" (Claude เลือกโมเดลได้)

- **สถานะ:** **อนุมัติแล้ว 2026-10-22 (Pakon "อนุมัติทั้ง4")**
- **ข้อกำหนดที่อ้าง:** การ์ด 0013 (แชทในเครื่อง) · 0016/0022 (ส่งให้ Claude อัตโนมัติ) · `cloud/ask.py` (`MODEL = "sonnet"` ตายตัว) · `cloud/budget.py` · H3 H4 H5
- **ที่มา:** รายการของ Pakon 2026-10-22 ข้อ 5 · โมเดลที่เลือกได้: Haiku / Sonnet / Opus

## 1. ปัญหาที่แก้ และใครใช้

ตอนนี้ผู้ใช้ไม่รู้ว่าคำตอบมาจาก AI ในเครื่องหรือ Claude และเลือกไม่ได้ · งานยาว/งานจริงจัง (เขียนรายงาน สรุปเอกสาร) อยากใช้ Claude ตั้งแต่แรกและเลือกความเก่ง/ราคาได้ ·
แชททั่วไปอยากให้อยู่ในเครื่องเท่านั้น (ส่วนตัว · ฟรี)

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไง |
|---|---|
| H3 ความเป็นส่วนตัวเป็นค่าเริ่มต้น | **แชททั่วไป = ในเครื่องล้วน ไม่ส่งออกเลย** (ต่างจากตอนนี้ที่ส่งให้ Claude อัตโนมัติ) · เปิดแอปมาเจอแชททั่วไปก่อน |
| H4 local-first | แชทงานต้องเลือกเอง · ปิด Claude ในตั้งค่า = แท็บงานกดไม่ได้ พร้อมบอกเหตุผล |
| H5 | แสดงชื่อโมเดลที่ตอบจริงทุกข้อความ (อ่านจากผลของ `claude -p` ไม่ใช่จากที่เลือก) |
| งบ (การ์ด 0016) | เพดานต่อครั้งและต่อวันเดิมยังคุม · แสดงราคาโดยประมาณต่อโมเดล (ตัวเลขจากผลจริงในสมุดบัญชี ไม่เดา) |

## 3. ออกแบบ

- หน้าแชทมีตัวสลับ 2 แท็บ: **ทั่วไป** · **งาน** · ประวัติแยกกัน (`chat/store.py` เพิ่มช่อง `mode`)
- **ทั่วไป:** llama-server เท่านั้น · สกิลในเครื่องยังใช้ได้ · ถามเรื่องที่ต้องใช้ข้อมูลสด → ตอบว่า "เรื่องนี้ต้องใช้อินเทอร์เน็ต ลองถามในแชทงาน" (ไม่ส่งเอง)
  - ⚠️ **เปลี่ยนพฤติกรรมเดิม** (การ์ด 0016/0022 ส่งให้ Claude อัตโนมัติ) → Pakon ต้องยืนยันว่าตั้งใจ
- **งาน:** ทุกข้อความไป `claude -p --model <haiku|sonnet|opus>` · ตัวเลือกโมเดลข้างช่องพิมพ์ จำค่าล่าสุดต่อผู้ใช้ (ค่าเริ่มต้น Sonnet) · ส่งประวัติแชทงานไปด้วย (ไม่ส่งของแชททั่วไป)
- `ask.py`: `MODEL` → พารามิเตอร์ ตรวจค่า ∈ {haiku, sonnet, opus} (ค่าอื่น = ปฏิเสธ · H7)
- **เสียง:** "สลับไปแชทงาน" / "ใช้โมเดล Opus" / "กลับแชททั่วไป" · คีย์ลัดยังเป็นคำสั่ง ไม่ใช่แชท (การ์ด 0027) — ส่งคำถามเข้าแชทงานด้วยเสียง = **ยังไม่รู้** ว่าควรทำรอบนี้ไหม (ข้อ 7)

## 4. กรณีที่ต้องคิดไว้ก่อน

ออฟไลน์ในแชทงาน → ข้อความค้าง "ส่งไม่ได้ ลองใหม่" ไม่หาย (H2) · งบวันนี้หมด → บอกยอดและเวลาที่งบรีเซ็ต · บัญชี Claude ไม่มีสิทธิ์ใช้ Opus → แสดงข้อความ error จริงจาก `claude` ·
ออกจากระบบ → ประวัติทั้งสองแท็บเก็บในบ้านของผู้ใช้เหมือนเดิม

## 5. ต้นทุน

RAM เท่าเดิม (ไม่มีโมเดลใหม่) · ค่าใช้ Claude ขึ้นกับโมเดล (Opus แพงสุด · คุมด้วยงบเดิม) · เวลาทำ ~2 วัน
