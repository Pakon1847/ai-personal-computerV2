## 1. ปัญหาที่แก้ และใครใช้

ตอนนี้ผู้ใช้ไม่รู้ว่าคำตอบมาจาก AI ในเครื่องหรือ Claude และเลือกไม่ได้ · งานยาว/งานจริงจัง (เขียนรายงาน สรุปเอกสาร) อยากใช้ Claude ตั้งแต่แรกและเลือกความเก่ง/ราคาได้ ·
แชททั่วไปอยากให้อยู่ในเครื่องเท่านั้น (ส่วนตัว · ฟรี)

## 3. ออกแบบ

- หน้าแชทมีตัวสลับ 2 แท็บ: **ทั่วไป** · **งาน** · ประวัติแยกกัน (`chat/store.py` เพิ่มช่อง `mode`)
- **ทั่วไป:** llama-server เท่านั้น · สกิลในเครื่องยังใช้ได้ · ถามเรื่องที่ต้องใช้ข้อมูลสด → ตอบว่า "เรื่องนี้ต้องใช้อินเทอร์เน็ต ลองถามในแชทงาน" (ไม่ส่งเอง)
  - ⚠️ **เปลี่ยนพฤติกรรมเดิม** (การ์ด 0016/0022 ส่งให้ Claude อัตโนมัติ) → Pakon ต้องยืนยันว่าตั้งใจ
- **งาน:** ทุกข้อความไป `claude -p --model <haiku|sonnet|opus>` · ตัวเลือกโมเดลข้างช่องพิมพ์ จำค่าล่าสุดต่อผู้ใช้ (ค่าเริ่มต้น Sonnet) · ส่งประวัติแชทงานไปด้วย (ไม่ส่งของแชททั่วไป)
- `ask.py`: `MODEL` → พารามิเตอร์ ตรวจค่า ∈ {haiku, sonnet, opus} (ค่าอื่น = ปฏิเสธ · H7)
- **เสียง:** "สลับไปแชทงาน" / "ใช้โมเดล Opus" / "กลับแชททั่วไป" · คีย์ลัดยังเป็นคำสั่ง ไม่ใช่แชท (การ์ด 0027) — ส่งคำถามเข้าแชทงานด้วยเสียง = **ยังไม่รู้** ว่าควรทำรอบนี้ไหม (ข้อ 7)

## 4. กรณีที่ต้องคิดไว้ก่อน

ออฟไลน์ในแชทงาน → ข้อความค้าง "ส่งไม่ได้ ลองใหม่" ไม่หาย (H2) · งบวันนี้หมด → บอกยอดและเวลาที่งบรีเซ็ต · บัญชี Claude ไม่มีสิทธิ์ใช้ Opus → แสดงข้อความ error จริงจาก `claude` ·
ออกจากระบบ → ประวัติทั้งสองแท็บเก็บในบ้านของผู้ใช้เหมือนเดิม

## 5. ต้นทุน

RAM เท่าเดิม (ไม่มีโมเดลใหม่) · ค่าใช้ Claude ขึ้นกับโมเดล (Opus แพงสุด · คุมด้วยงบเดิม) · เวลาทำ ~2 วัน

## 8. แก้หลังสร้าง (2026-10-22 · Pakon)

Pakon ดูผลแล้วสั่ง: **"ไฮบริดเอาไว้เหมือนเดิม เพราะบางครั้ง local AI ก็ไม่ฉลาด"** →

- **แชทงาน** ไม่เปลี่ยน: ทุกข้อความไป Claude ด้วยโมเดลที่เลือก
- หัวข้อ 2 แถว H3 และหัวข้อ 3 "ทั่วไป: llama-server เท่านั้น" **ยกเลิก** · เกณฑ์ **M1 เปลี่ยนเป็น**: แชททั่วไปทำงานเหมือนไฮบริดเดิมทุกข้อ (เทสต์ไฮบริดเดิมทั้งชุดผ่าน) ·
  ปิดสวิตช์ Claude = ส่งออก 0 ครั้ง (เกณฑ์เดิมของการ์ด 0016)
- ผลวัดไฮบริดเดิมในเล่มยังใช้ได้ (พฤติกรรมแชททั่วไปไม่เปลี่ยน)

## 9. เพิ่มหลังติดตั้ง (2026-10-22 ค่ำ · Pakon)

Pakon: "ทำให้เลือกได้ว่าจะเป็น low, medium, high, extra, max · ควรทำให้เห็นชัดกว่านี้ (ตอนนี้เหมือนปุ่มเปิด-ปิดเสียงอ่าน)" →
- **ระดับความคิด** ของแชทงาน: `claude -p --effort low|medium|high|xhigh|max` (ปุ่ม "Extra" = `xhigh`) · ค่าเริ่มต้น medium · จำต่อผู้ใช้ ·
  ค่าอื่น = ไม่ส่ง · แชททั่วไป (ไฮบริด) ไม่ส่ง effort (เหมือนเดิม) · ตรวจแล้ว: claude 2.1.294 บน Pi 5 มีตัวเลือกนี้ ·
  ลองจริงบนเครื่องพัฒนา haiku/sonnet + `--effort max` ตอบได้ไม่ error (ค่าใช้ ~0.009 USD)
- **หน้าตา:** แถวของตัวเองใต้ปุ่มด้านบน · แถบแบ่งช่อง (Segmented.qml) ราง 1 อัน ช่องที่เลือกพื้นสีเน้น + เครื่องหมายถูก + ป้ายกำกับ
  "โหมดแชท / โมเดล / ระดับความคิด" · โมเดลและระดับความคิดขึ้นเฉพาะแชทงาน · ใช้แนวทาง ui-ux-pro-max (สถานะที่เลือกไม่ใช้สีอย่างเดียว ·
  กดได้ ≥ 44 px · ใช้คีย์บอร์ดได้) · ดูภาพที่ตัวอักษร 100% / 200% แล้วไม่ล้นจอ
- คำโปรยแชททั่วไปเมื่อมี Claude: "AI ในเครื่องตอบก่อน ถ้าต้องใช้ข้อมูลสดจะถาม Claude" (เดิม "ทุกอย่างทำในเครื่องนี้" ไม่จริงเมื่อมีไฮบริด · H5)
