# การ์ดออกแบบ 0076: เลือก AI ในเครื่องได้ 3 ตัว พร้อมตารางเทียบ

- **สถานะ:** **อนุมัติแล้ว (2026-11-07, Pakon "อนุมัติ")** · ดาวน์โหลด 2 โมเดลลง `/opt/aipc-models`: Pakon "โหลดเลย" (ใช้ไฟล์เดียวกับที่วัดจาก `D:/bench-models` · ตรวจ sha256) · คำถาม 3 (ใครเลือกได้) ผู้ช่วยเลือกค่าเริ่ม = **ทุกบัญชีเลือกของตัวเอง** (ตรงกับคำกรรมการ · ไฟล์ต่อบัญชี) · แก้สคริปต์ติดตั้ง `--apply` ยังต้องถามก่อนรัน
- **ข้อกำหนดที่อ้าง:** คำแนะนำอาจารย์และกรรมการข้อ 1 และ 8 ([บันทึก](../reviews/2026-11-05-committee-advice.md)) · ADR-007 (เกณฑ์เลือกโมเดล) · ADR-014 (ไลเซนส์)
- **ผลวัดที่ใช้:** [เทียบ 17 โมเดล](../benchmarks/2026-10-29-llm-compare/README.md) (สาขา `bench/llm-compare` · ยังไม่รวม master)
- **สาขา:** `feature/0076-model-picker` (แตกจาก `feature/0072-gmail-api`)

## 1. ปัญหาที่แก้ และใครใช้

กรรมการอยากให้ผู้ใช้เลือกโมเดลเองได้ 3 ตัว พร้อมตารางเทียบว่าตัวไหนเหมาะกับอะไร · ตอนนี้โมเดลตั้งที่ `/etc/aipc/llm.conf` ตัวเดียวทั้งเครื่อง (ผู้ดูแลแก้)

## 2. ตัวเลือก 3 ตัว (จากผลวัดจริง · ไม่ใช่การเดา)

| | **Gemma 4 E2B** (ค่าเริ่ม) | **Qwen3.5 2B** (เร็ว · เบา) | **Qwen3.5 4B** (แม่นสุด · ช้า) |
|---|---|---|---|
| ความแม่น ชุดอิสระ 100 ข้อ (โน้ตบุ๊ก) | 83 | 77 | **88** |
| ชุดสอบเดิม 100 ข้อ (Pi 5) | 87 | 84 | **94** |
| แต่งข้อมูล | 0 | 0 | 1 (โน้ตบุ๊ก) / 0 (Pi) |
| ความเร็วสร้างข้อความ (Pi 5 · tok/s) | 6.82 | **7.38** | 3.33 ❌ (< 4) |
| เริ่มตอบ median (วิ) | 1.1 | **0.8** | 2.0 |
| RAM llama-server สูงสุด | 4.5 GB | **2.7 GB** | 5.6 GB |
| ไฟล์ | 3.11 GB (มีบน Pi แล้ว) | 1.28 GB (**ยังไม่มีบน Pi**) | 2.74 GB (**ยังไม่มีบน Pi**) |
| ไลเซนส์ | Apache-2.0 | Apache-2.0 | Apache-2.0 |

- ตัวเลขเวลา/RAM วัดตอน Pi ร้อน (throttle) → ใช้เทียบกันได้ ยังไม่ใช่ตัวเลขในเล่ม (รอพัดลม · ข้อ 2 ของกรรมการ)
- ผลชุดอื่นของระบบ (เลือกสกิลการ์ด 0074 · บังคับเลือก `tool_choice: required`) **วัดเฉพาะ Gemma** → ตัวเลือกอื่นต้องวัด S2a/S2b ใหม่ก่อนบอกผู้ใช้ว่าใช้ได้เท่ากัน

## 3. ออกแบบ (ร่าง)

1. **หน้าตั้งค่า → AI และอินเทอร์เน็ต:** การ์ด 3 ใบ (ชื่อ · จุดเด่น 1 บรรทัด · ตารางย่อจากหัวข้อ 2) · ตัวที่ยังไม่ได้ติดตั้งในเครื่อง = เลือกไม่ได้ + บอกว่าทำไม (H5)
2. **เก็บต่อบัญชี:** `~/.config/aipc/llm-model` (ชื่อจากรายการที่อนุญาตเท่านั้น · ไม่ใช่ path) · ไม่มีไฟล์ = ค่าของเครื่อง
3. **`aipc-llm-start`:** อ่านไฟล์ของผู้ใช้ → ถ้าเป็นชื่อในรายการ **และ** ไฟล์อยู่ใน `/opt/aipc-models` → ใช้ตัวนั้น (+ template ของมัน) · ไม่งั้นใช้ `/etc/aipc/llm.conf` (H7: backend ตัดสิน ไม่ใช่หน้าจอ · ผู้ใช้ชี้ไฟล์อื่นเองไม่ได้)
4. **สลับ:** กดเลือก → ถามยืนยัน ("AI จะเริ่มใหม่ ~1 นาที · แชทที่บันทึกแล้วไม่หาย") → restart `aipc-llm.service` ของผู้ใช้ · ระหว่างนั้นสถานะ "AI กำลังโหลด" แบบเดิม
5. **ติดตั้งโมเดลเพิ่ม (ผู้ดูแล):** `install-llm.sh --add-model <ไฟล์>` คัดลงที่ `/opt/aipc-models` อย่างเดียว (ไม่เปลี่ยนค่าของเครื่อง) · แสดง sha256

## 4. ต้นทุน

- ดิสก์ +4.0 GB (ว่าง 15 GB บน Pi ตอนนี้) · RAM: เปิดได้ทีละตัวต่อผู้ใช้ · Qwen3.5 4B 5.6 GB → **เสี่ยง OOM เมื่อเปิดเบราว์เซอร์พร้อมกัน** (ต้องวัดก่อนเปิดให้เลือก)
- ไม่เพิ่ม dependency ของ Python
