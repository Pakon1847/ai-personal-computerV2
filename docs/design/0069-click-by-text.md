# การ์ดออกแบบ 0069: กดปุ่มตามคำที่เห็นบนหน้าเว็บ (ทุกเว็บ · ไม่ต้องเดาตัวเลือก CSS)

- **สถานะ:** อนุมัติ 2026-10-28 (Pakon "ทำการ์ด0069") · สาขา `feature/0069-click-by-text` · **Pakon อนุมัติให้ติดตั้งบน Pi ก่อนผ่าน K3 (2026-10-28 ~04:00: "ติดตั้ง 0069 บน pi เลย")** · ยังไม่รวมเข้า master จนกว่าผ่าน K1–K3 · ที่มา (Pakon ~03:00: "ทำไมเราไม่เขียน python ให้จับหน้าจอแล้วกดตามคำที่เราพูด" ·
  "skill ที่ claude สร้าง … ไม่ใช่ใช้ได้บ้างไม่ได้บ้าง")
- **ข้อกำหนดที่อ้าง:** การ์ด 0046 (สกิลประจำเว็บ) · 0025 (OBSERVE_JS / CLICK_JS) · 0057 · 0066 · H3 H5 H6 H8

## 1. ปัญหาที่แก้ และใครใช้

Pakon ที่จอ: อยู่ใน Viu/Youku พูด "เข้าสู่ระบบ" → Claude สร้างสกิล → พูดซ้ำแล้วกดไม่ได้ ·
ต้นเหตุ (`backend._site_request`): Claude **ไม่เห็นหน้าเว็บ** ได้แค่ชื่อเว็บ + คำพูด → เดาตัวเลือก CSS
(Viu ได้ `a[href*="login"]`) · เดาถูก = ใช้ได้ · เดาผิด = "หน้านี้ไม่มีปุ่มนั้น" → ใช้ได้บ้างไม่ได้บ้างทุกเว็บ

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไง |
|---|---|
| H6 | หาปุ่มด้วยโค้ด: อ่านข้อความของปุ่มที่ **มองเห็นบนจอจริง** (DOM) แล้วเทียบคำ · ไม่ให้ AI เดา |
| H3 | ไม่ส่งหน้าเว็บให้ Claude · ทำในเครื่องทั้งหมด |
| H2/H5 | เจอ 1 ปุ่ม = กด · เจอหลายปุ่ม = ถามว่าอันไหน · ไม่เจอ = บอกตรง ๆ ไม่กดอย่างอื่นแทน |
| H8 | ข้อความบนหน้าเว็บเป็นข้อมูล ใช้เทียบคำเท่านั้น ไม่ใช่คำสั่ง |

**ทำไมไม่จับภาพหน้าจอแล้วอ่านตัวหนังสือ (OCR):** เบราว์เซอร์ของผู้ช่วยรู้อยู่แล้วว่าปุ่มไหนเขียนว่าอะไรและอยู่ตรงไหน (DOM)
→ แม่นกว่า เร็วกว่า ไม่ต้องลงโปรแกรมใหม่ · OCR ต้องเพิ่ม dependency และอ่านไทยผิดได้ (ยังไม่ได้วัดบน Pi)

## 3. ทำอะไร

1. **คำสั่งใหม่ "กด/คลิก/เลือก/เข้า <คำ>"** ในเว็บที่เปิดอยู่ (ทุกเว็บ) → ใช้ OBSERVE_JS เดิม (การ์ด 0025) หาปุ่ม/ลิงก์ที่มองเห็น
   ที่ข้อความ / aria-label / title ตรงกับคำ (ไทย-อังกฤษคู่ที่ใช้บ่อย เช่น เข้าสู่ระบบ ↔ Log in / Sign in) แล้วกดด้วย CLICK_JS เดิม
2. **สกิลที่ Claude สร้าง** เขียนเป้าหมายเป็นคำบนปุ่มได้: `→ กดปุ่มที่เขียนว่า เข้าสู่ระบบ|Log in|Sign in` (แทนการเดา CSS) ·
   สกิลเดิมที่ใช้ CSS: ถ้าหาไม่เจอ ลองหาด้วยคำของคำสั่งก่อนบอกว่าไม่มี
3. ปุ่มที่แตะบัญชี/เงิน (คำเสี่ยงชุดเดียวกับ `sitecmd.RISKY`: สมัคร ซื้อ จ่าย ลบ ออกจากระบบ …) = **ไม่กด** บอกให้กดเองที่จอ
   (ง่ายกว่าการ์ดยืนยัน และพลาดไม่ได้ · H1 H2)
4. ทางเสียง: มาหลังคำสั่งของระบบ สกิลประจำเว็บ และค้นในเว็บ · มาก่อนขอให้ Claude สร้างสกิล ·
   พูดว่า "กด…" แล้วไม่เจอ = บอกว่าไม่เห็นปุ่ม · พูดแค่ชื่อแล้วไม่เจอ = ให้ทางเดิมทำต่อ

## 4–6. ข้อมูล · รอยต่อ · กรณีพิเศษ

ไม่เก็บข้อมูลใหม่ · `BrowseCommand(kind="click_text", query=<คำ>)` · ปุ่มอยู่นอกจอ = ไม่นับ (พูด "เลื่อนลง" ก่อน) ·
ช่องรหัสผ่านไม่อ่าน (OBSERVE_JS ตัดอยู่แล้ว) · หน้าเว็บเปลี่ยนระหว่างหา = หาใหม่ 1 ครั้ง แล้วบอกตามจริง
