- **ข้อกำหนดที่อ้าง:** การ์ด 0005 (เครื่องมือกล้องใน terminal) · `aipc.doctor` ตัวตรวจกล้อง · DESIGN.md H3 H4 H5

## 1. ปัญหาที่แก้ และใครใช้

ยังไม่มีคำสั่งเดียวที่ตอบว่า "กล้องตัวนี้ใช้กับระบบได้ไหม" โดยไม่ต้องมีโมเดลใบหน้า (`camera check` ต้องโหลดโมเดลก่อน)
และคำแนะนำใน `aipc.doctor` ชี้ไป `rpicam-hello` ซึ่งหลอกว่ากล้อง USB เสีย
ผู้ใช้: Pakon/ผู้ติดตั้ง ตอนตั้งเครื่องใหม่ (Pi 5) หรือเปลี่ยนกล้อง · ใช้ก่อนทดสอบการ์ด 0010 กับคนจริง

## 3. ความสัมพันธ์กับชิ้นส่วนอื่น

- **พึ่ง:** `vision.camera.open_camera` / `find_camera` (มีแล้ว) · OpenCV (มีใน dependency แล้ว)
- **มีคนพึ่ง:** ขั้นตั้งเครื่อง Pi 5 · runbook ทดสอบการ์ด 0010 (ตรวจกล้องก่อนเริ่ม) · คำแนะนำของ `doctor` เมื่อไม่เจอกล้อง
- **ชั้น:** เครื่องมือ terminal ข้างแกนใบหน้า · ไม่แตะหน้าจอ QML ไม่แตะ greetd

## 4. ข้อมูล

ไม่มีข้อมูลใหม่ · ภาพจาก `--snap` เป็นไฟล์ที่ผู้สั่งเลือกที่เก็บเองและลบเอง

## 5. รอยต่อ (interface)

```
python -m aipc.vision.camera test [--camera N] [--seconds 3] [--snap ภาพ.jpg]
```
- `cmd_test(cap, seconds, snap=None, out=print, clock=time.monotonic) -> int`
- พิมพ์: ขนาดภาพจริง · FOURCC · เฟรมที่ทิ้ง · จำนวนเฟรม ÷ วิ · ความสว่างเฉลี่ย 0–255 + คำเตือน (มืด < 50 / สว่างเกิน > 205)
- exit 0 = อ่านเฟรมได้ · 1 = เปิดกล้องไม่ได้หรือไม่ได้เฟรมเลย

แก้ `doctor.check_camera` ข้อความแนะนำ: บอกว่า `rpicam-*` ใช้กับกล้อง CSI เท่านั้น · กล้อง USB ใช้ `v4l2-ctl --list-devices` หรือ `camera test`

## 6. กรณีที่ต้องคิดไว้ก่อน

- ไม่เจอกล้อง / เปิดไม่ได้ → ข้อความเดิมของ `open_camera` · exit 1
- กล้องหลุดกลางคัน → หยุดอ่าน รายงานเท่าที่ได้ · ได้ 0 เฟรม = exit 1
- กล้องไม่รองรับ MJPG/1280×720 → รายงานค่าที่ได้จริง (ไม่ถือว่าล้มเหลว)
- กล้องถูกโปรแกรมอื่นใช้อยู่ (เช่น หน้าจอ Login) → เปิดไม่ได้ → บอกให้ปิดโปรแกรมนั้นก่อน
- `--snap` เขียนไม่ได้ → บอกเหตุผล แต่ผลวัดยังพิมพ์ครบ

## 7. ต้นทุนบน Pi 5

RAM ≈ OpenCV + 1 เฟรม (ไม่โหลดโมเดล) · CPU เฉพาะถอด MJPG ระหว่างรัน 3 วิ · ดิสก์ 0 (ยกเว้น `--snap`) · LLM 0 ครั้ง

## 8. การทดสอบ และเกณฑ์ผ่าน

- **เทสต์อัตโนมัติ** (กล้องปลอม + นาฬิกาปลอม ใน `tests/test_vision_camera.py`):
  ทิ้งเฟรมอุ่นเครื่องแล้วนับภาพ/วิถูก · เตือนภาพมืด/สว่างเกิน · ไม่มี `--snap` = ไม่มีไฟล์ใหม่ · มี `--snap` = ได้ JPEG 1 ไฟล์ · ได้ 0 เฟรม = exit 1
- **เครื่องจริง:** Pi 5 8GB + Realtek 0bda:5855 → เปิดได้, ได้ 1280×720 MJPG, **≥ 15 ภาพ/วิ**, พิมพ์ความสว่าง

**ผลบนเครื่องจริง (2026-09-26):** Pi 5 8GB + Realtek 0bda:5855 · รันจาก `/tmp` ด้วย Python/OpenCV 4.10 ของ venv P3-1 (ยังไม่ติดตั้ง aipc)
→ `ภาพ 1280×720 · MJPG · ทิ้ง 23 เฟรมแรก` · `91 เฟรมใน 3.0 วิ = 30.1 ภาพ/วิ` · ความสว่าง 134/255 · exit 0 → **ผ่าน**
(เฟรมแรกก่อนปรับแสงที่ดึงด้วย ffmpeg มืดมาก — ยืนยันว่าต้องทิ้งช่วงอุ่นเครื่อง)
