# การ์ดออกแบบ 0044: คีย์ลัดเสียงเร็วขึ้นและแม่นขึ้น

- **สถานะ:** Pakon สั่งทำ 2026-10-20 ("ตอนนี้รู้สึกว่าการถอดเสียงช้ามาก อยากให้แม่นและเร็วขึ้น แก้เรื่องนี้มา") · เกณฑ์ประกาศก่อนแก้โค้ด
- **ข้อกำหนดที่อ้าง:** การ์ด 0019 (จุดจบเสียงพูด) · 0026 (Zipformer + hotwords) · 0040 (ฟังสองภาษา) · 0042 · H4 H5 H9

## 1. วัดก่อน: เวลาหมดไปไหน (Pi 5 · เสียงสังเคราะห์ · ทางเดียวกับแอป)

`aipc.spikes.voice_latency` (40 ประโยคชุด H · แค่วัดเวลา) + `aipc.spikes.voice_e2e_latency` (ชุดพัฒนา `tests/data/voice_latency_dev.json` ·
ส่งเสียงทีละ 0.1 วิตามเวลาจริงผ่าน Listener ตัวจริง · วัด "พูดจบ → ได้ข้อความ"):

| ขั้น | เวลา |
|---|---|
| Zipformer ถอด (โหลดไว้แล้ว) | ค่ากลาง 0.20 วิ |
| Zipformer โหลดใหม่ (ครั้งแรกหลังเข้าระบบ / ไม่ได้ใช้ 10 นาที) | **4.6 วิ** |
| รอเงียบหลังพูดจบ (Endpointer) | 1.0 วิ ทุกครั้ง |
| ลองถอดซ้ำเป็นอังกฤษ (whisper base.en · โปรเซสใหม่ทุกครั้ง) | **1.3–2.0 วิ** · เกิดกับทุกประโยคที่ทางเดิมไม่รู้จัก = คำถามทุกประโยค + ตั้งเตือน + สกิล + ค่าตั้ง (ตัวตัดสินดูแค่เส้นทางพื้นฐาน ไม่รู้จักทางใหม่ของ 0042) |

ความแม่นที่เห็นในชุดพัฒนา: ตัวเลขออกมาเป็นเลขไทย ("๒ทุ่ม" · ตัวแปลนัดไม่รู้จัก) · มีคำว่า "ก็" นำหน้าเกินมา

## 2. แก้

1. **โหลด Zipformer ไว้ตลอดเซสชัน:** เริ่มโหลดหลังเข้าระบบ (เบื้องหลัง) · ไม่ปิดเมื่อไม่ได้ใช้ (เดิมปิดหลัง 10 นาทีเพื่อคืน RAM ~329 MB · Pi 5 8 GB เหลือพอ)
2. **ลองอังกฤษเฉพาะที่น่าจะเป็นอังกฤษ:** ใช้เส้นทางเต็มของแอป (รวมตั้งเตือน สกิล ค่าตั้ง) · ไม่ใช่คำถามภาษาไทย (มีคำถาม เช่น ไหม อะไร กี่ ใคร) · สั้น (≤ 16 ตัวอักษร · คำสั่งอังกฤษที่ถอดเป็นไทยเพี้ยนจะสั้น)
3. **ถอดล่วงหน้าระหว่างรอเงียบ:** เงียบ 0.3 วิ = ถอดเสียงที่ได้ถึงตอนนั้นเลย (รวมลองอังกฤษถ้าต้อง) · พูดต่อ = ทิ้งผลล่วงหน้า · จบจริง = ใช้ผลที่ถอดไว้แล้ว
4. **จบเร็วเมื่อเป็นคำสั่งครบแล้ว:** ผลล่วงหน้าเป็นคำสั่งเว็บ/เครื่อง/ค่าตั้งที่สมบูรณ์ + เงียบ 0.6 วิ = จบเลย (ไม่รอครบ 1.0 วิ) ·
   ตั้งเตือน คำถาม และงานอื่นยังรอ 1.0 วิเหมือนเดิม (อาจพูดต่อ เช่น "เตือนประชุม … พรุ่งนี้สิบโมง")
5. **แก้ข้อความ:** เลขไทยเป็นเลขอารบิก · ตัด "ก็" / "เอ่อ" ที่นำหน้าประโยค

ไม่ทำในรอบนี้: เปลี่ยนโมเดล · ลด 1.0 วิ สำหรับประโยคทั่วไป (เสี่ยงตัดกลางประโยค) · เพิ่ม hotwords (ต้องวัดชุด H ใหม่ทั้งชุด · แยกรอบ)
