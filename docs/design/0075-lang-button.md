# การ์ดออกแบบ 0075: ปุ่มเปลี่ยนภาษาที่หน้าแรก

- **สถานะ:** **สร้างแล้ว รอ Pakon ตรวจ** · Pakon สั่ง 2026-11-07 "ทำมาให้ดีที่สุดก่อน แล้วถ้ายังไม่ดีเดี๋ยวผมกลับมาแก้ทีละจุด" (ระหว่างไม่อยู่หน้าจอ) →
  ผู้ช่วยเขียนการ์ดและโค้ดก่อนอนุมัติ **บนสาขาของตัวเองเท่านั้น** · ไม่ติดตั้งบน Pi ไม่รวม master จนกว่า Pakon อนุมัติ (กฎเหล็กข้อ 2)
- **ข้อกำหนดที่อ้าง:** คำแนะนำอาจารย์และกรรมการข้อ 4 ([บันทึก](../reviews/2026-11-05-committee-advice.md)) · การ์ด 0039 (ภาษาอังกฤษ) · BRIEF 5.7
- **สาขา:** `feature/0075-lang-button` (แตกจาก `feature/0072-gmail-api` = รุ่นที่ติดตั้งบน Pi ล่าสุด)

## 1. ปัญหาที่แก้ และใครใช้

ผู้ใช้ที่อ่านไทยไม่ออก (หรือคนไทยที่อยากใช้อังกฤษ) ต้องหาปุ่มภาษาในหน้าตั้งค่า · หน้าเข้าสู่ระบบมีปุ่ม "ภาษา: ไทย" แต่กดไม่ได้ (`enabled: false`) →
กรรมการขอให้เปลี่ยนภาษาได้ตั้งแต่หน้าแรก

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไง |
|---|---|
| H3 ความเป็นส่วนตัว | ภาษาหลังเข้าระบบเก็บในค่าตั้งของบัญชีนั้น (ไฟล์เดิม `ui.json`) · หน้า Login ไม่มีเจ้าของบัญชี จึง**ไม่เขียนไฟล์** |
| H5 ความจริงก่อนความสวย | ปุ่มที่กดไม่ได้ถูกแทนด้วยปุ่มที่ทำงานจริง · ข้อความที่ยังไม่มีคำแปลแสดงไทยเดิม (ไม่ซ่อน) |
| เรียบง่าย | ใช้ตารางคำแปลเดิมของการ์ด 0039 · ไม่เพิ่มคำแปลใหม่ ไม่เพิ่ม dependency |

## 3. ออกแบบ

1. **แถบข้าง (ทุกหน้าหลังเข้าระบบ):** ปุ่มลูกโลก + ป้าย "EN" (ตอนเป็นไทย) / "ไทย" (ตอนเป็นอังกฤษ) · กดครั้งเดียวสลับ · ใช้ `uiSettings.setLanguage` ตัวเดียวกับหน้าตั้งค่า (จำค่า)
2. **หน้าเข้าสู่ระบบ:** ปุ่มเดิมกดได้ · วน "สองภาษา (ค่าเริ่ม) → English → ไทย" · `Tr.both()` แสดงตามที่เลือก · วันที่เป็นอังกฤษเมื่อเลือก English ·
   ไม่จำข้ามการเปิดเครื่อง (ไม่มีเจ้าของ) · หน้าสมัครบัญชี/กู้รหัสที่ใช้ `Tr.both` ตามไปด้วย
3. ป้ายของปุ่มเขียนด้วย**ภาษาปลายทาง**เอง (คนที่อ่านภาษาปัจจุบันไม่ออกก็หาเจอ) · ชื่อสำหรับโปรแกรมอ่านหน้าจอ "ภาษา · Language"

## 4. ข้อมูล

ไม่มีข้อมูลใหม่ · ภาษาของบัญชี = `language` ใน `ui.json` เดิม · หน้า Login = ค่าในหน่วยความจำ (`Tr.loginLang`) หายเมื่อปิดโปรแกรม

## 5. รอยต่อ

`Tr.loginLang` (`both|th|en`) · `Tr.nextLoginLang()` · `SystemInfo.longDateEn` · `thaidate.long_date(dt, en=None)` · objectName `langToggle` `loginLang`

## 6. กรณีที่ต้องคิดไว้ก่อน

- ข้อความที่ไม่มีคำแปล → แสดงไทย (เทสต์ L2 ยืนยันว่าหน้า Login ตอนนี้ไม่มีไทยค้าง)
- เลือก English ที่หน้า Login แล้วเข้าบัญชีที่ตั้งไทย → หลังเข้าใช้ภาษาของบัญชี (ตั้งใจ: ภาษาเป็นของบัญชี) · **Pakon อาจอยากให้ติดไปด้วย → ถามตอนตรวจ**

## 7. ต้นทุนบน Pi 5

ปุ่ม 2 ปุ่ม · ไม่มี CPU/RAM/ดิสก์เพิ่มที่วัดได้ · ไม่เรียก LLM

## 8. การทดสอบ และเกณฑ์ผ่าน

| # | เกณฑ์ | สถานะ |
|---|---|---|
| L1 | เทสต์: กดปุ่มแถบข้าง 1 ครั้ง = ไม่มีข้อความไทยค้าง (ยกเว้นป้ายปุ่ม) + จำใน `ui.json` · กดอีกครั้ง = ข้อความเหมือนเดิมทุกตัว · ไม่มี warning ของ QML | ✅ วินโดวส์ |
| L2 | เทสต์: หน้า Login วน สองภาษา → English (ไม่มีไทยค้าง) → ไทย (ไม่มีอังกฤษปน) → สองภาษาเหมือนเดิม | ✅ วินโดวส์ |
| L3 | เทสต์ทั้งชุดผ่านบนวินโดวส์และ Pi 5 | วินโดวส์ ดูรายงาน · Pi ยังไม่ทำ |
| L4 | Pakon ที่จอ Pi: เห็นปุ่มทันทีบนหน้า Login และหน้าแรก กดแล้วเข้าใจ (Pakon ตัดสิน) | ยังไม่ทำ |

## 9. ไม่ทำในรอบนี้

- ภาษาอื่นนอกจากไทย/อังกฤษ · พูดสั่งเปลี่ยนภาษาที่หน้า Login · จำภาษาของหน้า Login ข้ามการเปิดเครื่อง (ต้องเขียนไฟล์ระบบ = ถามก่อน)
