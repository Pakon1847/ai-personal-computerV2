# การ์ดออกแบบ 0061: หน้าตั้งค่าแบ่งหมวด · ภาพเคลื่อนไหวเล็กน้อย

- **สถานะ:** อนุมัติแล้ว (2026-10-24, Pakon "อนุมัติ") · สาขา `feature/0061-settings-sections` (ต่อจาก `feature/0060-mouse-speed`)
- **ที่มา:** Pakon "หน้าตั้งค่าดูรกตามาก · ใช้ skill Ui Ux Pro Max · อยากมีอนิเมชันนิดหน่อยให้น่าใช้"

## 1. ปัญหา

การ์ด 12 ใบเรียงยาวหน้าเดียว ไม่มีหมวด ต้องเลื่อนหา · ตัวเลือกเรื่องเดียวกันอยู่ห่างกัน (ใบหน้า · ล็อก · ฟังเฉพาะหันหน้า)

## 2. หลักที่ใช้ (skill ui-ux-pro-max)

- จัดกลุ่ม + เมนูหมวดด้านซ้าย แสดงทีละหมวด · คงสี/ฟอนต์/ส่วนประกอบเดิมของระบบ (consistency · ไม่ใช้โทนสีที่เครื่องมือของ skill แนะนำสำหรับหน้าโฆษณาแอป)
- ภาพเคลื่อนไหว 2 จุดต่อหน้า (excessive-motion) · 200 ms ease-out · ใช้แค่ opacity/ตำแหน่ง (transform-performance) · **ปิดได้** (reduced-motion)
- ใช้คีย์บอร์ดได้ (Tab เข้าเมนู · ลูกศรขึ้น/ลง) · กรอบ focus เห็นชัด · ปุ่มสูง ≥ 44 · ตัวชี้เป็นรูปมือ

## 3. ออกแบบ

| หมวด | ของเดิมที่ย้ายมา |
|---|---|
| หน้าตาและการใช้ | ภาษา · ธีม · ขนาดตัวอักษร · ความเร็วเมาส์ · **ภาพเคลื่อนไหว (ใหม่)** |
| ใบหน้าและการล็อก | ใบหน้าของฉัน · เข้าเครื่องด้วยใบหน้า · ล็อกเมื่อไม่ได้ใช้เครื่อง (รวมปลดจอล็อกเอง) |
| เสียงและไมค์ | อ่านออกเสียง · ฟังคำสั่งเฉพาะตอนหันหน้าเข้าจอ (ย้ายจากการ์ดล็อก) |
| AI และอินเทอร์เน็ต | Claude/อากาศ · ปฏิทิน Google · บัญชีเว็บในเครื่อง |
| ความเป็นส่วนตัว | สิ่งที่ส่งออกนอกเครื่อง · ประวัติแชท |
| สำรองข้อมูล | ไดรฟ์ USB |

ภาพเคลื่อนไหว: เปลี่ยนหมวด = เนื้อหาจางเข้า + เลื่อนขึ้น 12 px · แถบเน้นในเมนูเลื่อนตามหมวด ·
ค่าตั้ง `animations` (ค่าเริ่มต้นเปิด) · ไม่เปลี่ยนการทำงานของตัวเลือกใด (ย้ายที่อย่างเดียว · objectName เดิม)

## 4–7. ข้อมูล · รอยต่อ · กรณีพิเศษ · ต้นทุน

`animations` ใน ui.json · `SettingsPage.section` (หมวดที่เปิด · ไม่จำข้ามการเข้าระบบ) · ตัวอักษร 200% = เมนูกว้างขึ้นตามตัวอักษร ·
CPU/RAM ~0 (ภาพเคลื่อนไหว 200 ms ตอนกดเท่านั้น)

## 10. รอบ 2 (Pakon 2026-10-24: "ตรง Claude ผู้ใช้จะงง ตรงที่บอกราคา · ทำให้เข้าใจง่าย · ติดตั้งเองเลย")

ชื่อ "Claude · AI ออนไลน์ที่เก่งกว่า" + บอกว่าใช้เมื่อไหร่ (AI ในเครื่องตอบไม่ได้) · ค่าใช้วันนี้เป็นประโยค "ถามไป N ครั้ง · ประมาณ $x จาก $y ที่ตั้งไว้" + แถบ ·
บอกว่าเงินเป็นดอลลาร์ตามที่ Claude แจ้ง และครบแล้วเครื่องจะหยุดถาม Claude จนพรุ่งนี้ · "เพดานต่อวัน" → "ใช้ได้ไม่เกินวันละ" ·
แยกพยากรณ์อากาศเป็นการ์ดของตัวเอง · แก้ข้อความ "ดูสิ่งที่ส่งได้ข้างล่าง" (ย้ายไปหมวดความเป็นส่วนตัวแล้ว) · ไม่มีคำเตือน QML
