# การ์ดออกแบบ 0060: ปรับความเร็วเมาส์เองในหน้าตั้งค่า (จำค่าไว้ ปิดเครื่องไม่หาย)

- **สถานะ:** อนุมัติแล้ว (2026-10-23, Pakon "ทำ ก. แล้วมาทำ ข.") · สาขา `feature/0060-mouse-speed`
- **ข้อกำหนดที่อ้าง:** หมายเหตุใน `scripts/pi/session/labwc/rc.xml` (2026-09-24: "ควรย้ายไปให้ผู้ใช้ปรับเองในหน้าตั้งค่า")

## 1. ปัญหาที่แก้ และใครใช้

Pakon: "เมาส์ช้า · ปิดเครื่องแล้วไม่ต้องรีเซ็ตค่าเมาส์" · ความเร็วเดิมเขียนตายตัว 0.6 ในค่าตั้ง labwc ของแอป (ทุกบัญชีเท่ากัน · ปรับเองไม่ได้) ·
เมาส์ตัวใหม่ (Compx Nearlink) ช้ากว่าตัวที่ใช้ตั้งค่าเดิม

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไง |
|---|---|
| H2 | ค่าเก็บใน ui.json ของผู้ใช้ (เขียนแบบปลอดภัย · ไฟดับไม่เสีย) · เข้าระบบครั้งหน้าใช้ค่าเดิม |
| H6 | เลือกจาก 4 ระดับที่กำหนดไว้ (โค้ดแปลงเป็นค่า libinput) · ไม่รับค่าอื่น |
| H5 | ใช้ไม่ได้ (ไม่ได้อยู่ในเซสชัน labwc ของเรา) = หน้าจอบอก ไม่ทำเป็นว่าเปลี่ยนแล้ว |

## 3. ออกแบบ

- **ก (ทำก่อน):** ค่าเริ่มต้น 0.6 → 0.9
- **ข:** หน้าตั้งค่า "ความเร็วเมาส์" 4 ระดับ: ช้า 0.3 · ปกติ 0.6 · เร็ว 0.9 (ค่าเริ่มต้น) · เร็วสุด 1.0 (libinput `pointerSpeed` · ช่วง -1 ถึง 1)
- aipc-session คัดค่าตั้ง labwc ไปไว้ใน `$XDG_RUNTIME_DIR/aipc-labwc` (ของผู้ใช้คนนั้น · หายเมื่อออกจากระบบ) แล้วเปิด labwc จากที่นั่น ·
  บอกแอปทาง `AIPC_LABWC_DIR`
- แอป (เปิดเสร็จ + ทุกครั้งที่เปลี่ยน): เขียนค่า `pointerSpeed` ลง rc.xml ในโฟลเดอร์นั้น → `labwc --reconfigure` = มีผลทันที ไม่ต้องออกจากระบบ

## 4. ข้อมูล

`mouse_speed` ใน `~/.config/aipc/ui.json` · ไฟล์ค่าตั้ง labwc ที่คัดไว้อยู่ใน runtime dir (RAM) · ลบ = ใช้ค่าเริ่มต้น

## 5. รอยต่อ

`UiSettings.mouseSpeed` / `setMouseSpeed(v)` · `aipc.ui.mouse.apply(speed)` → bool

## 6. กรณีที่ต้องคิดไว้ก่อน

ไม่มี `AIPC_LABWC_DIR` (วินโดวส์ / รุ่นเก่า) = บันทึกค่าได้ แต่บอกว่า "มีผลเมื่อเข้าระบบครั้งหน้า" · ค่าในไฟล์ผิดรูป = ใช้ค่าเริ่มต้น ·
คัดค่าตั้งไม่ได้ = เปิด labwc จากค่าตั้งเดิม (ความเร็วค่าเริ่มต้น)

## 7. ต้นทุนบน Pi 5

~0 (เขียนไฟล์เล็ก 1 ไฟล์ + สั่ง labwc โหลดค่าตั้งใหม่ ตอนเปลี่ยนเท่านั้น)
