# การ์ดออกแบบ 0052: ปุ่มปิดเครื่อง / รีสตาร์ต (หน้า Login + ในเซสชัน + เสียง)

- **สถานะ:** **อนุมัติแล้ว 2026-10-22 (Pakon "อนุมัติทั้ง4")** · **แตะ /etc (polkit) → ต้องอนุมัติ `--apply` แยกตามกฎเหล็กข้อ 1**
- **ข้อกำหนดที่อ้าง:** BRIEF "ควรมี" (BRIEF.md:368 หน้าปิดเครื่องอย่างปลอดภัย) · `LoginScreen.qml:280` (ปุ่มที่ยังกดไม่ได้) · H1 H2 H7
- **ที่มา:** รายการของ Pakon 2026-10-22 ข้อ 7

## 1. ปัญหาที่แก้ และใครใช้

ตอนนี้ปิด Pi ได้ทางเดียวคือดึงปลั๊ก (microSD เสียได้ · H1) · ผู้ใช้ทุกคนต้องปิด/รีสตาร์ตได้จากหน้าจอหรือด้วยเสียง

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไง |
|---|---|
| H1 | ปิดผ่าน `systemctl poweroff` (ระบบเขียนดิสก์ให้เสร็จก่อน) แทนการดึงปลั๊ก |
| H2 | ในเซสชัน: ถามยืนยัน + บันทึกแชท/ร่างก่อนปิด · มีผู้ใช้อื่นค้างอยู่ = บอกก่อน |
| H7 | สิทธิ์ตัดสินโดย **polkit** (ตัวตรวจสิทธิ์ของระบบ) ไม่ใช่หน้าจอ · ให้เฉพาะ poweroff/reboot ของคนที่นั่งหน้าเครื่อง (local active seat) ไม่ให้ทาง SSH |
| H6 | คำสั่งเสียง "ปิดเครื่อง" ผ่านตัวจับคำสั่งแบบกฎ **และถามยืนยันเสมอ** (สั่งผิดแล้วเครื่องดับ = เสียหายสูง) |

## 3. ออกแบบ

- **ทาง ก (เสนอ):** กฎ polkit ไฟล์เดียว `/etc/polkit-1/rules.d/50-aipc-power.rules` อนุญาต `org.freedesktop.login1.power-off` / `reboot` เมื่อ `subject.local && subject.active`
  (ทั้งผู้ใช้ปกติและบัญชี `_greetd` ของหน้า Login) · แอปเรียก `systemctl poweroff|reboot` ไม่ต้องใช้ sudo · ติดตั้งผ่าน `scripts/pi/install-power.sh` (เริ่มโหมดตรวจ · `--apply` ถามก่อน · ลบไฟล์ = ย้อนกลับ)
  - ยังไม่รู้: Raspberry Pi OS ตั้งค่าเริ่มต้นให้ผู้ใช้ที่นั่งหน้าเครื่องปิดได้อยู่แล้วหรือไม่ → **ขั้นแรก**ตรวจด้วย `pkcheck` บน Pi ก่อนเขียนกฎ (ถ้าได้อยู่แล้ว = ไม่ต้องแตะ /etc)
- ทาง ข: เพิ่มคำสั่งในตัวช่วยสิทธิ์ root เดิม → ขยายสิ่งที่ root ทำได้โดยไม่จำเป็น ✗
- **หน้า Login:** เปิดปุ่ม "ปิดเครื่อง" ที่มีอยู่ + เพิ่ม "รีสตาร์ต" · ถามยืนยัน 1 ครั้ง
- **ในเซสชัน:** เมนูข้างล่างของแถบซ้าย: ล็อก · ออกจากระบบ · รีสตาร์ต · ปิดเครื่อง · ยืนยัน → บันทึกงาน → สั่ง
- **เสียง:** "ปิดเครื่อง" / "รีสตาร์ตเครื่อง" → กล่องยืนยันบนจอ + ถามด้วยเสียง "ปิดเครื่องเลยไหม" → ต้องตอบ "ใช่" ภายใน 10 วิ ไม่งั้นยกเลิก

## 4. กรณีที่ต้องคิดไว้ก่อน

มีผู้ใช้อื่นยังเข้าระบบค้าง (หลายเซสชัน) → logind แจ้ง → ข้อความ "ยังมีผู้ใช้อื่นค้างอยู่ งานที่ยังไม่บันทึกอาจหาย" · กดปิดซ้ำระหว่างกำลังปิด → ไม่ทำซ้ำ ·
งานวัดผลที่รันด้วย systemd-run อยู่ → ถูกหยุด (ยอมรับ · แจ้งในกล่องยืนยันถ้าตรวจเจอ: ยังไม่รู้ว่าทำได้ง่ายไหม)

## 8. ผลตรวจบน Pi 5 ก่อนเขียนโค้ด (2026-10-22 · อ่านอย่างเดียว)

`implicit any/inactive: auth_admin_keep` → คนที่นั่งหน้าเครื่องปิด/รีสตาร์ตได้เลย · ทาง SSH ต้องรหัสผู้ดูแล (ตรงเกณฑ์ P3 โดยไม่ต้องแก้) →
