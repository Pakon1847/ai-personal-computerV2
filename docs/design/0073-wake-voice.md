## 4. ออกแบบ (ร่าง · รายละเอียดปรับตามผลขั้น 0)

```
สวิตช์เปิด + อยู่ในเซสชัน + จอไม่ล็อก + ไม่กำลังอ่านออกเสียง/ไม่มีเสียงจากลำโพง
 → ไมค์ฟังต่อเนื่อง · ตัวจับเสียงพูดแยกเป็นช่วง (เสียงอยู่ใน RAM)
 → แต่ละช่วงพูด → Zipformer ถอด (hotword = คำเรียก) → ขึ้นต้นด้วยคำเรียกไหม
      ไม่ใช่ → ทิ้งทันที (ไม่ส่งที่ไหน ไม่ถาม ไม่ตอบ)
      ใช่ → ขอ visiond `facing`: มีหน้าคนหันเข้าจอไหม (ภายใน ~1 วิ)
           ไม่เห็น → ไม่ทำ (ติ๊กเสียงต่ำ · บอกครั้งเดียวต่อรอบ "ไม่เห็นหน้า")
           เห็น → ติ๊ก + กล่องคำสั่งเสียง → ได้ข้อความคำสั่ง (ส่วนที่พูดต่อจากคำเรียก หรือฟังต่ออีกประโยค)
               สวิตช์ Claude เปิด + ออนไลน์ + งบเหลือ → Claude เลือกคำสั่งจากรายการ → JSON
                    → โค้ดตรวจ (อยู่ในรายการ · ค่าถูกรูปแบบ) → ทำ / ถามยืนยัน / "ไม่เข้าใจ ลองพูดใหม่"
               ไม่งั้น หรือ Claude ล้ม/ช้าเกิน → ตัวแปลแบบกฎเดิม (บอกผู้ใช้ว่าใช้แบบออฟไลน์)
```

- **คำเรียก:** Pakon เสนอ 2–3 คำ (ยาว 3–5 พยางค์ · ไม่ใช่คำที่พูดบ่อยในบทสนทนา) → ขั้น 0 วัดว่าคำไหนจับแม่นสุดและตื่นผิดน้อยสุด
- **รายการคำสั่งที่ส่งให้ Claude:** สร้างจากรายการคำสั่ง/สกิลที่โค้ดรู้จักอยู่แล้ว (แหล่งเดียวกับทางกฎ) ไม่เขียนรายการใหม่ซ้ำ
- **ประโยคที่ไม่ใช่คำสั่ง** (เรียกชื่อแล้วถามเรื่องทั่วไป) → ส่งเข้าแชทแบบเดิม (ไม่ใช่ Claude ทำคำสั่ง)

## 5. ข้อมูล

ค่าตั้ง `wake_voice` (bool · ค่าเริ่มต้นปิด) และ `wake_word` ใน ui.json ต่อบัญชี · สมุดบัญชีคลาวด์จดเหมือนการถาม Claude อื่น (ข้อความคำสั่ง · เวลา · ค่าใช้จ่าย) ·
ไม่เก็บเสียง ไม่เก็บภาพ ไม่เก็บประโยคที่ไม่ผ่านคำเรียก

## 6. รอยต่อ (ร่าง)

`WakeListener` (backend · ฟังต่อเนื่อง + ตัดสินคำเรียก) · `visiond facing` (0058 เดิม) · `interpret(text, commands) -> {"action", "args"} | None` (ถาม Claude) ·
ทางเดิม `handsfree.route(text, …)` เมื่อ `interpret` ได้ None · `UiSettings.wakeVoice`

## 7. กรณีที่ต้องคิดไว้ก่อน

- **ทีวี/คลิปพูดคำเรียก ขณะมีคนนั่งหน้าจอเงียบ ๆ** → กล้องเห็นหน้า = ผ่าน (**จุดอ่อนหลัก** · ตัวหาหน้า YuNet ให้แค่ 5 จุด ดูไม่ออกว่าปากขยับ) → วัดและรายงานตามจริง (K4) · ไม่แก้ในรอบนี้
- คนอื่นนั่งหน้าจอแล้วเรียก → ทำได้ในนามเจ้าของเซสชัน (เหมือนกด F9 วันนี้) · ไม่แยกว่าใครพูด
- เพลง/วิดีโอเปิดดัง → ช่วงพูดเกิดถี่ → CPU ขึ้น (วัดขั้น 0) · ลำโพงอ่านออกเสียงอยู่ = ไม่ฟัง (กันไมค์ได้ยินเสียงตัวเอง)
- ไม่มีเน็ต / Claude ช้า (> เกณฑ์เวลา) / JSON ผิด / งบหมด → ทางกฎเดิม + บอกผู้ใช้
- จอล็อก / ออกจากระบบ / ปิดสวิตช์ → ปิดไมค์และกล้อง ≤ 2 วิ · ไมค์หลุด → ปิดโหมด + บอกครั้งเดียว
- กล้องถูกใช้อยู่ (presence · จอล็อก) → ใช้คิวกล้องเดิมของ visiond · ไม่ได้ภายในเวลา = ไม่ทำ + บอก
