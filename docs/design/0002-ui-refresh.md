# การ์ดออกแบบ 0002: หน้าตาใหม่ของระบบ (UI รอบ 2)

- **สถานะ:** สร้างเสร็จ 2026-09-24 · ผู้ใช้อนุมัติ 2026-09-23 · เกณฑ์ข้อ 8 ผ่านครบ: เทสต์เดิม + ความต่างสี + การ์ดนัดถัดไป + ไฟกล้อง/ไมค์ทุกหน้า + ภาพตรวจ 2 ธีม × 100/200% + RAM บน Pi 4 +2.0% ([ผล](../benchmarks/2026-09-24-card0002/README.md)) · ภาพร่างอยู่บนบอร์ด หัวข้อ "UI รอบ 2 (รออนุมัติ)"
- **ข้อกำหนดที่อ้าง:** BRIEF 5.7 (ขนาดตัวอักษร 100–200%, ระยะบรรทัด) · DESIGN.md H3 H4 H5 · การ์ด 0001 (นัดหมาย)

## 1. ปัญหาที่แก้ และใครใช้

ผู้ใช้ (เจ้าของเครื่อง) บอกว่าหน้าจอ "ยังเห็นเป็นแบบเก่า" — หน้าตาปัจจุบันคือแบบร่างแรกแทบทุกจุด:
เมนูซ้ายกว้าง 232 px + รายการบทสนทนาอีก 264 px กินจอไป 39% ของ 1280 px ก่อนถึงแชท
และหน้าแรกเป็นแชทว่าง ไม่บอกว่าเครื่องทำอะไรได้บ้างหรือมีนัดอะไรวันนี้

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไงในงานนี้ |

## 3. ทางเลือก และที่เลือก

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| ก. ปรับแค่สี/มุมโค้ง คงโครงเดิม | งานน้อย ความเสี่ยงต่ำ | ผู้ใช้จะยังรู้สึกว่า "แบบเก่า" เพราะโครงเหมือนเดิม |
| **ข. เปลี่ยนโครง Shell + หน้าแรก + Login, ใช้ token ใหม่ทั้งระบบ (เลือก)** | เห็นความต่างชัด · แชทได้พื้นที่เพิ่ม · หน้าแรกบอกสิ่งที่ทำได้จริง | ต้องแก้ QML หลายไฟล์ · ต้องถ่ายภาพตรวจใหม่ทุกหน้า |
| ค. ทำใหม่ทั้งหมดรวมหน้าสมัคร/ตั้งค่า | สม่ำเสมอที่สุด | ช้า · หน้าสมัครกับตั้งค่าไม่มีปัญหาเรื่องพื้นที่ แค่เปลี่ยน token ก็พอ |

**สิ่งที่เปลี่ยนในทางเลือก ข.**

1. **แถบนำทางแบบราง (rail) กว้าง 76 px** — ไอคอน + ป้ายสั้นใต้ไอคอน · แต่ละช่องสูง ≥ 56 px (กดได้ ≥ 44) · ผู้ใช้ ปิดบัง ออก อยู่ล่างสุด
2. **รายการบทสนทนาเป็นแผงเปิด/ปิด** (ปุ่ม "ประวัติ") ไม่กินที่ตลอดเวลา — ตอนนี้ยังไม่มีการบันทึกประวัติอยู่แล้ว (เฟส 1)
3. **หน้าแรกของผู้ช่วย** เมื่อยังไม่มีข้อความ: คำทักตามเวลา + ช่องพิมพ์ใหญ่กลางจอ + ปุ่มลัดสกิลที่ใช้ได้จริง (สกิลที่ยังไม่พร้อมแสดงเป็นสีจางพร้อมคำว่า "ยังไม่พร้อม") + การ์ด "นัดถัดไป" (จาก `skills.upcoming`) + การ์ด "เครื่อง" (จาก `status`)
4. **แถบบนกระชับ** — ซ้าย: ชื่อหน้า · ขวา: ไฟกล้อง ไฟไมค์ (เห็นตลอด) · ป้ายโมเดล · พื้นที่ว่าง · เวลา
5. **Login แบบหน้าล็อก** — เวลาใหญ่กลางบน, วงกล้องกลม 200 px กลางจอ, ชื่อ + ช่องรหัสผ่านใต้วง, สมัครบัญชีอยู่แถบล่าง
6. **token ใหม่** (ชื่อเดิมทุกตัว เปลี่ยนแค่ค่า — หน้าจอที่ไม่ได้แก้โครงจะได้หน้าตาใหม่อัตโนมัติ): สีพื้นเทาเย็น, คราม `#4338CA` / `#A5B4FC`, มุมโค้งการ์ด 16 → ปุ่มและช่องพิมพ์ทรงแคปซูล, ตัดเส้นขอบการ์ดออกใช้สีพื้นต่างระดับแทน

## 4. ความสัมพันธ์กับชิ้นส่วนอื่น

- **พึ่ง:** `SkillsController.upcoming` (มีแล้ว, การ์ด 0001) · `SystemStatus` (มีแล้ว) · `SkillsController.skills[].ready` (มีแล้ว)
- **มีคนพึ่ง:** ทุกหน้าจอ · บอร์ด "หน้าจอจริง" ต้องถ่ายใหม่ทั้งหมดหลังสร้าง
- **ชั้น:** หน้าจอ (QML) อย่างเดียว · ไม่แตะ backend ยกเว้นเพิ่ม Property เล็ก ๆ ถ้าจำเป็น (เช่น คำทักตามเวลา — ทำใน Python เพื่อทดสอบได้)

## 5. ข้อมูล

ไม่มีข้อมูลใหม่ · ธีมและขนาดตัวอักษรยังบันทึกที่ `~/.config/aipc/ui.json` เหมือนเดิม

## 6. กรณีที่ต้องคิดไว้ก่อน

- **ขนาดตัวอักษร 200%** — rail 76 px ป้ายยาวจะล้น → ป้ายใต้ไอคอนตัดเป็นบรรทัดเดียว (`oneLine`) และมี tooltip · ต้องถ่ายภาพตรวจที่ 200%
- **ไม่มีนัด** — การ์ดนัดถัดไปเขียนว่า "ยังไม่มีนัด · ลองพิมพ์ “เตือน…”" ไม่ใช่ซ่อนการ์ด
- **ไฟล์นัดเสีย** — การ์ดนัดแสดง `skills.reminderWarning` แทนรายการ (H2)
- **อ่านค่าเครื่องไม่ได้** — การ์ดเครื่องเขียน "ไม่รู้" เหมือนหน้าสุขภาพเครื่อง
- **จอเล็กกว่า 1280×720** — ยังไม่รองรับ (เดิมก็ไม่รองรับ) · บันทึกไว้ในข้อ 9

## 7. ต้นทุนบน Pi 5

- ไม่มีเงา/เบลอ = ไม่มี offscreen pass เพิ่ม · จำนวนไอคอนบนจอลดลง (rail ไม่มีข้อความยาว + ไม่มีรายการบทสนทนาค้าง)
- RAM ของ QML: **ยังไม่รู้** — วัดด้วย `aipc.bench` เทียบก่อน/หลังบน Pi 4 (เกณฑ์ข้อ 8)
- ไม่เรียก LLM

## 8. การทดสอบ และเกณฑ์ผ่าน (ประกาศก่อนสร้าง)

- เทสต์เดิมทั้งหมดผ่าน (โหลดทุกหน้าจอแบบ offscreen ไม่มี QML warning, Enter/Shift+Enter)
- **เทสต์ใหม่: ความต่างสีของ token** — ทุกคู่ตัวอักษร/พื้นที่ใช้จริงต้อง ≥ 4.5:1 (WCAG AA) ทั้งสองธีม · ค่าที่คำนวณไว้ก่อนสร้าง: ต่ำสุด 5.13 (ธีมสว่าง `inkFaint` บน `bg`)
- เทสต์ใหม่: หน้าแรกแสดงนัดถัดไปจาก `upcoming` จริง และแสดงข้อความ "ยังไม่มีนัด" เมื่อว่าง
- ถ่ายภาพตรวจทุกหน้า × 2 ธีม × ขนาดตัวอักษร 100% และ 200% — ไม่มีข้อความล้นหรือถูกตัด
- ไฟกล้อง/ไมค์ปรากฏในทุกหน้าของ Shell (เทสต์หา objectName)
- RAM ของโปรเซส UI บน Pi 4 หลังเปลี่ยน ต้องไม่เกินของเดิม + 10% (วัดทั้งก่อนและหลัง ห้ามเดาค่าเดิม)

## 9. ไม่ทำในรอบนี้

- หน้าสมัคร ตั้งค่า สุขภาพเครื่อง ไฟล์ — เปลี่ยนเฉพาะ token ไม่เปลี่ยนโครง
- จอเล็กกว่า 1280×720 / จอแนวตั้ง
- ภาพเคลื่อนไหวตอนเปลี่ยนหน้า
- ประวัติบทสนทนา (ยังไม่มีที่เก็บ — ADR-004)
