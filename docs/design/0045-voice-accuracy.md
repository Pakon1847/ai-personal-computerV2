# การ์ดออกแบบ 0045: คีย์ลัดเสียงจับคำแม่นขึ้น

- **สถานะ:** Pakon สั่งทำ 2026-10-20 ("ยังจับคำที่พูดได้ไม่ดี ทำให้ดี ๆ หน่อย") · เกณฑ์และชุดทดสอบประกาศก่อนแก้
- **ข้อกำหนดที่อ้าง:** BRIEF 5.6 ข้อ 2 (fuzzy กับผลยืนยันเท่านั้น · ไม่มั่นใจ = ถาม "หมายถึง…ใช่ไหม" ไม่ทำเอง) · การ์ด 0026 (Zipformer + hotwords) · 0028 (ใกล้เคียงสกิล) · 0042 · 0044 · H5 H6 H9

## 1. ตรวจก่อน

- ไมค์ Leviosa ระดับ 100% · ไม่มี USB หลุดตั้งแต่บูต 20:54 → ไม่ใช่ปัญหาฮาร์ดแวร์ตอนนี้
- คำใบ้ (hotwords) ของ Zipformer มีแค่คำสั่งเว็บ/เพลงของการ์ด 0024–0036 · **ไม่มีคำสั่งที่เพิ่มหลังจากนั้น** (ตั้งเตือน ค่าตั้ง หน้าในระบบ เสียงเครื่อง เต็มจอ ข้ามโฆษณา Spotify ฯลฯ)
- ชุดพัฒนาของ 0044 เห็นถอดผิดแบบคำใกล้เสียง: "ปิดเสียง" → «ปีกเสียง» · "เปิดหน้าตั้งค่า" → «เปิดหน้าตังคา» · "เปิดโหมดมืด" → «เปิดหมดมืด» → ตอนนี้ได้แค่ "ไม่รู้จัก" หรือการ์ดถามส่งไปแชท

## 2. แก้

1. **คำใบ้ครบทุกคำสั่งที่มีตอนนี้** (ประโยคคำสั่งสั้นที่ใช้บ่อย · ไม่ได้มาจากชุดทดสอบ)
2. **ได้ยินใกล้เคียงคำสั่ง = ถามก่อน:** ข้อความที่ไม่ตรงอะไร แต่ใกล้กับประโยคคำสั่งในรายการ (เทียบตัวอักษรหลังตัดวรรณยุกต์และรวมสระสั้น-ยาว) →
   การ์ด "หมายถึง “ปิดเสียง” ใช่ไหม" · ตอบ "ใช่" = ทำคำสั่งนั้น · "ไม่" = ไม่ทำอะไร (BRIEF 5.6 ข้อ 2)

ไม่ทำในรอบนี้: เปลี่ยนโมเดล · เก็บเสียงผู้ใช้ไว้ปรับโมเดล (H3)
