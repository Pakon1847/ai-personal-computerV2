## 5. รอยต่อ

- **ใหม่** `SkillsController.voiceSkill(text) -> str`: id ของสกิลที่ประโยคตรงเป๊ะ และทำด้วยโค้ดทั้งหมด · "" = ไม่มี
- **ใหม่** `SkillsController.voiceHint(text) -> str`: ประโยคตัวอย่างที่ใกล้ที่สุดเมื่อใกล้เคียงแต่ไม่ตรง (เกณฑ์ใกล้เคียงเดียวกับตัวแปลคำสั่ง `FUZZY_CUTOFF` 0.72) · "" = ไม่ใกล้
- `handsfree.route(text, browser_running, skill=lambda t: "")`: สกิลตรงเป๊ะ → `"skill"` **หลังคำสั่งเว็บ/เปิดเบราว์เซอร์/คำสั่งเครื่อง และก่อน "ต้องเปิดเบราว์เซอร์ก่อน"**
  (แก้ 2026-10-15 จากผลข้อ 2 รอบ 1 · หัวข้อ 10) = ตรงกับตอนพิมพ์ (แชทตรวจคำสั่งเครื่องก่อน `repeat_of`) และสกิลเปลี่ยนคำสั่งเดิมไม่ได้
- **ใหม่** `SkillsController.voiceExample(id) -> str`: ประโยคตัวอย่างแรกที่ผ่าน `route` แล้วถึงสกิลนี้จริง (ใช้บนการ์ดสร้างสกิล)
- QML `voiceCommand`: `"skill"` → `dispatch(skills.handleAs(id, ข้อความ))` (ทางเดิมของการ์ดสกิล) · `"unknown"` + มีคำใบ้ → "ไม่รู้จักคำสั่ง «…» · ใกล้กับ «…» ลองพูดอีกครั้ง"
- การ์ด "สร้างสกิลแล้ว" (0017) เพิ่ม 1 บรรทัด: "กด Alt+Space แล้วพูดได้: «voiceExample»" (เฉพาะสกิลที่ทำด้วยโค้ด · ไม่มีประโยคที่ถึงสกิล = ไม่บอก)

## 6. กรณีที่ต้องคิดไว้ก่อน

- **ถอดเสียงเพี้ยนนิดเดียว** ("เปิดโหมดประชม"): ไม่ทำ · บอกคำใบ้ · ความแม่นของการถอดประโยคสกิลวัดในหัวข้อ 8 ข้อ 3 (รอบนี้ไม่เพิ่ม hotwords เพื่อไม่เปลี่ยนค่าที่ 0026 วัดไว้)
- **สกิลถูกปิด** (ผิด 2 ครั้ง · 0017 ชั้นที่ 3) หรือถูกลบ: ไม่อยู่ในรายการ = ไม่รู้จัก
- **สกิลที่มี "ถาม AI:"** (`code+llm`): ไม่เข้าทางเสียง · บอกไม่รู้จัก (พิมพ์ในแชทได้)
- **หลายผู้ใช้:** แต่ละบัญชีเห็นแต่สกิลของตัวเอง (โหลดจาก home ของคนนั้น) · คีย์ลัดเป็น FIFO ของผู้ใช้คนนั้น (0024)
- **ออฟไลน์:** สกิลที่เปิดเว็บจะเปิดเบราว์เซอร์แล้วโหลดไม่ขึ้น (เหมือนพิมพ์สั่ง) · สกิลปรับเสียงทำงานปกติ
- **ประโยคสกิลชนคำสั่งเดิม** (เช่น "เปิดแผนที่ให้หน่อย" · "อยากดูยูทูบ"): คำสั่งเดิมชนะ เหมือนตอนพิมพ์ · ประตูของ 0017 **ไม่ได้กัน**การชนนี้ (สกิลของ Claude 3 ใน 5 ตัวที่เป็นโค้ดล้วน มีตัวอย่างชนคำสั่งเดิม รวม 5 จาก 17 ประโยค · หัวข้อ 10) · การ์ดสร้างสกิลจึงบอกเฉพาะประโยคที่ถึงสกิลจริง

## 12. รอบ 2: ทาง ก + ข (Pakon อนุมัติ "ทำ ก., ข." 2026-10-15 ~01:40 · ประกาศก่อนสร้าง)

ที่มา: ข้อ 3 ตรงเป๊ะ 4/15 · พาไปสกิลผิด 0 · ใกล้พอให้คำใบ้ 10/11 · คำแรกหาย ("เข้า…") และ "ไฟล์" → «ไฟ» บ่อย

**ทาง ก · ใกล้เคียง = การ์ดยืนยันใบเดียว** (BRIEF 5.6 ข้อ 2 "หมายถึง…ใช่ไหม"): ได้ยินไม่ตรงเป๊ะแต่ใกล้ตัวอย่างของสกิลโค้ดล้วน
(`FUZZY_CUTOFF` 0.72 ตัวเดียวกับคำสั่งเครื่อง) → `SkillsController.voiceConfirm(text)` คืนการ์ด "หมายถึง “<ชื่อสกิล>” ใช่ไหม" พร้อมรายการขั้นตอน ·
**ไม่ทำอะไรจนกว่าตอบ "ใช่"** (พูดหรือกด) → ทำขั้นตอนทางเดียวกับการ์ดสกิลที่ยืนยันแล้ว (`_pending` แบบ `"steps"` · ยืนยันครั้งเดียวครอบทั้งการเลือกสกิลและการทำ) ·
"ไม่" = ไม่ทำ · ไม่ใกล้ = "ไม่รู้จักคำสั่ง" ตามเดิม · ใช้แทนข้อความคำใบ้ของรอบ 1

**ทาง ข · hotwords ของสกิล:** ตัวถอดของคีย์ลัดเพิ่มประโยคตัวอย่าง (เฉพาะที่มีตัวอักษรไทย) ของสกิลโค้ดล้วนของผู้ใช้คนนั้นเข้า hotwords
(น้ำหนัก ×5 เท่าเดิม · ไม่แก้รายการคำสั่งเว็บของ 0026) · สกิลเปลี่ยน (สร้าง/ลบ/ปิด) = ตัวถอดเริ่มใหม่พร้อมรายการใหม่ตอนกดครั้งถัดไป
