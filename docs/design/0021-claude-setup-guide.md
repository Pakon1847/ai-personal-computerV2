# การ์ดออกแบบ 0021: คู่มือเชื่อมต่อ Claude ในแอป

- **สถานะ:** อนุมัติแล้ว (2026-10-08, Pakon เลือก "คู่มือในแอป") · ทำก่อนหยุดเพิ่มฟีเจอร์ 9 ต.ค.
- **ข้อกำหนดที่อ้าง:** การ์ด 0016 (ไฮบริด) · การ์ด 0017 (Claude สร้างสกิล) · ข้ออ้างรอบ 4 ข้อ 2 ("การเข้าสู่ระบบ Claude แยกต่อบัญชี") · H5

## 1. ปัญหาที่แก้ และใครใช้

ผู้ใช้ที่ไม่เคยใช้ Claude Code เห็นแค่ข้อความ "บัญชีนี้ยังไม่ได้ติดตั้งหรือเข้าสู่ระบบ Claude Code" แต่ไม่รู้ว่าต้องทำอะไร และหน้าจอ V2 ไม่มีเทอร์มินัล ·
ผู้ใช้คือเจ้าของบัญชีทุกคนที่อยากใช้ Claude (ถามข้อมูลสดหรือสร้างสกิล) · Pakon ตัดสินแล้ว 2026-10-08 ว่าให้ติดตั้งและเข้าสู่ระบบแยกต่อบัญชีเหมือนเดิม

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไงในฟีเจอร์นี้ |
|---|---|
| H5 ของที่ไม่มีจริงไม่โชว์ | คู่มือขึ้นเฉพาะตอนที่บัญชียังไม่มีคำสั่ง `claude` · มีแล้ว = ซ่อน |
| ข้อมูลแยกต่อบัญชี | คำสั่งในคู่มือใช้ชื่อบัญชีที่กำลังใช้อยู่ · ไม่มีการติดตั้งหรือเข้าสู่ระบบส่วนกลาง |
| ไม่ส่งข้อมูลออกเอง | คู่มืออ่านแค่ชื่อบัญชีกับที่อยู่ IP ของเครื่องจากในเครื่อง · ไม่เรียกเน็ต · ไม่รันคำสั่งติดตั้งให้ |

## 3. ความสัมพันธ์กับชิ้นส่วนอื่น

- **พึ่ง:** `aipc.cloud.ask.find_claude` (หา `claude` ใน PATH หรือ `~/.local/bin/claude`) · `CloudUsage.available` ในหน้าตั้งค่า
- **มีคนพึ่ง:** หน้าตั้งค่า (การ์ดส่งข้อมูลออกนอกเครื่อง) · หน้าสกิล (ข้อความตอนยังไม่มีสกิลจะชี้มาที่คู่มือ)
- **ชั้น:** หน้าจอ (`aipc.ui`) + ฟังก์ชันล้วน `aipc.cloud.setup_guide`

## 4. ข้อมูล

ไม่เก็บอะไรเพิ่ม · ที่อยู่ IP อ่านจาก `hostname -I` ตอนเปิดคู่มือ

## 5. รอยต่อ

- `setup_guide.addresses(run=subprocess.run) -> list[str]` คืน IPv4 ที่ไม่ใช่ loopback · อ่านไม่ได้ = `[]`
- `setup_guide.steps(user, addrs) -> list[dict]` คืนรายการขั้น `{title, detail, command}` (`command` ว่างได้)
- `CloudUsage.guideSteps` (QVariantList) + `CloudUsage.refreshGuide()` (อ่าน IP ใหม่ตอนกดเปิดคู่มือ)

## 6. กรณีที่ต้องคิดไว้ก่อน

- ไม่มีเน็ตหรืออ่าน IP ไม่ได้ → ขั้น SSH บอกให้ต่อเน็ตก่อน แล้วกดเปิดคู่มือใหม่
- มีหลาย IP → แสดงทุกอัน
- ติดตั้งเสร็จระหว่างที่แอปเปิดอยู่ → แอปตรวจ `claude` ตอนเริ่มเซสชัน · ขั้นสุดท้ายบอกให้ออกจากระบบแล้วเข้าใหม่ (ไม่ทำตัวตรวจซ้ำในรอบนี้)
- ติดตั้งแล้วแต่ยังไม่ได้เข้าสู่ระบบ → แอปถือว่ามี Claude · ถาม Claude แล้วจะล้ม · คู่มือมีหมายเหตุให้ทำขั้นเข้าสู่ระบบซ้ำ
- หน้า Login ไม่มีเจ้าของบัญชี → ไม่มีคู่มือ (หน้าตั้งค่าไม่อยู่ในหน้า Login)

## 7. ต้นทุนบน Pi 5

รัน `hostname -I` หนึ่งครั้งต่อการกดเปิดคู่มือ · ไม่มีเธรดหรือตัวจับเวลาเพิ่ม · ไม่เรียก LLM

| # | เกณฑ์ | วัดด้วย | เครื่อง |

## 9. ไม่ทำในรอบนี้

- ปุ่มติดตั้งและเข้าสู่ระบบให้ในแอป (ไม่ต้องใช้คอมพิวเตอร์อีกเครื่อง) — งานใหญ่ ทดสอบขั้นเข้าสู่ระบบจริงไม่ทันก่อน 9 ต.ค. → งานต่อยอด
- ตรวจว่าเข้าสู่ระบบแล้วหรือยัง (ไม่ใช่แค่มีคำสั่ง) และตรวจซ้ำโดยไม่ต้องออกจากระบบ
