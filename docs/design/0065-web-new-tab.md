# การ์ดออกแบบ 0065: เปิดเว็บเป็นแท็บใหม่ (ไม่ทับหน้าเดิม)

- **สถานะ:** ร่าง (2026-10-26 · ผู้ช่วย) · Pakon ขอ "การเปิดเว็บ เปิดเป็นแท็บอีกแท็บ" · **อนุมัติแล้ว 2026-10-26 (Pakon)** · กำลังสร้าง
- **ข้อกำหนดที่อ้าง:** [0024](0024-voice-browser.md) เบราว์เซอร์ของผู้ช่วย · [0031](0031-web-apps.md) ปุ่ม/คำสั่งเปิดเว็บ · [0064](0064-voice-account-window.md) (ต้องมีก่อน) · H2 H4 H5
- **หลังวันหยุดเพิ่มฟีเจอร์** → สาขา `feature/0065-web-new-tab` (ต่อจาก 0064) · ไม่ติดตั้ง/ไม่รวม master จนกว่าผ่านเกณฑ์ + Pakon อนุมัติ

## 1. ปัญหาที่แก้ และใครใช้

ดู YouTube อยู่แล้วพูด/กด "เปิดจีเมล" → Gmail **ทับหน้า YouTube** ในแท็บเดิม (`BrowserControl._go` เปลี่ยนหน้าในแท็บเดียว) ·
ผู้ใช้ที่เปิดหลายเว็บสลับกันได้ใช้ (ดูคลิปไปด้วย เช็กเมลไปด้วย)

## 2. หลักการที่ใช้ตัดสิน

| หลักการ | ใช้ยังไง |
|---|---|
| H2 ไม่ทำงานผู้ใช้หาย | ไม่ทับหน้าที่ผู้ใช้เปิดอยู่ · ไม่ปิดแท็บของผู้ใช้เองเพื่อประหยัด RAM |
| H4 พอดี Pi 5 8GB | ไม่เปิดแท็บซ้ำของเว็บเดิม (สลับไปแท็บที่มีอยู่แทน) · จำกัดจำนวนแท็บ |
| H5 ความจริงก่อนความสวย | คำสั่งเสียงต้องคุม**แท็บที่ผู้ใช้เห็น** · ไม่รู้ว่าแท็บไหน = บอก ไม่เดา |
| H6 งานแน่นอน = โค้ด | เลือกแท็บด้วยชื่อเว็บ (host) ไม่ใช้ AI |

## 3. ความสัมพันธ์กับชิ้นส่วนอื่น

- **พึ่ง:** 0064 (Gmail/ไดรฟ์/ปฏิทินอยู่ในเบราว์เซอร์ของผู้ช่วยแล้ว) · `Target.createTarget` / `Target.activateTarget` ของ CDP (ใช้อยู่แล้วใน `control._page`)
- **ชั้น:** `src/aipc/browser/control.py` อย่างเดียว · ตัวแปลคำพูดไม่เปลี่ยน

## 4. ข้อมูล

ไม่เก็บอะไรเพิ่ม · แท็บอยู่ในโปรไฟล์เบราว์เซอร์เดิม · ปิดเบราว์เซอร์ = แท็บหายเหมือนเดิม

## 5. รอยต่อ (พฤติกรรม)

| คำสั่ง | ตอนนี้ | หลังการ์ดนี้ |
|---|---|---|
| "เปิด<เว็บ>" / ปุ่มหน้าแรก / ขั้น "เปิดเว็บ" ของสกิล | ทับแท็บเดิม | แท็บเดิมว่าง (about:blank / แท็บใหม่) = ใช้แท็บนั้น · **มีเว็บนั้นเปิดอยู่แล้ว = สลับไปแท็บนั้น** · ไม่งั้น = **แท็บใหม่** |
| "ค้นหา…" · "ค้นในยูทูบว่า…" · "เปิดลิงก์ที่ 2" · "ย้อนกลับ" | แท็บเดิม | แท็บเดิม (เป็นงานต่อจากหน้าที่ดูอยู่) |
| "ปิดแท็บ" | ปิดแท็บที่คุมอยู่ | เหมือนเดิม → แท็บที่เหลือล่าสุดขึ้นมา และคุมต่อได้ |
| คำสั่งอื่นทั้งหมด | แท็บที่คุมอยู่ | แท็บที่ผู้ใช้เห็นอยู่ (ข้อ 6) |

## 6. กรณีที่ต้องคิดไว้ก่อน

- **ผู้ใช้คลิกสลับแท็บเอง** → คำสั่งเสียงต้องตามไปแท็บที่เห็น · วิธี: ถามทุกแท็บว่า `document.visibilityState == "visible"` ·
  **ยังไม่รู้** ว่าบน Pi (Wayland · หน้าต่างเดียว) ตอบถูกทุกครั้งไหม → ทดสอบก่อนเขียนส่วนอื่น (T0) · ไม่ได้ = ใช้แท็บล่าสุดที่ระบบเปิด + บอกในการ์ด
- **แท็บมากเกินไป:** เกิน 6 แท็บ (ร่าง · ต้องวัด RAM ก่อนตั้งค่าจริง) → ไม่เปิดเพิ่ม · บอก "เปิดอยู่ 6 แท็บแล้ว · พูด “ปิดแท็บ” ก่อน" · ไม่ปิดแท็บเก่าเอง (H2)
- **เว็บเดิมแต่คนละหน้า** (YouTube หน้าแรก vs กำลังดูคลิป) → นับเป็นเว็บเดียวกัน · สลับไปแท็บนั้นโดยไม่เปลี่ยนหน้า (ไม่ทำคลิปที่ดูอยู่หาย · H2)
- **หน้าล็อกอิน Google (0064)** ยังเป็นหน้าต่างแยกแบบไม่คุม · ทำเป็นแท็บไม่ได้ (Google ตรวจทั้งโปรแกรม)
- **หลายผู้ใช้ / ออกจากระบบ** → เหมือนเดิม (โปรไฟล์ต่อคน · ปิดเบราว์เซอร์ตอนออก)

## 7. ต้นทุนบน Pi 5

- แต่ละแท็บที่เปิดค้าง ใช้ RAM เพิ่ม · **ยังไม่รู้ตัวเลข** → วัดใน T2 (YouTube + Gmail + ไดรฟ์ เทียบ 1 แท็บ) ก่อนตั้งเพดานจำนวนแท็บ
- CPU: YouTube ที่ไม่ได้อยู่หน้าสุดยังเล่นเสียงต่อได้ → ต้องดูว่าเล่นซ้อนกันไหม (T2)
- ไม่เรียก LLM เพิ่ม

## 8. การทดสอบ และเกณฑ์ผ่าน (ประกาศก่อนสร้าง)

- **T0 (ก่อนเขียนโค้ด · Pi 5 ทาง SSH):** เปิด 2 แท็บในเบราว์เซอร์ของผู้ช่วย สลับด้วย CDP 5 ครั้ง · `visibilityState` บอกแท็บที่อยู่หน้าถูก **5/5** = ใช้วิธีนี้ · ไม่ถึง = ใช้แท็บล่าสุด
- **ผล T0 ✅ (2026-10-26 · Pi 5 · `src/aipc/spikes/tab_visibility.py` · โปรไฟล์ชั่วคราว · หน้าต่างบนจอของ pakon ~5 วิ):** สลับ 2 แท็บด้วย `Target.activateTarget` 5 ครั้ง · แท็บหน้าตอบ `visible` แท็บหลังตอบ `hidden` **5/5** → ใช้วิธีนี้ ·
  ข้อจำกัด: สลับด้วย CDP ไม่ใช่คนคลิก → ยืนยันการคลิกจริงใน T2
- **T1 (เทสต์อัตโนมัติ · วินโดวส์):** ตามตารางหัวข้อ 5 ทุกแถว · เว็บซ้ำ = ไม่เปิดแท็บใหม่ · เกินเพดาน = ไม่เปิด + บอก · เทสต์ทั้งชุดผ่าน
- **ผล T1 ✅ (2026-10-26 · วินโดวส์):** เทสต์ใหม่ 7 ข้อ (แท็บว่างใช้แท็บนั้น · เว็บที่ 2 = แท็บใหม่ คลิปเดิมไม่หาย · เว็บเดิม = สลับไม่โหลดใหม่ ไม่เปิดแท็บที่ 3 · คำสั่งตามแท็บที่ผู้ใช้คลิก · ค้นหาอยู่แท็บเดิม · ครบเพดาน = ไม่เปิด/ไม่ปิดแท็บของผู้ใช้ · ชื่อเว็บเดียวกัน) · ทั้งชุด **1304 ผ่าน · ไม่ผ่าน 0 · ข้าม 19** · ระดับ 3 · ยังไม่ติดตั้ง
- **T2 (Pi 5 · Pakon ที่จอ):** ลำดับ "เปิดยูทูบ → เปิดวิดีโอแรก → เปิดจีเมล → เปิดยูทูบ (ต้องกลับไปคลิปเดิม ไม่ใช่แท็บที่ 3) → หยุดก่อน → ปิดแท็บ → เปิดไดรฟ์" ·
  ทำ 3 รอบ · **ทุกขั้นถูก 3/3** · คำสั่งไปผิดแท็บ **0 ครั้ง** · จด RAM (`free -m`) ตอน 1 กับ 3 แท็บ
- **ผล T2 รอบ 1 ✅ (2026-10-26 ~21:35 · Pakon ที่จอ · รุ่น `995bbfd5`):** ข้อ a–g ผ่านทุกข้อ (Pakon "a-g ผ่านหมด") · ยังไม่ได้จด RAM · เหลือ 2 รอบ
- **พบระหว่าง T2 (นอกลำดับทดสอบ):** อยู่หน้าปฏิทินของแอป + เบราว์เซอร์เปิดอยู่ · พูด "กลับไปหน้าผู้ช่วย" → เบราว์เซอร์แค่ย่อ แอปค้างหน้าปฏิทิน ·
  แก้ (ไม่ใช่งานของการ์ดนี้ แต่อยู่สาขาเดียวกัน): พูดชื่อหน้าผู้ช่วย/แชท = `BrowseCommand("app", query="workspace")` → `BrowserController.pageRequested` → `ShellScreen` ไปหน้าผู้ช่วย ·
  "กลับไปแอป" เฉย ๆ = หน้าเดิม · รับคำว่า "กลับไป**ใน**ผู้ช่วย" ด้วย · ชุดวัดเดิม 5 ชุดไม่แก้: `browse_eval.as_recorded` ตัดช่อง query ของ app ก่อนเทียบ (8 ประโยค) ·
  **ยังไม่ได้ลองที่จอ**
- **ผล T2 รอบ 2 (2026-10-26 ~22:15 · รุ่น `0b901215`):** a–f ผ่าน · **g ❌** "เปิดไดรฟ์" ถอดเสียงได้ "เปิดได" → ค้นใน Gmail ว่า "ได" (outbound.json 22:13–22:14 ×3) · "กลับไปหน้าผู้ช่วย" ผ่าน (Pakon "ผ่านหมด")
- **พบรอบ 2 + Pakon ขอเพิ่ม (2026-10-26):**
  ① "เปิดยูทูบอีกแท็บ" เดิมแปลเป็น "ค้นในยูทูบว่า อีกแท็บ" → ทับแท็บ Gmail → **แก้:** `site` + `direction="newtab"` = แท็บใหม่แม้เว็บนั้นเปิดอยู่ (อีกแท็บ · แท็บใหม่ · แท็บที่สอง · เพิ่มอีกหนึ่งแท็บ) ·
  ② **เพิ่ม "ปิดแท็บทั้งหมด"** (ปิดทุกแท็บ · ปิดเบราว์เซอร์) = ปิดเบราว์เซอร์ของผู้ช่วย · ③ ตัวถอดเสียงได้ยิน "แท็บ" เป็น "แถบ" → รับทั้งสองคำ ·
  ④ ไม่รู้จัก → "ให้ Claude เพิ่มเข้าสกิลไหม" → ใช่ → Claude ไม่ใส่คำนั้น (คีย์ลัดเว็บเปิดแท็บไม่ได้ · ถูกแล้ว) แต่หน้าจอบอก "แก้สกิลแล้ว" และติดตั้งรุ่นใหม่ ·
  พูดซ้ำก็ถามซ้ำ เรียก Claude ทุกครั้ง (วันนี้ 5 ครั้ง $0.28) → **แก้:** สกิลที่ได้ไม่มีคำที่ขอ = ไม่ติดตั้ง + บอก "Claude เพิ่มคำสั่ง … ไม่ได้" (H5) ·
  **ยังไม่แก้ (บอก Pakon):** "เปิดได" ในเว็บที่ค้นได้ = ค้นทันที (การ์ด 0057) · "หยุด" คำเดียวไม่ใช่คำสั่งหยุดคลิป · สกิล `youtube-channel8-voice` ของ Pakon ถูก Claude แก้เป็นรุ่น 1.4 (เหลือแค่คำสั่งพักคลิป)
