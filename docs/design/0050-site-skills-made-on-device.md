# การ์ดออกแบบ 0050: สกิลประจำเว็บสร้างโดย Claude ในเครื่องของผู้ใช้ (ไม่ติดมากับระบบ)

- **สถานะ:** **อนุมัติแนวทาง 2026-10-21 (Pakon: "OK ตามนี้อนุมัติ")** · ทำหลังการ์ด 0049 · เกณฑ์ประกาศในหัวข้อ 4 ก่อนเขียนโค้ด
- **ข้อกำหนดที่อ้าง:** การ์ด 0046 (สกิลประจำเว็บ) · 0043 (สกิลในตัว Claude เขียน) · 0031 (หน้าต่างบัญชี Google) · 0049 · H3 H5 H8 H9

## 1. ปัญหา

อาจารย์ต้องการให้ **Claude ในเครื่องเป็นผู้สร้างสกิล** ไม่ใช่สกิลที่ติดมากับระบบ (อนาคตผู้ใช้ต้องสร้างสกิลของเว็บต่าง ๆ เอง) ·
ตอนนี้ youtube-voice / spotify-voice เป็นสกิลในตัว (Claude เขียนบนโน้ตบุ๊ก · Opus · การ์ด 0046)

## 2. ออกแบบ

- **ถอด** `builtin/youtube-voice.md` `builtin/spotify-voice.md` ออกจากสกิลในตัว (เก็บไว้ใน `docs/benchmarks/2026-10-21-site-skills/claude/` เป็นหลักฐาน)
- **สกิลในตัว 6 ตัวคงไว้** (นัด · สั่งเครื่อง · สถานะเครื่อง · แปล · สรุป · จดหมาย) = งานหลักที่ต้องใช้ได้แม้ไม่มีเน็ต/Claude
- เปิดเว็บที่คุมได้ (YouTube Spotify Netflix ข่าว …) และยังไม่มีสกิลประจำเว็บของบัญชีนี้ → กดคีย์ลัดพูด หรือการ์ดในแชท:
  "ยังไม่มีคำสั่งเสียงของ <เว็บ> · ให้ Claude สร้างไหม (ส่งเฉพาะชื่อเว็บ)" → ใช่ → forge ในเครื่อง (sonnet เหมือนแอป) → ตัวตรวจ 0046 → ติดตั้งในบัญชีนี้
  (ทางเดิม "เพิ่มคำสั่ง … ให้สกิลไหม" ของ 0046 ใช้ต่อ = สร้าง/แก้สกิลของผู้ใช้)
- Gmail / ปฏิทิน / ไดรฟ์ / เอกสาร: สกิลสั่งในหน้าเว็บ **ทำไม่ได้** (หน้าต่างบัญชีที่ไม่ได้คุม · ตัวตรวจปฏิเสธ) → บอกตรง ๆ · สร้างแบบ "โหมด" (เปิดเว็บ + ปรับเครื่อง) ได้ตามเดิม
- ถามสร้างครั้งเดียวต่อเว็บต่อบัญชี (ตอบไม่ = ไม่ถามซ้ำจนกว่าจะสั่งเอง)

## 3. ต้นทุน

Claude ~1 ครั้งต่อเว็บต่อบัญชี (ราคาต้องวัด) · ต้องต่อเน็ต + เข้าสู่ระบบ Claude ตอนสร้าง · ใช้งานไม่ต้องใช้เน็ต · เวลาทำ ~1 วัน
