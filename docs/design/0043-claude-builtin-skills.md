- **สถานะ:** อนุมัติแล้ว 2026-10-20 (Pakon: "พวก skill ในเครื่องก็ให้ claude สร้างสิ ไม่ใช่ไปสร้างเอง" · เลือก "Claude สร้างใหม่ครบ 6 ไฟล์")
- **ข้อกำหนดที่อ้าง:** ความต้องการของอาจารย์ ([ข้อเสนอ 2026-09-29 หัวข้อ 11](../reviews/2026-09-29-feature-proposal.md)) · การ์ด 0017 (forge) · ADR-011 · H6 H7 H8 H9

## 1. ปัญหาที่แก้

สกิลในเครื่อง 6 ไฟล์: Claude สร้าง 2 (ร่างจดหมาย · สรุปข้อความ · 2026-09-29) · เราเขียนเอง 4 (แปล · นัดหมาย · สั่งงานเครื่อง · ถามสถานะเครื่อง) ·
อาจารย์ต้องการให้ Claude สร้างสกิล แล้ว AI ในเครื่องเรียกใช้

## 2. หลักการ: เราสร้างเครื่องมือ · Claude สร้างสกิล

## 3. วิธี

`python -m aipc.skills.forge rebuild <id>` (โหมดใหม่) → คำขอ = คำอธิบายเครื่องมือ/งานของสกิลนั้น (ไม่ส่งไฟล์เดิมให้ Claude ดู · ไม่ลอก) →
`claude -p` ทางเดิมของ forge (โฟลเดอร์ว่าง · ปิดเครื่องมือ · ไม่เก็บบทสนทนา) → **ล็อกส่วนหัวเรื่องสิทธิ์เป็นค่าของระบบ** (Claude ใส่ต่างไป = เขียนลงรายงาน) →
ตัวตรวจเดิม → ทดลองเส้นทาง (ห้ามแย่งประโยคของสกิลอื่น) → ผู้ช่วยอ่านรายงาน → ติดตั้งแทนไฟล์เดิม · ไฟล์เดิมอยู่ใน git (ย้อนได้)

## 4. ต้นทุน

เรียก Claude 6–12 ครั้ง (ไม่ผ่านตัวตรวจ = แก้อีกรอบ สูงสุด 2) · ราคาอ้างอิงรอบก่อน ~0.09 USD/สกิล (บัญชี subscription) · Pi 5: ไม่มีต้นทุนเพิ่ม (ไฟล์ขนาดเท่าเดิม)
