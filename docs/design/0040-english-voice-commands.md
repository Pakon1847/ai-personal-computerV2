# การ์ดออกแบบ 0040: สั่งงานด้วยเสียงภาษาอังกฤษ (ระยะ D ของการ์ด 0039)

- **สถานะ:** **ร่าง · รอ Pakon อนุมัติ** (2026-10-19) · ห้ามเขียนโค้ดจนกว่าอนุมัติ · ห้ามดาวน์โหลดโมเดลจนกว่าอนุมัติ (กฎเหล็กข้อ 5)
- **ข้อกำหนดที่อ้าง:** การ์ด 0039 (ระยะ D) · การ์ด 0019 (ปุ่มไมค์) · 0024/0026 (คีย์ลัด F9 + Zipformer) · BRIEF 5.6 · ADR-014 · H1 H4 H5 H6 H9

## 1. ปัญหาที่แก้ และใครใช้

ผู้ใช้ที่ตั้งหน้าจอเป็นภาษาอังกฤษ พิมพ์อังกฤษได้แล้ว (0039 ระยะ A–C) และฟังคำตอบเป็นเสียงอังกฤษได้แล้ว (ระยะ B) แต่**พูด**อังกฤษไม่ได้ ·
ตัวถอดเสียงทั้งสองตัวตอนนี้เป็นภาษาไทยล้วน (whisper Thonburian `-l th` ที่ปุ่มไมค์ · Zipformer ไทยที่คีย์ลัด)

## 3. ความสัมพันธ์กับชิ้นส่วนอื่น

- **พึ่ง:** `aipc/skills/english.py` (ระยะ C · ข้อจำกัด 84–86% ที่ข้อความพิมพ์) · `UiSettings.language` (ระยะ A) · `stt.Listener` · whisper.cpp v1.9.4 ที่ build ไว้แล้วบน Pi
- **มีคนพึ่ง:** หน้าผู้ช่วย (ปุ่มไมค์) · `handsfree` (คีย์ลัด F9)
- **ชั้น:** ชั้นเสียง (voice) · รันบน Pi ในเครื่อง ไม่ส่งเสียงออกนอกเครื่อง

## 4. ข้อมูล

ไม่เก็บอะไรเพิ่ม · ไฟล์เสียงชั่วคราวใน `$XDG_RUNTIME_DIR` ลบทันทีหลังถอด (เหมือนเดิม) · ชุดวัดเสียงของ Pakon เก็บนอก git (เช่น `~/voice-bench/en-cmd/` บน Pi) · ใน git มีแค่ข้อความเฉลย + ผล

## 5. รอยต่อ

- `stt.Listener(..., language=lambda: ui.language)` → `"en"` ใช้ `whisper-cli -m <โมเดลอังกฤษ> -l en` · `"th"` ทางเดิม
- คีย์ลัดในโหมดอังกฤษ: ถอดด้วย whisper อังกฤษ (Zipformer ไทยใช้ไม่ได้) → `english.to_thai()` → ได้รูปไทย = `handsfree.route` ทางเดิม · ไม่ได้ = การ์ด "ไม่รู้จักคำสั่ง" (คีย์ลัดไม่คุยกับ AI · BRIEF 5.6)
- ไม่มีโมเดลอังกฤษ = ปุ่มไมค์/คีย์ลัดในโหมดอังกฤษบอก "ยังไม่ได้ติดตั้งตัวถอดเสียงภาษาอังกฤษ" (ไม่ถอดด้วยตัวไทยแล้วได้ภาษาไทยมั่ว ๆ)

## 6. กรณีที่ต้องคิดไว้ก่อน

- ผู้ใช้ตั้งหน้าจออังกฤษแต่พูดไทย (หรือกลับกัน) → ถอดผิดภาษา · ปุ่มไมค์ยังไม่ส่งเอง ผู้ใช้เห็นก่อน · คีย์ลัด: ตัวแปลงไม่รู้จัก = ไม่ทำอะไร
- สำเนียงไทยพูดอังกฤษ = ความแม่นยำ**ยังไม่รู้** → ต้องวัดด้วยเสียง Pakon จริง (D2) ไม่ใช่เสียงสังเคราะห์อย่างเดียว
- ชื่อนัดที่พูด (เช่น "call Somchai") ถอดเป็นตัวสะกดอังกฤษแปลก ๆ ได้ → การ์ดยืนยันแสดงก่อนบันทึกเหมือนเดิม
- หลายผู้ใช้: ภาษาเป็นค่าตั้งของแต่ละผู้ใช้อยู่แล้ว (`ui.json` ของแต่ละคน)

## 7. ต้นทุนบน Pi 5

- ตัวเลือกโมเดล (whisper.cpp ggml ภาษาอังกฤษล้วน · OpenAI Whisper · **ไลเซนส์ต้องเปิดอ่านจริงก่อนใช้ · ADR-014**):
  `tiny.en` (~75 MB) · `base.en` (~142 MB) · `small.en` (~466 MB) · ขนาดโดยประมาณจากรายการไฟล์ของ whisper.cpp **ยังไม่ได้ตรวจกับไฟล์จริง**
- RAM/ความเร็วบน Pi 5: **ยังไม่รู้** → วัดในระยะ D1 · เปิดโปรเซสเฉพาะตอนถอด (ไม่ค้าง RAM) เหมือน whisper ไทย
- ดิสก์: 75–466 MB ตามโมเดลที่เลือก · LLM: ไม่เรียกเพิ่ม

## 8. การทดสอบ และเกณฑ์ผ่าน (ร่าง · ประกาศก่อนสร้าง)

- **D1 (spike · ก่อนเขียนโค้ดแอป):** วัด `tiny.en` `base.en` (และ `small.en` ถ้า base ไม่พอ) บน Pi 5 ด้วยเสียงสังเคราะห์ (เสียง ljspeech ของระยะ B อ่านประโยคชุด C1 รอบ 1 ที่กลายเป็นชุดพัฒนาแล้ว) ·
  บันทึกเวลาถอดต่อประโยค · RAM สูงสุด · ความแม่นช่องข้อมูลหลังผ่าน `to_thai` · **เลือกโมเดลเล็กสุดที่ถอดประโยค ~3 วิ ได้ใน ≤ 2.5 วิ** (ใกล้ของไทยตอนนี้ ~2 วิ)
- **D2 (เสียงคนจริง · ชุดไม่เห็นโค้ด):** Pakon อ่านคำสั่งอังกฤษ 30 ประโยคจากชุด C1 รอบ 2 ที่ตัวแปลงรู้จักแล้ว (เพื่อวัดเฉพาะตัวถอด ไม่ซ้อนข้อจำกัดของ C) + ประโยคไม่ใช่คำสั่ง 10 ·
  **ผ่านเมื่อ:** คำสั่งได้ช่องข้อมูลตรงกับตอนพิมพ์ประโยคเดียวกัน **≥ 80%** · ไม่ใช่คำสั่งถูกแปลงเป็นคำสั่ง **0** · คำสั่งที่ทำโดยไม่ยืนยันทั้งที่ช่องผิด **0**
- **D3:** เวลาจากหยุดพูดถึงขึ้นการ์ด มัธยฐาน **≤ 3 วิ** บน Pi 5 · RAM ตอนถอดเพิ่ม **≤ 500 MB** (ยังต้องรวมกับ AI ในเครื่องที่เปิดค้าง)
- **D4:** ภาษาไทยไม่ถอยหลัง: เทสต์ทั้งชุดผ่าน · เส้นทางคีย์ลัด 308 เปลี่ยน 0 · หน้าจอภาษาไทยไม่เรียกตัวถอดอังกฤษเลย
- **เทสต์อัตโนมัติ:** เลือกตัวถอดตามภาษา · ไม่มีโมเดลอังกฤษ = ข้อความบอก · คีย์ลัดอังกฤษ → to_thai → route (ตัวถอดปลอม)

## 9. ไม่ทำในรอบนี้

- ตรวจภาษาอัตโนมัติจากเสียง (โมเดลหลายภาษา) · พูดสองภาษาปนในประโยคเดียว · hotwords ภาษาอังกฤษแบบ Zipformer ·
  คุยกับ AI ผ่านคีย์ลัด (กติกาเดิม: คีย์ลัดสั่งงานอย่างเดียว)

## 10. ความเห็นที่ปรึกษา (ติตรง ๆ)

ระยะ D ใหญ่ที่สุดและเสี่ยงสุดของการ์ด 0039: ต้องโมเดลใหม่ + วัดใหม่ทั้งชุด + Pakon ต้องอัดเสียง 40 ประโยค ·
และความแม่นรวมถูกจำกัดด้วยระยะ C (84–86% ที่ข้อความพิมพ์) อยู่แล้ว · **แนะนำทำแค่ D1 (spike ครึ่งวัน) ก่อน** แล้วตัดสินจากตัวเลขจริงว่าจะทำ D2–D4 หรือเขียนเป็นงานต่อยอดในบทที่ 5
