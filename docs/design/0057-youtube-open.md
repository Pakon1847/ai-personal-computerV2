## 3. ออกแบบ

1. **กฎใหม่ (ไม่ขึ้นกับหน้าที่เปิด):** "เปิด/ดู/เล่น/ฟัง X ในยูทูบ" · "เปิดยูทูบ(แล้ว)(เปิด/ดู/เล่น/ฟัง) X" → ค้น X ใน YouTube (บริการค้นได้อื่นด้วย: Spotify Netflix …)
2. **อยู่ในเว็บที่ค้นได้แล้ว:** หน้าที่เปิดอยู่เป็น YouTube (หรือบริการค้นได้อื่น · Google = ค้นเว็บ) + พูด "เปิด/ดู/เล่น/ฟัง X" ที่ไม่ใช่คำสั่งอื่น → ค้น X ในเว็บนั้น ·
   ("ค้นหา X" เฉย ๆ ยังค้น Google ตามกฎเดิมของการ์ด 0024 · แก้ระหว่างสร้าง ก่อนวัด: ไม่เปลี่ยนพฤติกรรมเดิม) ·
   ลำดับ: หลังคำสั่งของระบบ คำสั่งของสกิลประจำเว็บ (เช่น "เปิดซับ") และ "หมายถึง … ใช่ไหม" · ก่อนถาม Claude เพิ่มคำสั่ง ·
   ไม่ค้นเมื่อเป็นคำถาม/ปฏิเสธ/เล่าเรื่อง ("ดูไม่ออก" "เปิดไม่ได้ทำไม" "เปิดแล้วค้าง")
3. **ไม่ให้ Claude ทำสกิลสำหรับงานที่ต้องพิมพ์:** "ค้นหา/หา/พิมพ์/เสิร์ช X" ในเว็บที่ค้นไม่ได้ → ไม่ถาม "เพิ่มคำสั่ง" (บอกตามจริงว่าสกิลประจำเว็บพิมพ์ไม่ได้) ·
   คำขอที่ส่ง Claude เพิ่มข้อ: งานที่ต้องพิมพ์ข้อความทำไม่ได้ ห้ามทำคำสั่งที่แค่วางเคอร์เซอร์แทน
4. **บอกผลตามจริง:** ค้นในบริการ → ดูว่าที่อยู่หน้าเป็นหน้าผลค้นหาของบริการนั้น · ไม่ใช่ = "เปิดหน้าค้นหาใน … ไม่สำเร็จ" ·
   กดคีย์ของสกิลประจำเว็บ → "กดปุ่ม … แล้ว" แทน "ทำแล้ว"

ใช้ต่อ: "เปิดคลิปแรก" / "เปิดคลิปที่ 2" มีอยู่แล้ว (การ์ด 0042)
