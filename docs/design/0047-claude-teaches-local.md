## 1. ปัญหาที่แก้ และใครใช้

AI ในเครื่องตอบความรู้เฉพาะเรื่องไม่ได้ → ส่งไปถาม Claude ทุกครั้ง (ต้องมีเน็ต · เสียเงิน · ข้อมูลออกนอกเครื่องทุกครั้ง) แม้เป็นเรื่องเดิมที่ถามไปแล้ว ·
ผู้ใช้ที่ถามเรื่องเดิมซ้ำ (วิธีทำ ขั้นตอน ความรู้ที่ไม่เปลี่ยนตามเวลา) → **ให้ Claude เขียนความรู้เรื่องนั้นเป็นสกิลไว้ในเครื่อง ครั้งหน้า AI ในเครื่องตอบเอง**

ข้ออ้างของเล่ม: ระบบเก่งขึ้นจากการใช้งาน · Claude เป็นครู · AI ในเครื่องเป็นคนใช้ · พึ่งคลาวด์น้อยลงเรื่อย ๆ (ตรงกับที่อาจารย์ขอ: "Claude สร้าง · AI ในเครื่องเรียกใช้")
**ไม่ใช่** การกลั่นน้ำหนักโมเดล (knowledge distillation แบบ Hinton) · เป็นการถ่ายทอดความรู้ระดับไฟล์สกิล ซึ่งอ่านได้ ตรวจได้ ลบได้

## 4. ข้อมูล

- สกิลความรู้ = สกิลของผู้ใช้แบบเดิม (`~/.local/share/aipc/skills/<id>.md` + รุ่นเก่าใน `.versions/` · 0600 ตามที่เก็บเดิม) · เจ้าของ = บัญชีที่สอน · ไม่แชร์ข้ามบัญชี
- ส่วนหัวเพิ่ม `kind: knowledge` · `learned: <วันที่>` · `source: claude` (ระบบเขียนเอง ไม่ให้ Claude เขียน)
- ไฟดับกลางสอน = ไม่ติดตั้งครึ่ง ๆ (ที่เก็บเดิมเขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ) · ลบ/ย้อนรุ่น = ปุ่มเดิมในหน้า Skill

## 5. รอยต่อ

- `ChatController`: ข้อความที่ Claude ตอบมีช่อง `cloud: true` (มีอยู่แล้ว) · หน้าจอเพิ่มปุ่ม **"สอนเครื่องให้ตอบเอง"** ใต้คำตอบของ Claude
- `SkillsController.teach(question, answer) -> card` · การ์ดยืนยันบอกสิ่งที่จะส่ง → ใช่ → forge (ทางเดิม) ด้วยคำขอแบบความรู้ → การ์ดผล
- `SkillsController.teachHint(question) -> card | {}` · คำถามที่กำลังส่ง Claude **คล้ายคำถามที่เคยส่ง Claude แล้ว ≥ 1 ครั้ง** (ประวัติในสมุดส่งออกของบัญชีนี้) →
  หลังคำตอบมา แสดงคำแนะนำ "ถามเรื่องนี้เป็นครั้งที่ 2 แล้ว · สอนเครื่องไว้ไหม" (ไม่ส่งอะไรจนกดใช่)
- forge prompt เพิ่มแบบ "สกิลความรู้" + ช่อง `volatile` (Claude บอกว่าเรื่องนี้เปลี่ยนตามเวลาไหม · ใช่ = ไม่สร้าง แล้วบอกผู้ใช้)

## 6. กรณีที่ต้องคิดไว้ก่อน

- **Claude ตอบผิด แล้วเครื่องจำผิด:** บอกที่มา + วันที่ทุกคำตอบ · ลบ/ย้อนรุ่นได้ · "ไม่ใช่แบบนี้" = ให้ Claude แก้ (ทางเดิมของการ์ด 0017)
- **เรื่องที่เปลี่ยนตามเวลา:** Claude ต้องตอบ `volatile` · โค้ดปฏิเสธซ้ำด้วยรายการคำของข้อมูลสด (**ตอนนี้ยังไม่มีในโค้ด** · เขียนใหม่ในการ์ดนี้ ·
  ใช้หมวดเดียวกับคำอธิบาย ask-cloud ใน `catalog.py`: ข่าว ราคา อากาศ ผลกีฬา อัตราแลกเปลี่ยน เหตุการณ์ปัจจุบัน)
- **ถามนอกเรื่องที่สอน:** prompt บังคับ "เรื่องอื่นให้บอกว่าไม่รู้" · ไม่ตอบเกินความรู้ในไฟล์
- **ไม่มีเน็ต/ปิด Claude/งบหมด ตอนจะสอน:** ปุ่มบอกเหตุผลตรง ๆ ไม่ส่งอะไร · **ตอนใช้ความรู้ไม่ต้องมีเน็ต**
- **ความรู้ชนสกิลเดิม:** ตัวตรวจเดิม (แย่งประโยคของสกิลอื่น = ไม่ผ่าน)
- **หลายผู้ใช้:** ความรู้อยู่ในบัญชีที่สอนเท่านั้น · Logout ไม่กระทบ

## 9. คำถามที่กรรมการน่าจะถาม

- **"Claude ตอบผิดแล้วจำผิดถาวร?"** → ทุกคำตอบบอกที่มา + วันที่ · ลบ/ย้อนรุ่น/ให้ Claude แก้ได้ · เรื่องที่เปลี่ยนตามเวลาไม่จำ (K5)
- **"ต่างจาก RAG ยังไง ทำไมไม่ใช้ embedding"** → ไม่เพิ่มโมเดล/RAM (RAG อยู่ในรายการตัด) · ใช้กลไกเลือกสกิลเดิม · ไฟล์ความรู้คนอ่านและตรวจได้
- **"เว็บที่ Claude ค้นมีคำสั่งแฝง แล้วเข้าไปอยู่ในความรู้?"** → ตอนตอบด้วยความรู้ AI ในเครื่องไม่มีเครื่องมือ สั่งอะไรเครื่องไม่ได้ (H8) · ตัวตรวจเดิมกรองไฟล์สกิล
