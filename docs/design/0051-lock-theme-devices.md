## 1. ปัญหาที่แก้ และใครใช้

ผู้ใช้ทุกคนบน Pi 5: (ก) ลุกไปแป๊บเดียวแล้วกลับมาเจอว่าถูก**ออกจากระบบ** แอปและงานที่เปิดไว้หายหมด · (ข) หน้า Login สีไม่ตรงกับข้างใน ·
(ค) ปฏิทินอัปเดตเฉพาะตอนเข้าระบบหรือตอนถาม · (ง) ไม่รู้ว่าไมค์/กล้อง/USB ที่เสียบอยู่ระบบเห็นไหม · (จ) ทั้งหมดนี้ต้องสั่งด้วยเสียงได้

## 4. ออกแบบรายข้อ

**4.1 ล็อกอย่างเดียว**
- `settings.py`: `logout_min` เพิ่มค่า `0 = ไม่ออกเอง` และเป็น**ค่าเริ่มต้นใหม่** · ผู้ใช้เดิมที่มีไฟล์ค่าตั้ง: ย้ายเป็น 0 ครั้งเดียว (Pakon ขอชัดว่าไม่ต้องการออกเอง) ·
  กล้อง (`presence_logout_s`) ใช้กฎเดียวกัน: ไม่เห็นเจ้าของ = ล็อก ไม่ออก
- หน้าตั้งค่า: ตัวเลือก "ออกจากระบบเองหลังล็อก" = ไม่ออก (ค่าเริ่มต้น) / 5 / 10 / 30 นาที
- เสียง: "ล็อกหน้าจอ" / "ล็อกเครื่อง" → ล็อกทันที (`swaylock` ตัวเดิม)

**4.2 ธีมหน้า Login = ธีมของผู้ใช้ที่เข้าล่าสุด**
- หน้า Login รันเป็นบัญชี `_greetd` อ่านไฟล์ของผู้ใช้ไม่ได้ (ตั้งใจ) · **ตัวช่วยสิทธิ์เดิมเรียกได้จากหน้า Login เท่านั้น** (เซสชันของผู้ใช้เรียกไม่ได้) →
  ปรับแบบระหว่างสร้าง (2026-10-22): คำสั่ง `greeter-theme` ของตัวช่วย ·
  (1) เข้าสำเร็จ → หน้า Login ส่ง `user` → ตัวช่วยจำชื่อไว้ใน `/var/lib/aipc/greeter-user.json` (root 0600 · คนอื่นอ่านไม่ได้) ·
  (2) หน้า Login เปิดใหม่ → ตัวช่วยอ่าน `~/.config/aipc/ui.json` **ปัจจุบัน**ของคนที่จำไว้ (จึงได้ธีมที่เปลี่ยนระหว่างใช้ด้วย) แล้วคืนแค่ `dark`/`light`
- ไฟล์อยู่ในพื้นที่ของผู้ใช้ → ต้องอยู่ใน home จริง (ไม่ตามลิงก์ออกนอก) · ≤ 64 KB · ค่าอื่น/อ่านไม่ได้/ตัวช่วยไม่ตอบ = ธีมดำ (ค่าเริ่มต้นการ์ด 0041)
- ชื่อคนล่าสุดอยู่กับ root เท่านั้น · หน้า Login รู้แค่ธีม (H3) · ไม่ต้องสร้างโฟลเดอร์หรือสิทธิ์ใหม่ในระบบ

**4.3 ปฏิทินดึงเองตามรอบ** — ตัวจับเวลาในเซสชันเรียก `gcal.sync()` ทุก 15 นาที (ใช้ลิงก์ iCal เดิม · อ่านอย่างเดียว) · ออฟไลน์ = ข้าม ใช้สำเนาเดิม ·
ไม่เปิดเว็บ ไม่ใช้ OAuth (การ์ด 0014 ข้อ 9 ยังมีผล) · เสียง: "อัปเดตปฏิทิน"

**4.4 รายการอุปกรณ์** — ส่วนใหม่ในหน้าสุขภาพเครื่อง: USB (`lsusb` หรือ `/sys/bus/usb/devices`) · กล้อง (`/dev/video*`) · ไมค์/ลำโพง (`wpctl status`) · Bluetooth ที่จับคู่และต่ออยู่ (`bluetoothctl devices Connected`) ·
จอ (`/sys/class/drm/*/status`) · ปุ่ม "ตรวจใหม่" · อ่านอย่างเดียว · เสียง: "มีอุปกรณ์อะไรต่ออยู่" → เปิดหน้านี้ + อ่านสรุปสั้น

**4.5 ปรับเสียง** — มีแล้ว (`command.py:201`) · รอบนี้แค่วัดซ้ำด้วยชุดทดสอบเสียง (ข้อ 8 V6)

## 5. รอยต่อ

- ตัวช่วยสิทธิ์: `{"op": "greeter-theme", "user"?: "<ชื่อ>"}` → `{"ok": true, "theme": "dark"|"light"}` · ชื่อผิดรูปแบบ = `{"ok": false}`
- `doctor.devices.scan() -> list[Device(kind, name, state)]` · `kind` ∈ usb/camera/audio_in/audio_out/bluetooth/display
- คำสั่งเสียงใหม่: `lock_screen` · `gcal_sync` · `show_devices`

## 6. กรณีที่ต้องคิดไว้ก่อน

- **เครื่องหลายคน + ไม่ออกเอง:** เจ้าของล็อกค้าง คนอื่นใช้เครื่องไม่ได้ → ยังไม่รู้ว่า labwc + greetd สลับผู้ใช้ได้ไหม · **รอบนี้:** ผู้ดูแลเปิด "ออกเองหลัง N นาที" ได้ · การสลับผู้ใช้ = ไม่ทำ (ข้อ 9)
- ลืมรหัสตอนล็อก → เหมือนเดิม (ปลดด้วยรหัสเท่านั้น)
- `bluetoothctl` ไม่มี/ไม่มีการ์ด Bluetooth → "ตรวจไม่ได้"
- ไฟล์ธีมของหน้า Login ถูกแก้มือ → ค่าไม่รู้จัก = ดำ
- ปฏิทินดึงระหว่างล็อก → ทำได้ (ไม่แสดงอะไรบนจอล็อก)

RAM ≈ 0 (ไม่มีโปรเซสค้างใหม่) · CPU: ดึง iCal ทุก 15 นาที (ไม่กี่ร้อย ms) · ตรวจอุปกรณ์เฉพาะตอนเปิดหน้า · ดิสก์ < 1 KB · LLM 0 ครั้ง · เวลาทำ ~1.5–2 วัน
