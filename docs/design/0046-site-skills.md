# การ์ดออกแบบ 0046: สกิลประจำเว็บ (Claude เขียน) · สั่งในหน้าเว็บด้วยเสียง · ไม่รู้จัก = ถามว่าจะเพิ่มเข้าสกิลไหม

- **สถานะ:** **อนุมัติแล้ว 2026-10-20 (Pakon · ให้กดคีย์ลัด + คลิกปุ่มได้)** · (Pakon 2026-10-20: "ควรจะสั่งงานด้วยเสียงได้ทุกอย่างของแต่ละเว็บที่มีการสร้างเป็นไฟล์ .md เพื่อลดการใช้เมาส์ ·
  ถ้าไม่รู้ก็ถามว่าจะเอาคำสั่งนี้ไปเพิ่มใน skill มั้ย · ผู้ใช้จะสร้าง skill ของเว็บอื่น ๆ Claude ในเครื่องก็ควรสร้างได้ รวมคำสั่งเสียงด้วย")
- **ข้อกำหนดที่อ้าง:** BRIEF 5.6 ข้อ 2–6 · ADR-011 (สกิลเป็นข้อมูล) · การ์ด 0017/0030 (forge) · 0024 (เบราว์เซอร์ของผู้ช่วย) · 0025 (AI คิดเอง = หยุดแล้ว) · 0028 (เสียง → สกิล) · 0031 (หน้าต่างบัญชี Google) · 0043 · H5 H6 H7 H8 H9

## 1. ปัญหาและข้อจำกัดจริง

- สกิล .md ตอนนี้สั่ง**ในหน้าเว็บ**ไม่ได้ (ขั้นตอนได้แค่ เปิดเว็บ/แอป/หน้า · ปรับเสียง · ถาม AI · บอก · บอกนัด)
- คำสั่งในหน้าเว็บที่มีตอนนี้เขียนตายตัวในโค้ด (ย้อน · เลื่อน · หยุด/เล่น · เต็มจอ · ข้ามโฆษณา · เลือกคลิป)
- **Gmail / Drive / Docs / ปฏิทิน Google คุมไม่ได้:** เปิดในหน้าต่างบัญชีแยกที่ไม่ได้คุม (Google ไม่ให้เข้าสู่ระบบในเบราว์เซอร์ที่ถูกคุม · การ์ด 0031) →
  สกิลประจำเว็บใช้ได้กับเว็บที่เปิดในเบราว์เซอร์ของผู้ช่วยเท่านั้น (YouTube Netflix Spotify Viu WeTV iQIYI Disney+ ข่าว Wikipedia Maps Google ค้นหา)
- "ทุกอย่างของเว็บ" ทำครบไม่ได้จริง: หน้าเว็บเปลี่ยนบ่อย · บางอย่างต้องพิมพ์ข้อความ/ล็อกอิน · การคลิกตามที่ AI เดาหน้าเว็บสด = การ์ด 0025 ที่ไม่ผ่าน
  → เป้าหมายจริง: **คำสั่งที่ใช้บ่อยของแต่ละเว็บ** (ราว 10–20 คำสั่งต่อเว็บ) และเพิ่มได้เรื่อย ๆ ด้วยเสียง

## 2. ออกแบบ

**ไฟล์สกิลประจำเว็บ** (Claude เขียนผ่าน forge · คนอนุมัติ · ข้อมูล ไม่ใช่โค้ด):

```
---
id: youtube-voice
name: สั่ง YouTube ด้วยเสียง
site: youtube            ← ใช้เมื่อหน้าที่เปิดอยู่ในเบราว์เซอร์ของผู้ช่วยเป็นเว็บนี้ (เทียบโดเมนในโค้ด)
permissions: page_actions
---
## คำสั่ง
- เดินหน้าสิบวิ | ข้ามไปสิบวิ → กดคีย์ l
- ถอยหลังสิบวิ → กดคีย์ j
- เปิดคำบรรยาย | ปิดคำบรรยาย → กดคีย์ c
- กดไลก์ → คลิก button[aria-label^="like this video"]
- ยกเลิกสมัครสมาชิก → คลิก … · ยืนยันก่อน      ← คำสั่งที่ย้อนไม่ได้/แตะบัญชี ต้องมี "ยืนยันก่อน"
```

**ขั้นตอนใหม่ (allow-list · โค้ดทำ · H6):**
1. `กดคีย์ <คีย์>` — คีย์ลัดของเว็บ (ตัวอักษร ตัวเลข ลูกศร Space Enter Esc + Shift/Ctrl) · ไม่พิมพ์ข้อความลงช่องใด
2. `คลิก <ตัวเลือก CSS>` — กดปุ่มที่ตัวเลือกเขียนตายตัวในไฟล์ · หาไม่เจอ = บอกตามจริง ไม่กดอย่างอื่นแทน (H5 H8) · ไม่อ่านเนื้อหาหน้าเว็บมาเป็นคำสั่ง
3. ทั้งสองแบบทำงานได้เฉพาะเมื่อโดเมนของหน้าที่เปิดอยู่ตรงกับ `site:` ของสกิล
(ไม่ทำในรอบนี้: พิมพ์ข้อความลงช่อง · ล็อกอิน · ซื้อ/จ่ายเงิน)

**เส้นทางเสียง:** หน้าเว็บที่เปิดอยู่มีสกิลประจำเว็บ → เทียบคำพูดกับคำสั่งของสกิลนั้นก่อน (ตรง = ทำ · ใกล้เคียง = "หมายถึง … ใช่ไหม" · การ์ด 0045) ·
คำสั่งในสกิลเข้าคำใบ้ของตัวถอดเสียง (ทาง 0028)

**ไม่รู้จัก → ถามเพิ่มเข้าสกิล:** อยู่ในเว็บที่มีสกิล + คำพูดไม่ตรงอะไร → การ์ด "เพิ่มคำสั่ง “…” ให้สกิล YouTube ไหม (ส่งให้ Claude)" →
"ใช่" = forge ทางแก้สกิล (id เดิม) → ตัวตรวจ → การ์ดอนุมัติ → ติดตั้ง → ครั้งหน้าใช้ได้ · ยังไม่มีสกิลของเว็บนั้น = "สร้างสกิลสั่ง <เว็บ> ด้วยเสียงไหม"

**สร้างสกิลเว็บอื่น:** "สร้างสกิลสั่ง Netflix ด้วยเสียง" (พิมพ์หรือพูด) → forge สร้างสกิลประจำเว็บแบบเดียวกัน (Claude รู้คีย์ลัดของเว็บดัง ๆ) · เว็บนอกรายการ = https://… ที่เขียนตายตัว

## 3. ความปลอดภัย (คำถามที่กรรมการจะถาม)

- ตัวเลือก CSS / คีย์ ที่ Claude เขียน = ข้อมูลจากภายนอก → ตัวตรวจ (รูปแบบ · ห้าม `javascript:` · ห้ามตัวเลือกช่องรหัสผ่าน/ชำระเงิน) + คนอนุมัติก่อนติดตั้ง (H8 · ADR-011)
- คำสั่งที่มีคำเสี่ยง (ลบ ยกเลิก ซื้อ จ่าย ส่ง โพสต์ สมัคร ออกจากระบบ) ตัวตรวจบังคับ "ยืนยันก่อน" · สิทธิ์ `page_actions` ใหม่ ระบบล็อกแบบการ์ด 0043
- ไม่ให้ AI อ่านหน้าเว็บแล้วตัดสินใจกดเอง (ต่างจาก 0025)

## 4. ต้นทุน

Pi: ไม่มีโมเดลใหม่ · เรียก Claude ครั้งละ ~0.1 USD อ้างอิง เฉพาะตอนสร้าง/เพิ่มคำสั่ง (ต้องมีเน็ต + Claude ในบัญชี) · ใช้งานไม่ต้องใช้เน็ต/ Claude ·
เวลาทำโดยประมาณ 1–2 วัน (ตัวแปลขั้นตอนใหม่ · ตัวสั่งในเบราว์เซอร์ · เส้นทางเสียง · forge · การ์ดถามเพิ่ม · เทสต์ · วัดบน Pi)
