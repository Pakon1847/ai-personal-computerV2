## 1. ปัญหาที่แก้ และใครใช้

สร้างความสามารถใหม่ด้วย Claude ตอนนี้ต้องพิมพ์ · วันสอบ: "สาธิตได้ทั้งสายด้วยเสียง" — พูดขอโหมดใหม่ → Claude สร้าง → พูดสั่งโหมดนั้น (0028) ·
ความเสี่ยงหลัก: ประโยคยาว ถอดเพี้ยนง่าย และ**เป็นทางที่ข้อความออกนอกเครื่อง**

## 3. ความสัมพันธ์

- **พึ่ง:** `router.define_intent` · `router.route_ai_first` (ไม่มีสกิลเดิมตรง = "create") · `SkillsController._start_forge` · `canForge` · สวิตช์ Claude (มีทั้งหมด)
- **ชั้น:** หน้าจอ · Pi 5 · ส่งออก: Claude (เฉพาะหลังยืนยัน)

## 4. ข้อมูล

ไม่เก็บอะไรเพิ่ม · ข้อความที่ส่งบันทึกในบันทึกสิ่งที่ส่งออก (ทางเดิมของการสร้างสกิล)

## 5. รอยต่อ

- **ใหม่** `SkillsController.voiceCreate(text) -> card | {}`: ขอสร้างโหมด/งานประจำ (`define_intent`) และไม่มีสกิลเดิมตรง (`route_ai_first` = "create") →
  มี Claude และเปิดสวิตช์ = การ์ด "ส่งให้ Claude สร้างสกิลนี้ ใช่ไหม" (ข้อความตามตัวอักษร · ป้ายส่งออก · `_pending` แบบ `"forge"`) ·
  ปิดสวิตช์/ไม่มี Claude = การ์ดอธิบายเดิมของ `_start_forge` (ไม่ส่ง) · อื่น ๆ = {}
- `confirm(token, ใช่)` แบบ `"forge"` → `_start_forge(ข้อความ)` (ทางเดิมทั้งหมด) · "ไม่" = ไม่ส่ง
- สร้างจากทางเสียง: `forgeDone` ไม่ส่งต่อ (`fallback` = false) · การ์ดผลอ่านออกเสียง
- QML `voiceCommand` ทาง `unknown`: `voiceAnswer` (0029) → `voiceConfirm` (0028) → **`voiceCreate`** → ไม่รู้จักคำสั่ง

## 6. กรณีที่ต้องคิดไว้ก่อน

- **ถอดเพี้ยน:** เห็นบนการ์ดก่อนส่ง · "ไม่" = ไม่มีอะไรออก
- **กำลังสร้างสกิลอื่นอยู่:** การ์ดเดิมของ `_start_forge` ("รอสักครู่")
- **มีสกิลเดิมตรงอยู่แล้ว** ("เปิดโหมดประชุม" ตอนมีโหมดประชุม): ไม่สร้างซ้ำ · ไปทางสกิล/การ์ดยืนยันของ 0028
- **เน็ตหลุดระหว่างสร้าง / Claude ไม่ผ่านประตู:** การ์ด "สร้างสกิลไม่สำเร็จ · ไม่ได้ติดตั้งอะไร" (อ่านออกเสียง) · ไม่ส่งต่อ
- **เพดานค่าใช้จ่าย Claude:** ทางเดิม (budget บล็อก = บอกเหตุผล)

## 7. ต้นทุน

บนเครื่อง ~0 · Claude 1–3 ครั้งต่อสกิล (ผลเดิม: มัธยฐาน 26 วิ · ~$0.10/สกิล · การ์ด 0017) เฉพาะเมื่อตอบ "ใช่"
