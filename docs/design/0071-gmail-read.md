- **สถานะ:** อนุมัติ 2026-10-28 ~11:40 (Pakon: "อ่าน Gmail ต้องทำได้" → "ทำเลย ติดตั้งเลย") · สาขา `feature/0070-claude-logout`

## 1. ปัญหาที่แก้ และใครใช้

Pakon ที่จอ: "อ่านเมลล่าสุด" / "มีเมลใหม่ไหม" ทำไม่ได้ · ใน Gmail พูด "เมลล่าสุด" แล้วระบบไปขอ Claude สร้างสกิลของ Gmail
(ห้ามอยู่แล้ว · `sitecmd.NO_SITE_SKILL`) → ล้ม 2 ครั้ง เสียโควตา $0.10 (ledger 11:14:55)

**ทางที่ลองแล้วไม่ได้ (บันทึกตามจริง):** ตัวเชื่อม Gmail ของ claude.ai — บัญชี Pakon ต่อไว้ (`claude mcp list` = Connected) แต่ใน
`claude -p` (ที่แอปใช้) ตัวเชื่อมต่อแบบไม่รอ และเมื่อตั้ง `MCP_CONNECTION_NONBLOCKING=0` Gmail ขึ้น `needs-auth` ทุกครั้ง (ลอง 6 ครั้ง ·
claude 2.1.310 · รวม ~$0.008 · ไม่ได้อ่านเมล) → หยุดตามกติกา "แก้ไม่สำเร็จ 2 ครั้ง"

## 3. ทำอะไร

1. พูด "อ่านเมลล่าสุด" · "มีเมลใหม่ไหม" · "เมลยังไม่อ่าน" · "มีเมลจาก <ชื่อ> ไหม" (ทางเสียง · มาก่อนทางอื่นทั้งหมด)
2. ยังไม่ได้เปิด Gmail = เปิดให้ก่อน (คำสั่งเปิดเว็บเดิม · แท็บเดิมถ้ามี) · เปิดอีเมลฉบับเดียวอยู่ = กลับหน้ากล่องจดหมาย
3. `control.INBOX_JS` อ่านแถวที่มองเห็นในรายการ (`tr.zA` · ยังไม่อ่าน = `zE`) → ผู้ส่ง (`[email]`) หัวเรื่อง (`.bog`) เวลา (`td.xW`)
4. ตอบ 3 ฉบับแรก เช่น "เมลยังไม่อ่าน 2 ฉบับ (ในหน้าแรกของกล่องจดหมาย): 1. จาก … เรื่อง … (10:15) · …" แล้วอ่านออกเสียง

## 4–6. ข้อมูล · รอยต่อ · กรณีพิเศษ

ไม่เก็บข้อมูลใหม่ · ไม่บันทึกเนื้อหาเมลลงไฟล์ · `BrowseCommand(kind="mail_read", query=latest|unread|from, direction=<ชื่อ>)` ·
ชื่อ class ของ Gmail เปลี่ยน = อ่านไม่ได้แล้วบอกว่าไม่เห็นรายการ (ไม่เดา) · แท็บ Gmail อื่น (โปรโมชัน) ที่ซ่อนอยู่ไม่นับ

  ยังไม่อ่าน/ล่าสุด/จากชื่อ/ไม่มี · ไม่ใช่หน้า Gmail = ไม่อ่าน · ใน Gmail พูดคำที่ไม่รู้จัก = ไม่ขอ Claude สร้างสกิล
