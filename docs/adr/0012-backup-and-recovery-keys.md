# ADR-012: ปลายทาง backup + ใครถือกุญแจกู้คืน

- **สถานะ:** **ตัดสินแล้ว 2026-09-28** (Pakon · ขอบเขตรอบ 3)
- **ต้องตัดสินก่อน:** เฟส 1

## ค่าที่ brief แนะนำ

ไดรฟ์ USB เข้ารหัส + รหัสสำรองพิมพ์เก็บ · ค่าเริ่มต้นผู้ดูแลไม่ถือกุญแจกู้คืนของผู้ใช้ (รีเซ็ตรหัสผ่านได้ แต่ข้อมูลที่เข้ารหัสจะเปิดไม่ได้ถ้าไม่มีรหัสกู้คืน — ต้องบอกตั้งแต่ตอนสมัคร)

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`

## การตัดสิน

**backup = image ของ microSD ทั้งการ์ด (ทำก่อนวันสาธิต) + คัดลอก home ลงไดรฟ์ USB ด้วยมือตามคู่มือ** · ไม่มีบริการ backup อัตโนมัติ · **รหัสกู้คืน:** ออกให้ตอนสมัคร เก็บเป็น hash (scrypt) ที่ root อ่านได้เท่านั้น ใช้ตั้งรหัสผ่านใหม่ ใช้แล้วออกรหัสใหม่ ([การ์ด 0012](../design/0012-real-signup.md)) · ผู้ดูแลตั้งรหัสผ่านให้ผู้ใช้ได้เสมอ ข้อมูลไม่หายเพราะไม่ได้เข้ารหัส (ADR-003) · [ข้อเสนอรอบ 3](../reviews/2026-09-28-scope-cut.md)
