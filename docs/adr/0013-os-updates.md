# ADR-013: อัปเดต OS/เคอร์เนล/EEPROM/PostgreSQL

- **สถานะ:** เสนอ (ยังไม่ตัดสิน)
- **ต้องตัดสินก่อน:** ก่อน build แรกที่ให้ผู้อื่นทดสอบ

## ค่าที่ brief แนะนำ

ผู้ดูแลยืนยันชุดอัปเดตที่ทดสอบแล้ว · backup ก่อน · ย้อน OS ด้วย backup หรือ A/B ภายหลัง

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`
