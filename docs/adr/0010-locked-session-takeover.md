# ADR-010: คนอื่นต้องการใช้เครื่องขณะเซสชันเดิมล็อกอยู่

- **สถานะ:** เสนอ (ยังไม่ตัดสิน)
- **ต้องตัดสินก่อน:** เฟส 2

## ค่าที่ brief แนะนำ

สิ้นสุดเซสชันเดิมได้เมื่อล็อกเกินเวลาที่ตั้ง + บันทึกร่างก่อน

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`
