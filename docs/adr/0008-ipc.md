# ADR-008: IPC

- **สถานะ:** **ตัดสินแล้ว 2026-09-28** (Pakon · ขอบเขตรอบ 3)
- **ต้องตัดสินก่อน:** เฟส 1

## ค่าที่ brief แนะนำ

JSON-RPC บน Unix socket + SO_PEERCRED · งานผู้ดูแลผ่าน polkit

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`

## การตัดสิน

**HTTP ผ่าน Unix socket ของ llama-server** ที่ `$XDG_RUNTIME_DIR/aipc/llm.sock` · หน้าจอกับตรรกะยังอยู่โปรเซสเดียวกัน (ไม่แยก Session Agent ในรุ่นนี้) · `$XDG_RUNTIME_DIR` เป็นของผู้ใช้คนนั้น (0700) OS จึงกันผู้ใช้อื่นให้ ไม่ต้องเขียนโปรโตคอลหรือตรวจ SO_PEERCRED เอง · ต้องยืนยันว่า build ที่ใช้รองรับ socket (spike 0.7) · งานผู้ดูแล (สร้างบัญชี) ใช้ตัวช่วยผ่าน sudo ตาม[การ์ด 0012](../design/0012-real-signup.md) แทน polkit · [ข้อเสนอรอบ 3](../reviews/2026-09-28-scope-cut.md)
