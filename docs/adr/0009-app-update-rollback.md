# ADR-009: อัปเดต/ย้อนเวอร์ชันแอป

- **สถานะ:** **ตัดสินแล้ว 2026-09-28** (Pakon · ขอบเขตรอบ 3)
- **ต้องตัดสินก่อน:** เฟส 1 (แบบพื้นฐาน)

## ค่าที่ brief แนะนำ

release แยกโฟลเดอร์ (รวม venv/Qt) + symlink + migration แบบ expand/contract · A/B ภายหลัง

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`

## การตัดสิน

**โฟลเดอร์ต่อรุ่น + ลิงก์ `current` + ลองเปิดหน้า Login ก่อนสลับ** · สลับด้วย symlink ทีเดียว · ย้อนด้วยคำสั่งเดียวโดยไม่ต้องใช้เน็ต · ไม่มี migration เพราะไม่มี DB · เหตุผล: `update-app.sh` เดิมแตกไฟล์ทับโฟลเดอร์เดิม ย้อนต้องใช้เน็ต และเลือกไฟล์สำรองผิดได้ (ตรวจ 2026-09-28) · [ข้อเสนอรอบ 3](../reviews/2026-09-28-scope-cut.md)
