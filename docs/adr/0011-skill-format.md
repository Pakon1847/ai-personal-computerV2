# ADR-011: รูปแบบ Skill

- **สถานะ:** ตัดสินบางส่วน 2026-09-23 (Pakon) — รูปแบบและชุดแรกตัดสินแล้ว · วิธีแชร์ยังเป็นข้อเสนอ
- **ต้องตัดสินก่อน:** เฟส 5

## ค่าที่ brief แนะนำ

v1 ไม่มีโค้ด · โค้ด + sandbox หลังเฟส 6

## การตัดสิน

1. **Skill v1 เป็นข้อมูล ไม่ใช่โค้ด** — ชื่อ, คำอธิบาย, ตัวอย่างคำขอ, prompt, Action ที่อนุญาต, สิทธิ์ที่ขอ
   · **รูปแบบไฟล์ = `.md`** (Pakon 2026-09-29): ส่วนหัว + `## ขั้นตอน` ที่เขียนได้เฉพาะแบบที่ระบบรู้จัก (โค้ดทำตาม) หรือ
   `## คำสั่งให้ AI` · สกิลเดิม 4 ตัวแปลงจาก JSON แล้ว (ค่าทุกช่องตรงกัน) · ตัวอ่าน JSON ยังอยู่เพื่อความเข้ากันได้ ·
   รายละเอียดใน [SKILLS.md](../SKILLS.md)
2. **ชุดแรก 6 สกิล** ตาม [SKILLS.md](../SKILLS.md): แปลไทย↔อังกฤษ, จดโน้ตจากเสียง, จดนัดหมายและเตือนความจำ,
   สั่งงานเครื่อง, ถามเครื่องว่าเป็นอะไร, "นี่คืออะไร"
3. **"AI ช่วยสร้างสกิล" ไม่ใช่การฝึกโมเดล** — ไม่มีการ fine-tune บน Pi · AI เขียน Skill (ข้อมูล) ให้ในรูป JSON ที่บังคับรูปแบบ
   → ตรวจด้วยโค้ด → ทดลองกับตัวอย่าง → ผู้ใช้ยืนยันก่อนติดตั้งเสมอ

## ข้อเสนอที่ยังไม่ตัดสิน

- **แชร์สกิลเป็นไฟล์เดียวที่ลงลายเซ็น Ed25519** ผ่าน USB/โฟลเดอร์ ใช้ได้ออฟไลน์ · เครื่องปลายทางตรวจลายเซ็น แสดงสิทธิ์ที่ขอ
  และถือเนื้อหาเป็นข้อมูลจากภายนอก (BRIEF 5.6 ข้อ 6) ก่อนให้ผู้ใช้อนุมัติ · สาธิตด้วย Pi 5 → Pi 4
- แชร์ผ่าน LAN ทีหลัง (ต้องออกแบบเรื่องเปิดพอร์ตเพิ่ม)

## หลักฐานที่ใช้ตัดสิน

ยังไม่มีผลวัด · เกณฑ์ผ่านรายสกิลอยู่ใน SKILLS.md
