# ADR-003: วิธีเข้ารหัสรายบัญชี + โหมดสะดวก

- **สถานะ:** เสนอ (ยังไม่ตัดสิน)
- **ต้องตัดสินก่อน:** เฟส 1

## ค่าที่ brief แนะนำ

fscrypt ถ้าเคอร์เนลรองรับ ไม่งั้น LUKS image ต่อผู้ใช้ (backup image ได้ขณะไม่ mount) · โหมดสะดวก = ห่อกุญแจบัญชีเพิ่มด้วยกุญแจเครื่องที่ผูกกับ OTP ของบอร์ด เฉพาะโหมดส่วนตัว ปิดเป็นค่าเริ่มต้น

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`
