# ADR-002: กล้อง RGB หรือ NIR

- **สถานะ:** **นอกขอบเขตรุ่นนี้** (ขอบเขตรอบ 3, Pakon อนุมัติ 2026-09-28) · เก็บไว้เป็นงานต่อยอด
- **ต้องตัดสินก่อน:** เปิดโหมดใช้ร่วมกันจริง

## ค่าที่ brief แนะนำ

เริ่มด้วย RGB เพื่อพัฒนา · ประเมิน NIR ก่อนเปิดใช้โหมดใช้ร่วมกันจริง

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`

## การตัดสิน

ไม่ตัดสินในรุ่นนี้ — ฟีเจอร์ที่พึ่ง ADR นี้ถูกตัดออก ([ข้อเสนอรอบ 3](../reviews/2026-09-28-scope-cut.md) หัวข้อ 5)
