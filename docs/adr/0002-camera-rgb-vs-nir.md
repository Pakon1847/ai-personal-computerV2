# ADR-002: กล้อง RGB หรือ NIR

- **สถานะ:** เสนอ (ยังไม่ตัดสิน)
- **ต้องตัดสินก่อน:** เปิดโหมดใช้ร่วมกันจริง

## ค่าที่ brief แนะนำ

เริ่มด้วย RGB เพื่อพัฒนา · ประเมิน NIR ก่อนเปิดใช้โหมดใช้ร่วมกันจริง

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`
