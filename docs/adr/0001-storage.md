# ADR-001: ที่เก็บข้อมูล: microSD อย่างเดียว หรือเพิ่ม SSD

- **สถานะ:** **ตัดสินแล้ว 2026-09-28** (Pakon · ขอบเขตรอบ 3)
- **ต้องตัดสินก่อน:** เฟส 1

## ค่าที่ brief แนะนำ

SSD สำหรับ DB/โมเดล/ข้อมูลผู้ใช้ · microSD อย่างเดียวได้ แต่ต้องยอมรับความเร็วและความทนทานที่ต่ำกว่า

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`

## การตัดสิน

**microSD อย่างเดียวในรุ่นนี้** · ขอบเขตรอบ 3 ไม่มีฐานข้อมูล งานเขียนมีแค่ไฟล์ข้อมูลเล็ก ๆ ใน home · ต้องวัดและใส่เล่ม: เวลาโหลดไฟล์โมเดล LLM จาก microSD (ADR-007) · SSD เป็นงานต่อยอด · [ข้อเสนอรอบ 3](../reviews/2026-09-28-scope-cut.md)
