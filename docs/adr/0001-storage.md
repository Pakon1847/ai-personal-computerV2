# ADR-001: ที่เก็บข้อมูล: microSD อย่างเดียว หรือเพิ่ม SSD

- **สถานะ:** เสนอ (ยังไม่ตัดสิน)
- **ต้องตัดสินก่อน:** เฟส 1

## ค่าที่ brief แนะนำ

SSD สำหรับ DB/โมเดล/ข้อมูลผู้ใช้ · microSD อย่างเดียวได้ แต่ต้องยอมรับความเร็วและความทนทานที่ต่ำกว่า

## หลักฐานที่ใช้ตัดสิน

ยังไม่มี · เมื่อวัดแล้วให้ลิงก์ไฟล์ใน `docs/benchmarks/`
