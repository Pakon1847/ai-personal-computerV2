# โครงเล่มปริญญานิพนธ์ — แผนที่ "หัวข้อนี้เอาข้อมูลจากไฟล์ไหน"

> ร่าง 2026-09-28 สำหรับ Pakon · ใช้คู่กับคู่มือรูปแบบเล่มของมหาวิทยาลัย/คณะ (ถ้าหัวข้อไม่ตรงคู่มือ ให้ยึดคู่มือ) ·
> **เขียนเนื้อหาด้วยภาษาของ Pakon เอง** ไฟล์นี้บอกแค่ว่าข้อเท็จจริงและตัวเลขอยู่ที่ไหน ·
> ตรวจระเบียบของคณะเรื่องการใช้ AI ช่วยทำงาน แล้วระบุในเล่มตามที่กำหนด ·
> ตัวเลขทุกตัวในเล่มต้องมีไฟล์หลักฐานใน `docs/benchmarks/` และบอกเครื่องที่วัด (ผล Pi 4 เขียน "(Pi 4)")

ลำดับเขียนที่แนะนำ: บทที่ 1 (สั้น) → บทที่ 3 ส่วนที่นิ่งแล้ว (3.1–3.4) → บทที่ 2 → ที่เหลือของบทที่ 3 → บทที่ 4 ตามผลที่ได้ → บทที่ 5 ·
**เริ่มเขียน ส. 10 ต.ค.** (Pakon 2026-10-07 · วันที่เดิมในหัวบทเลื่อนทั้งหมด)

**ชุดข้อมูลพร้อมที่มา (เตรียม 2026-10-07):** [บทที่ 1](facts-ch1.md) · [บทที่ 2 + รายการอ้างอิงที่ตรวจแล้ว 48 รายการ](facts-ch2.md) · [บทที่ 3](facts-ch3.md) —
อ่านคู่กับตารางด้านล่าง · ชุดข้อมูลบอกข้อเท็จจริงและตัวเลข ส่วนตารางบอกว่าหัวข้อไหนใช้ไฟล์ไหน

| หัวข้อ | ผลที่มีแล้ว / ที่ต้องวัด |
|---|---|
| 4.1 สภาพเครื่องที่ใช้วัด | `aipc.doctor --save` บน Pi 5 (runbook ตั้ง Pi 5 ขั้น 3) |

| 4.3 ใบหน้า | มีแล้ว: LFW 99.35%, EER · ต้องวัด: เวลา/RAM บน Pi 5 · กับคนจริงตาม face-protocol (ถ้าทัน) |
| 4.4 Skill | มีแล้ว: สกิล 4 ชุดสำรอง 93.0% / 1.1% · ต้องวัดใหม่ **ผ่านเส้นทางจริงของผู้ใช้** หลังแก้บั๊ก (ตัวเลข 40/40 เดิมวัดแค่ตัวแปลงวันเวลา) |
| 4.5 หน้าจอ | เวลาเปิด, RAM, ตัวอักษร 200% (มีผล Pi 4 · ต้องวัด Pi 5) |
| 4.6 ความปลอดภัย | T6 ไม่รั่ว · T12 ข้ามบัญชี · สิทธิ์หน้า Login (`sudo -l -U _greetd`) · สมัคร/กู้คืนตามการ์ด 0012 ข้อ 8 |
| 4.7 ความทนทาน | T1–T14 (บูต, kill, ถอดกล้อง, ไฟดับ, ดิสก์เต็ม, soak 12 ชม.) |
