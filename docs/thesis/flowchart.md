## ภาพที่ 1 ภาพรวม: เปิดเครื่อง → เข้าสู่ระบบ → ใช้งาน → ออก

```mermaid
flowchart TD
    A([เปิดเครื่อง Raspberry Pi 5]) --> B[systemd เริ่ม greetd]
    B --> C[หน้า Login ของระบบ]
    C --> D{ผู้ใช้เลือก}
    D -->|สมัครบัญชีใหม่| E[ตัวช่วยสิทธิ์ root ตรวจกฎ<br/>สร้างบัญชี + PIN กู้คืน]
    E --> C
    D -->|ลืมรหัสผ่าน| F[ใช้ PIN กู้คืน ตั้งรหัสใหม่]
    F --> C
    D -->|เข้าสู่ระบบ| G{PAM ตรวจรหัสผ่าน<br/>หรือสแกนใบหน้าที่ลงทะเบียนไว้}
    G -->|ไม่ผ่าน| C
    G -->|ผ่าน| H[เริ่มเซสชันของผู้ใช้<br/>labwc + หน้าจอระบบ + AI ในเครื่อง]
    H --> I[อุ่นแคช AI: system prompt + รายการสกิล]
    I --> J[หน้าแรก / แชท / ปฏิทิน / ไฟล์ / Skill / เครื่อง / ตั้งค่า]
    J --> K{ผู้ใช้สั่งงาน}
    K -->|พิมพ์ในแชท| L[[เส้นทางข้อความ · ภาพที่ 2]]
    K -->|กดคีย์ลัด F9 แล้วพูด| M[[เส้นทางเสียง · ภาพที่ 3]]
    K -->|กดปุ่มบนหน้าจอ| N[ทำงานนั้นตรง ๆ]
    L --> J
    M --> J
    N --> J
    J --> O{ไม่ได้ใช้งาน}
    O -->|ไม่แตะเครื่องตามเวลาที่ตั้ง| P[ล็อกหน้าจอ<br/>ปลดด้วยรหัสผ่าน]
    O -->|เปิดกล้องตรวจเจ้าของ: ไม่เห็นเจ้าของ| P
    P -->|ล็อกนานต่อ| Q[ออกจากระบบ]
    P -->|ปลดล็อก| J
    J -->|กดออกจากระบบ| Q
    Q --> R[ปิดทุกโปรเซสของผู้ใช้] --> C
```

## ภาพที่ 2 เส้นทางของข้อความที่พิมพ์

```mermaid
flowchart TD
    A([ผู้ใช้พิมพ์ข้อความ]) --> B{กฎในโค้ด<br/>ไม่ผ่าน AI}
    B -->|คำสั่งเครื่อง: เปิดเว็บ/แอป/หน้า ปรับเสียง| C{ต้องยืนยันไหม}
    C -->|ไม่| D[ทำทันที + ปุ่มย้อนกลับ]
    C -->|ใช่| E[การ์ดยืนยัน] -->|ใช่| D
    B -->|นัด/เตือน · วันเวลาคำนวณด้วยโค้ด| F[การ์ดนัด → ยืนยัน → บันทึก]
    B -->|คำถามที่โค้ดตอบได้: เวลา นัด ไฟล์ สุขภาพเครื่อง อากาศ| G[ตอบจากข้อมูลจริงในเครื่อง]
    B -->|ประโยคตรงกับสกิล| H[[ทำสกิล · ภาพที่ 4]]
    B -->|ขอโหมด/งานประจำที่ยังไม่มี| I[[Claude สร้างสกิล · ภาพที่ 4]]
    B -->|ไม่ตรงกฎ| J[AI ในเครื่อง Gemma 4 E2B<br/>+ รายการเครื่องมือ: สกิล · ask-cloud · create-skill]
    J -->|ตอบเอง| K[คำตอบ + ทำไมได้คำตอบนี้]
    J -->|เลือกสกิล| H
    J -->|ask-cloud หรือตอบว่าไม่รู้| L{เปิดใช้ Claude ไว้ไหม}
    L -->|ไม่| M[บอกตรง ๆ ว่าต้องเปิด Claude]
    L -->|ใช่| N[ส่งคำถาม + บริบท ≤ 4 ข้อความ ไป Claude<br/>จดในสมุดส่งออก · ตรวจงบต่อวัน]
    N --> O[คำตอบของ Claude พร้อมป้ายที่มา<br/>ยังไม่ติดตั้ง: ปุ่มสอนเครื่องให้ตอบเอง]
    J -->|create-skill| I
```

## ภาพที่ 3 เส้นทางเสียง (คีย์ลัด F9)

```mermaid
flowchart TD
    A([กด F9 แล้วพูด]) --> B[ถอดเสียงในเครื่อง<br/>Zipformer ไทย + คำใบ้คำสั่ง · ภาษาอังกฤษ whisper]
    B --> C{มีการ์ดรอตอบอยู่ไหม}
    C -->|มี| D{ใช่ / ไม่ / ไม่ชัด}
    D -->|ใช่| E[ทำตามการ์ด]
    D -->|ไม่| F[ยกเลิก ไม่ทำอะไร]
    D -->|ไม่ชัด| G[ขอให้ตอบใหม่]
    C -->|ไม่มี| H{คำสั่งของระบบ<br/>เบราว์เซอร์ · เครื่อง · แอป · สกิลโค้ด}
    H -->|ตรง| I[ทำทันที · ผลเด้งบนจอ + อ่านออกเสียง]
    H -->|ไม่ตรง| J{หน้าเว็บที่เปิดอยู่มีสกิลประจำเว็บ<br/>และพูดตรงคำสั่ง}
    J -->|ตรง| K[กดคีย์ลัด/คลิกปุ่มในเว็บนั้น<br/>ตรวจโดเมนซ้ำตอนกด · คำสั่งเสี่ยงยืนยันก่อน]
    J -->|ไม่ตรง| L{นัด / งานภาษา}
    L -->|นัด| M[การ์ดนัด → ยืนยัน]
    L -->|งานภาษา| N[ถามก่อน แล้วส่งไปแชท]
    L -->|ไม่ใช่| O{ได้ยินใกล้คำสั่ง}
    O -->|ใกล้| P[ถาม: หมายถึง … ใช่ไหม]
    O -->|ไม่ใกล้| Q{อยู่ในเว็บที่คุมได้}
    Q -->|ใช่| R[ถาม: เพิ่มคำสั่งนี้ให้สกิลของเว็บไหม<br/>ใช่ = Claude เขียนเพิ่ม]
    Q -->|ไม่| S[ถาม: ส่งไปถามผู้ช่วยในแชทไหม]
```

```mermaid
flowchart TD
    A([เลือกสกิลแล้ว]) --> B{ชนิดของสกิล .md}
```
