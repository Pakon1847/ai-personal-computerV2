## 3.1 ภาพรวมสถาปัตยกรรม ([ARCHITECTURE](../ARCHITECTURE.md))

```text
เปิดเครื่อง → systemd → greetd → aipc-greeter → cage → aipc.ui --greeter       (ผู้ใช้ระบบ _greetd)
                │ PAM ของ OS: รหัสผ่าน หรือ ตั๋วจาก visiond (สแกนหน้า · ผู้ใช้ระบบ _aipcvision)
                ▼ ผ่าน
           aipc-session (ผู้ใช้คนนั้น) → labwc (ค่าของเรา) → aipc-shell-loop → aipc.ui --session --fullscreen
                ├ llama-server ของผู้ใช้ (systemd --user · Unix socket ใน $XDG_RUNTIME_DIR · โมเดลเดียว)
                ├ swayidle → swaylock / ออก · (ถ้าเปิด) ตัวตรวจด้วยกล้อง
                └ ตามคำขอ: claude -p (ไฮบริด/สร้างสกิล) · Piper (อ่านออกเสียง) · whisper.cpp (ถอดเสียง) · Open-Meteo
           "ออก" → labwc --exit → KillUserProcesses ปิดทุกโปรเซสของผู้ใช้ → กลับหน้า Login
หน้า Login → sudo -n aipc-accounts (ตัวช่วย root ตัวเดียว · สมัคร/กู้คืน/ลบบัญชี)
```

## 3.5 แต่ละส่วนของระบบ

### 3.5.1 เข้าสู่ระบบ สมัคร กู้คืน ลบบัญชี ([0003](../design/0003-real-login.md) · [0004](../design/0004-v2-session.md) · [0012](../design/0012-real-signup.md) · [0015](../design/0015-face-login.md))

- หน้า Login เป็น greeter ของ greetd [R8] · **โค้ดเราไม่ตรวจรหัสผ่านเอง** PAM ของ OS ตรวจ · ผังแป้นอังกฤษ/ไทยเหมือนในเซสชัน (สลับด้วย ~) · เตือนเมื่อพิมพ์ไทยในช่องรหัส
- สมัคร: หน้าจอ → `sudo -n /usr/local/sbin/aipc-accounts` (อนุญาตเฉพาะผู้ใช้ `_greetd` · JSON ทาง stdin) → ตัวช่วย root ตรวจกฎซ้ำ → `useradd`/`chpasswd` · home 0700 · ไม่ใส่กลุ่ม sudo · ตั้ง PIN
- สแกนหน้าเข้าเครื่อง: `aipc-visiond` (ผู้ใช้ `_aipcvision`) สแกน 1:N แล้วออกตั๋ว → PAM `pam_exec` [R34] → ผ่านแล้วข้ามรหัสผ่าน · แม่แบบอยู่นอก home · รหัสผ่านใช้ได้เสมอ
- กู้คืน: PIN → ตั้งรหัสใหม่ (หน่วงเมื่อผิด ราว 30 ครั้ง/วัน) → ลบ `login.keyring` ในนามผู้ใช้ (กัน symlink)
- ลบบัญชี: ที่หน้า Login · ต้องใส่รหัส + พิมพ์ยืนยัน · ใบยืนยัน 7 บรรทัด · ตัวช่วยเดียวกับสมัคร ([runbook + ผล](../runbooks/pi5-account-delete.md))

### 3.5.4 สกิล ([ADR-011](../adr/0011-skill-format.md) · [SKILLS](../SKILLS.md) · [0001](../design/0001-reminder.md) · [0008](../design/0008-skill-command.md) · [0009](../design/0009-skill-machine.md) · [0017](../design/0017-auto-skill.md) · [0018](../design/0018-skill-retrieval.md))

- เส้นทางข้อความ: **กฎ (โค้ด) ก่อน** → ไม่ตรง → AI ในเครื่อง + เครื่องมือ (สกิลในตัว + สกิลผู้ใช้ 5 ตัวที่เกี่ยวที่สุด [+ ask-cloud, create-skill ถ้าเปิด Claude])
- สกิลเป็นไฟล์ `.md`: ส่วนหัว + `## ขั้นตอน` (เปิดเว็บ · เปิดแอป · เปิดหน้า · ปรับ/ปิด/เปิดเสียง · ถาม AI · บอก) หรือ `## คำสั่งให้ AI` · บรรทัดที่ไม่รู้จัก = โหลดไม่ได้ทั้งไฟล์
- สั่งเครื่อง: allow-list (ACTIONS/APPS/SITES/PAGES ใน `skills/actions.py`) · รันเป็นรายการอาร์กิวเมนต์ ไม่ผ่าน shell · ไม่แน่ใจ = ถามก่อน · ย้อนกลับคำสั่งล่าสุดได้
- นัด: แปลงวันเวลาด้วยโค้ด · ยืนยันก่อนบันทึก · เตือนบนจอ · แจ้งนัดที่พลาด · นัดซ้ำ
- **Claude สร้างสกิล** (`claude -p` · ไม่มีเครื่องมือ · โฟลเดอร์ว่าง · ไม่เก็บบทสนทนา · เพดาน $1.00/ครั้ง · แก้ได้ 2 รอบ) → **ประตู 3 ชั้น**:
  (1) ก่อนติดตั้ง (โค้ด): ตัวตรวจไฟล์ ≤ 8,000 ไบต์ · id ไม่ซ้ำ · ประโยคทดสอบไปถูกสกิล · **ไม่แย่งประโยคของสกิลเดิม** · สิทธิ์อยู่ในรายการ
  (2) หลังใช้ (ผู้ใช้): ป้าย "สกิลใหม่ (Claude สร้าง · รุ่น N)" + [ยกเลิก] / [ไม่ใช่แบบนี้] → Claude แก้เป็นรุ่นใหม่
  (3) ปิดเอง (โค้ด): ผิด 2 ครั้งติด = ปิด · [R20] [R48]
- เลือกสกิลผู้ใช้ 5 ตัว: TF-IDF n-gram ตัวอักษร 2–3 ตัว (ไม่ใช้โมเดล · < 1 ms บน Pi) [R46] [R47]
