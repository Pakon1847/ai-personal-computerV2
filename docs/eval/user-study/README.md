# ชุดทดสอบกับผู้ใช้จริง (ร่าง · รอ Pakon ตรวจและนัดอาสาสมัคร)

แนวคิดข้อ 3 ใน [ข้อเสนอบ่าย 1 ต.ค.](../../reviews/2026-10-01-ideas-afternoon.md) · เตรียมโดยผู้ช่วย 2026-10-01 · **ยังไม่ได้ใช้กับใคร**

## เป้าหมาย

วัดว่าคนทั่วไป (รวมผู้สูงอายุ) ใช้เครื่องนี้ทำงานประจำวันได้จริงไหม · หลักฐานที่เล่มยังไม่มี (ตอนนี้มีแต่ชุดประโยคที่ AI เขียน)

## ผู้เข้าร่วมและขั้นตอน

- 5 คน: ผู้สูงอายุ (60+) 2 คน · คนทำงาน/นักศึกษา 3 คน · ไม่เคยเห็นเครื่องนี้มาก่อน
- ใช้บัญชีทดสอบที่สร้างใหม่ต่อคน (ไม่ใช้บัญชีจริงของ Pakon) · ลบบัญชีหลังทดสอบ
- ขอความยินยอมก่อน (แบบฟอร์มข้างล่าง) · ไม่บันทึกเสียงหรือภาพ · จดแค่ผลตามตาราง
- ผู้ดำเนินการอ่านโจทย์ให้ฟังทีละข้อ · ไม่ช่วยกดให้ · ช่วยได้เมื่อผู้ใช้ขอ (นับเป็น "สำเร็จแบบมีคนช่วย")
- เวลา: ~30 นาทีต่อคน

## เตรียมเช้าวันทดสอบ (เพิ่ม 2026-10-05)

1. `sudo /opt/aipc-v2/.venv/bin/python -m aipc.spikes.study_prep p1 p2 p3 p4 p5` (ดูก่อน) → เติม `--apply` ·
   สร้างบัญชีผ่านตัวช่วยเดียวกับหน้าสมัคร · ใส่ `~/Documents/ใบเสร็จค่าซ่อมแอร์.txt` (T5 · คำตอบ **1,600 บาท**) ·
   ใส่นัด "รับยาที่โรงพยาบาล" 18:00 ของวันนี้ (T3 ต้องมีคำตอบ) · **รันวันเดียวกับที่ทดสอบ** (นัดเป็นของ "วันนี้")
2. เข้าทุกบัญชีที่หน้าจอครั้งละ 1 นาทีแล้วออก → AI อุ่นแคชไว้ (ไม่อุ่น = ข้อความแรกรอ ~40 วิ · [ผล](../../benchmarks/2026-10-01-llm-speed-ideas-pi5/README.md)) · เวลาที่จดจะไม่รวมการรอนี้
3. กดปุ่มตรวจความพร้อม (หน้าเครื่อง) · อุณหภูมิเริ่มต้น < 70°C · จดรุ่นแอป (`readlink /opt/aipc-v2`)
4. หลังแต่ละคน: ลบบัญชีที่หน้า Login › ลบบัญชี (ทดสอบฟีเจอร์ลบบัญชีไปด้วย · จดผลตาม [runbook](../../runbooks/pi5-account-delete.md))
5. ลองครบ 8 โจทย์เองก่อน 1 รอบ (pilot) · โจทย์ไหนไม่ผ่านแม้ผู้ดำเนินการทำเอง = แก้ก่อนเริ่ม ไม่ใช่ปัญหาของผู้ใช้

## โจทย์งาน (8 ข้อ) · เกณฑ์สำเร็จ

| # | โจทย์ (อ่านให้ผู้เข้าร่วมฟัง) | สำเร็จเมื่อ |
|---|---|---|
| T1 | เข้าเครื่องด้วยรหัสผ่านที่ได้รับ | เห็นหน้าผู้ช่วย |
| T2 | ให้เครื่องเตือนว่าพรุ่งนี้บ่ายสองโมงมีนัดหมอ | นัดขึ้นในการ์ด "นัดถัดไป" ถูกวันเวลา |
| T3 | ถามว่าวันนี้ต้องทำอะไรบ้าง | ได้รายการนัดของวันนี้ |
| T4 | แปลประโยค "ขอบคุณที่ช่วยเหลือ" เป็นภาษาอังกฤษ | ได้คำแปลที่ถูก |
| T5 | หาไฟล์ใบเสร็จค่าซ่อมแอร์ (เตรียมไฟล์ไว้ในโฟลเดอร์) แล้วถาม AI ว่าจ่ายไปเท่าไร | ตอบยอดเงินถูก |
| T6 | ให้เครื่องอ่านคำตอบล่าสุดออกเสียง | ได้ยินเสียง |
| T7 | ขยายตัวหนังสือให้ใหญ่ขึ้น | ตั้งขนาด ≥ 150% |
| T8 | ถามว่าเครื่องร้อนไหม | ได้คำตอบจากค่าจริงของเครื่อง |

บันทึกต่อข้อ: สำเร็จเอง / สำเร็จแบบมีคนช่วย / ไม่สำเร็จ · เวลา (วินาที) · ปัญหาที่เห็น

## แบบสอบถาม SUS (10 ข้อ · 1 = ไม่เห็นด้วยอย่างยิ่ง … 5 = เห็นด้วยอย่างยิ่ง)

ต้นฉบับ: Brooke, J. (1996). *SUS: A "quick and dirty" usability scale.* ใน P. W. Jordan et al. (Eds.), Usability Evaluation in Industry (pp. 189–194). Taylor & Francis.
**คำแปลไทยข้างล่างผู้ช่วยแปลเอง ยังไม่ผ่านการทดสอบความเที่ยง** · ค้นแล้วยังไม่พบฉบับไทยที่ตีพิมพ์ (มีฉบับมาเลย์ JMIR Human Factors 2018 doi:10.2196/10308) ·
ก่อนใช้: ให้คนที่สองแปลกลับเป็นอังกฤษแล้วเทียบ (back-translation) และบอกข้อจำกัดนี้ในเล่ม

| # | English (original) | ไทย (ร่าง) |
|---|---|---|
| 1 | I think that I would like to use this system frequently. | ฉันคิดว่าอยากใช้ระบบนี้บ่อย ๆ |
| 2 | I found the system unnecessarily complex. | ฉันรู้สึกว่าระบบซับซ้อนเกินความจำเป็น |
| 3 | I thought the system was easy to use. | ฉันคิดว่าระบบใช้งานง่าย |
| 4 | I think that I would need the support of a technical person to be able to use this system. | ฉันคิดว่าต้องมีคนที่รู้เรื่องเทคนิคช่วย จึงจะใช้ระบบนี้ได้ |
| 5 | I found the various functions in this system were well integrated. | ฉันรู้สึกว่าส่วนต่าง ๆ ของระบบทำงานเข้ากันได้ดี |
| 6 | I thought there was too much inconsistency in this system. | ฉันคิดว่าระบบนี้มีความไม่สม่ำเสมอมากเกินไป |
| 7 | I would imagine that most people would learn to use this system very quickly. | ฉันคิดว่าคนส่วนใหญ่จะเรียนรู้วิธีใช้ระบบนี้ได้เร็วมาก |
| 8 | I found the system very cumbersome to use. | ฉันรู้สึกว่าระบบนี้ใช้งานยุ่งยากมาก |
| 9 | I felt very confident using the system. | ฉันรู้สึกมั่นใจมากเมื่อใช้ระบบนี้ |
| 10 | I needed to learn a lot of things before I could get going with this system. | ฉันต้องเรียนรู้หลายอย่างก่อนจะเริ่มใช้ระบบนี้ได้ |

คิดคะแนน (Brooke 1996): ข้อคี่ = คะแนน − 1 · ข้อคู่ = 5 − คะแนน · รวม × 2.5 → 0–100 ·
สคริปต์: `python -m aipc.spikes.user_study results.csv` (รูปแบบไฟล์ดู `results-template.csv`)

## เกณฑ์ (ประกาศก่อนทดสอบ)

- งานสำเร็จเอง (ไม่นับมีคนช่วย) ≥ 80% ของทุกงานรวมกัน
- คะแนน SUS เฉลี่ย ≥ 68 (ค่าเฉลี่ยจาก ~500 ผลิตภัณฑ์ · Sauro, J. 2011 *A Practical Guide to the System Usability Scale: Background, Benchmarks & Best Practices* ·
  อ้างซ้ำใน Brooke, J. 2013 "SUS: A Retrospective", Journal of Usability Studies 8(2):29–40 · ตรวจ 2026-10-01)
- รายงานผู้สูงอายุแยก · 5 คนบอกแนวโน้มได้ ไม่ใช่สถิติ
