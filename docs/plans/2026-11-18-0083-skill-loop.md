# การ์ด 0083 วงจรเรียนรู้สกิล · แผนลงมือ

> ทำเองใน session (CLAUDE.md: ไม่ใช้ subagent ถ้า Pakon ไม่สั่ง) · skill `executing-plans` + `test-driven-development` · หัวงานใช้ "Task N" ให้สคริปต์ของ skill หาเจอ

**เป้าหมาย:** ตัววัด `aipc.spikes.skill_loop_eval` วัดเกณฑ์ L1–L5 บน Pi 5 กับแอปตัวจริง · ทดสอบด้วย Claude ปลอม + AI ปลอมบนวินโดวส์ก่อน (ไม่ใช้โควตา)

**แนวทาง:** ใช้ `AppDriver` เดิม (การ์ด 0022) · `drv.say(ข้อความ)` = ทางเดียวกับหน้าจอ (AI ในเครื่องเลือก create-skill → Claude สร้าง → ประตู → ติดตั้ง → ทำงาน) · ห่อตัวสร้างสกิลเพื่อเก็บ Proposal ทุกครั้ง (L5) · สกิลผู้ใช้ 50 ตัวโหลดด้วย `skill_select.load_pool`

**การ์ด:** [docs/design/0083-skill-loop.md](../design/0083-skill-loop.md) (อนุมัติ 2026-11-18 · L1 นับครบวงจร)

## ข้อกำหนดรวม

- ชุดทดสอบ `tests/data/skill_loop_test1.txt` **ตัววัดอ่านเอง · ผู้ช่วยไม่เปิดอ่านจนรันเสร็จ** · ไฟล์ยังว่าง (ไม่มีข้อที่กรอก) = ตัววัดหยุดพร้อมข้อความ ไม่รัน
- ไม่แก้ไฟล์ใน `tests/data/` ที่มีอยู่ · ไม่เพิ่ม dependency · ruff ผ่าน
- ผลดิบเก็บทุกข้อ รวมข้อที่ไม่ผ่าน · ไม่มีข้อมูลส่วนตัว

## จุดที่ต้องระวัง (ไม่มีเทสต์อื่นครอบ)

1. ไฟล์ชุดข้อมูลมีข้อที่ "คำสั่ง:" ว่าง → ต้องหยุดและบอกเลขข้อ ไม่ข้ามเงียบ → เทสต์ใน Task 1
2. ครั้งแรก AI ในเครื่องส่งต่อ Claude ถาม (route `cloud`) แทนการสร้าง → นับ "ไม่ถาม Claude สร้าง" ไม่ล้ม → Task 2
3. Claude สร้างแล้วไม่ผ่านประตู/ทดลองเส้นทาง → ต้องเก็บ `skill_md` + `trial` + `errors` ไว้ (L5 · บทเรียน 2026-10-08) → Task 2
4. ครั้งที่สองไปสกิลอื่นที่ไม่ใช่ตัวใหม่ แต่ ledger 0 → L2 ไม่ผ่านข้อนั้น (ต้องเป็นสกิลตัวใหม่) → Task 2
5. คำสั่งเครื่องถูกทำในข้อที่ route เป็นสกิลผู้ใช้ โดยไม่มีการ์ด `confirmToken` → นับ L4 → Task 2

### Task 3: ทั้งชุด + สรุป + ใบตรวจของ Pakon + L3

**ไฟล์:** แก้ `src/aipc/spikes/skill_loop_eval.py` · เทสต์ `tests/test_skill_loop_eval.py` · สร้าง `scripts/bench/run_skill_loop.sh`

**รอยต่อ:**
- `summarize(rows, judged: dict[str, bool] | None) -> dict` · `L1 = [ข้อที่ asked_create และ installed, ทั้งหมด]` + แยกขั้น `asked_create` · `installed` · `L2 = [ข้อที่ installed และ again_new_skill และ again_ledger_added == 0 และ judged[id] เป็นจริง, ข้อที่ installed]` (ยังไม่มีใบตรวจ = `L2` เป็น `None` แต่ส่วน route/ledger รายงานได้) · `L4 = รวม unconfirmed` · `pass = {"L1": ≥ 0.8 · "L2": ≥ 0.9 · "L4": == 0}`
- `review_sheet(rows) -> str` · Markdown ทีละข้อ: คำสั่ง · ผลที่ถูก · ครั้งที่สองเครื่องทำอะไร (plans/ข้อความ) · ช่อง `ตัดสิน: ถูก / ไม่ถูก` ให้ Pakon กรอก · `read_sheet(text) -> dict[str, bool]`
- `h_routes(skills) -> dict[str, str]` · ข้อความชุด H (`voice_h_eval.h_items()`) → `handsfree.route(text, False, skills.voiceSkill, skills.voiceIntent)` · L3 = จำนวนข้อคำสั่ง (expect ไม่ว่าง) ที่ route เปลี่ยนระหว่างก่อน/หลังติดตั้งสกิลใหม่ · ผ่านเมื่อ 0 (ไม่มีข้อที่เคยเป็นคำสั่งแล้วกลายเป็นอย่างอื่น)
- CLI: `python -m aipc.spikes.skill_loop_eval --server URL --data FILE --user-skills POOL --user-count N --out FILE` · `--score FILE.json --sheet ใบตรวจ.md` = รวมคำตัดสินของ Pakon แล้วสรุปใหม่ (ไม่รันซ้ำ) · `--fake-claude` = ตัวสร้างสกิลปลอมคืนสกิลตายตัวที่ผ่านประตู (ลองตัววัดบน Pi โดยไม่ใช้โควตา · ผลไม่นับ)
