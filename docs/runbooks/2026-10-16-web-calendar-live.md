## เตรียมเครื่อง (ผู้ช่วย · ~15 นาที · ไม่แตะหน้าจอ)

1. ส่งสาขาบนสุด (`feature/0036-voice-site-search` · รวม 0014 0031–0038) ขึ้น Pi ด้วย git bundle
2. ติดตั้ง dependency 7 ตัวของ 0014 ใน venv ทดสอบ (`~/aipc-0025/.venv`) · รันเทสต์ทั้งชุดบน Pi → จดผ่าน/ล้ม/ข้าม
3. ชุด H เสียงสังเคราะห์ (120) กับ hotwords ใหม่ 18 คำ (0031 +7 · 0035 +5 · 0036 +6): `voice_h_eval --zip-only` →
   เกณฑ์ในการ์ด: ทำถูก ≥ 69 · ไม่ใช่คำสั่งแต่ทำ 0
4. `update-app.sh` แบบดูก่อน → บอกเลขรุ่น → **Pakon ตอบ "ใช่ ติดตั้ง <รุ่น>"** → `--apply` · จดรุ่นก่อนหน้า (ทางย้อนกลับ)
5. จดค่าก่อนเริ่ม: จำนวนงานของ AI ในเครื่อง (log llama-server) · จำนวนรายการ "สิ่งที่ส่งออก" ของบัญชีที่ทดสอบ
6. Pakon ออกจากระบบแล้วเข้าใหม่ (หรือผู้ช่วย restart หน้าเข้าสู่ระบบเมื่อไม่มีใครใช้จอ)

วิธีพูดทุกข้อ: Alt+Space → รอติ๊ก → พูด → รอติ๊กต่ำ · จด ✓ / ✗ (เครื่องทำอะไร) / "ครั้งที่ 2" ถ้าพูดซ้ำ
