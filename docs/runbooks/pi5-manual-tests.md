# ทดสอบระบบที่ต้องใช้มือกับตัวเครื่อง (T2 T5 T7 T9 T10 T13) · Pi 5

เตรียม 2026-09-30 (ผู้ช่วย) · ข้ออื่นใน T1–T14 ผู้ช่วยรันผ่าน SSH แล้ว ดู `docs/benchmarks/2026-09-30-systest-pi5/README.md` ·
เกณฑ์จาก[ขอบเขตรอบ 3 หัวข้อ 9](../reviews/2026-09-28-scope-cut.md) · จดผลในคอลัมน์สุดท้าย แล้วบอกผู้ช่วยให้บันทึกเป็นหลักฐาน

| # | ทำ | ผ่านเมื่อ | เวลา | ผล |
|---|---|---|---|---|
| **T2** ทางลัด | ที่หน้า Login กด Ctrl+Alt+Q · กด Ctrl+Alt+F1 · Alt+F4 | หน้า Login ไม่ปิด · F1 ไม่ได้ shell ที่ login ไว้ (tty1 ต้องถามรหัส) | 2 นาที | |
| **T5** ออฟไลน์ | ปิด hotspot/Wi-Fi → login ด้วยใบหน้า → เปิดยูทูบ (ต้องบอกว่าเปิดไม่ได้ ไม่ค้าง) → ถาม "ทำไมท้องฟ้าสีฟ้า" (AI ในเครื่องตอบได้) → ถาม "วันนี้อากาศเป็นไง" (ต้องบอกว่าไม่มีเน็ต/ไม่มีข้อมูลสด ไม่ค้าง) → จดนัด → ออก | ทุกข้อทำได้หรือบอกเหตุผลตรง ๆ · ไม่มีหน้าจอค้าง | 10 นาที | |
| **T7** AI พัง (ส่วนหน้าจอ) | login → ถามคำถามยาว ๆ เช่น "อธิบายภาวะโลกร้อนละเอียด ๆ" → ระหว่างกำลังตอบ บอกผู้ช่วยให้ `kill -9` llama-server ทาง SSH | คำตอบขึ้นหมายเหตุ "ตอบไม่จบ: AI หยุดทำงาน · ระบบกำลังเปิด AI ใหม่เอง" · แถบบนขึ้น "AI กำลังเริ่มใหม่…" · ภายใน 60 วิ กลับเป็น "โมเดล: พร้อม" แล้วถามต่อได้ (ส่วนเวลาผ่านแล้วทาง SSH: 13 วิ) | 5 นาที | |
| **T9** กล้องหลุด | หน้าสมัครขั้นใบหน้า หรือหน้าตั้งค่า "เข้าเครื่องด้วยใบหน้า" → กดเริ่มสแกน → ถอดสาย USB กล้องกลางคัน | บอก "ใช้กล้องไม่ได้" ภายในไม่กี่วินาที · ไม่บันทึกอะไร · หน้าจอไม่ค้าง · เสียบคืนแล้วลองใหม่ได้ | 5 นาที | |
| **T10** ไฟดับ | **ใช้การ์ดสำรองเท่านั้น** · ระหว่างรอ AI ตอบหรือกด "บันทึกนัด" ดึงปลั๊ก · ทำ 10 ครั้ง | บูตได้ 10/10 · แชท/นัดเดิมอ่านได้ (หายได้ไม่เกินข้อความล่าสุด) | 40 นาที | |
| **T13** ดิสก์เต็ม | **ใช้การ์ดสำรองเท่านั้น** · ผู้ช่วยเติมไฟล์จนเหลือ < 1% → จดนัด → ส่งแชท | บอกว่าบันทึกไม่สำเร็จ · ไม่พัง · ข้อมูลเดิมไม่เสีย | 15 นาที | |

**ก่อนทำ T10/T13:** ต้องมี microSD สำรองที่ทำ image จากการ์ดตัวจริงแล้ว (ขอบเขตรอบ 3 หัวข้อ 10 ข้อ 5) ·
การ์ดตัวจริงมีโมเดล ~13 GB และบัญชีทดสอบ อย่าทดลองดึงปลั๊กกับการ์ดนี้
