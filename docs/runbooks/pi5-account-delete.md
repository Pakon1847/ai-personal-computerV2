## เกณฑ์ผ่าน (ประกาศก่อนลอง · H9)

1. ใบยืนยันขึ้น "ลบแล้ว" ครบ 7 บรรทัด
2. ตรวจแยกเองด้วยคำสั่ง (ไม่เชื่อใบยืนยันอย่างเดียว): ไม่เหลือไฟล์ของเลขผู้ใช้เดิม
   `sudo find / -xdev -uid <UID> 2>/dev/null` ว่าง และ `/tmp` `/dev/shm` (คนละ filesystem) ก็ว่าง
3. ไม่มีบัญชีอื่นเสียหาย: ไฟล์ใบหน้าของคนอื่นใน `/var/lib/aipc-vision/face-login` ยังอยู่ · pakon1 เข้าเครื่องได้ตามเดิม
4. ปฏิเสธถูก: รหัสผิด · พิมพ์ยืนยันไม่ตรง · บัญชีที่ยังเข้าใช้อยู่ · บัญชีผู้ดูแล (aipc2030) → ไม่มีอะไรถูกลบ
5. สมัครบัญชีใหม่หลังลบ (ได้เลขผู้ใช้เดิม) → มองไม่เห็นไฟล์ใด ๆ ของบัญชีที่ลบไป

ไม่ผ่านข้อไหน = บันทึกตามจริงในหัวข้อผลด้านล่าง แล้วแก้ · ห้ามปรับเกณฑ์หลังเห็นผล

## ขั้นตอน (ทำเมื่อไม่มีใครใช้ที่จอ หรือใช้บัญชีทดสอบเท่านั้น)

1. หน้า Login › สมัคร: บัญชีทดสอบ `deltest` (ตั้ง PIN · ลงทะเบียนใบหน้าด้วย)
2. เข้า `deltest` · จดนัด 1 อัน · คุยกับ AI 1 ข้อความ · ถามอากาศ 1 ครั้ง · ออกจากระบบ
3. จดเลขผู้ใช้: `id -u deltest` → `<UID>` · วางไฟล์ค้าง: `sudo -u deltest touch /tmp/deltest-left /dev/shm/deltest-left`
4. ลองปฏิเสธ (เกณฑ์ข้อ 4): รหัสผิด · พิมพ์ยืนยันผิด · เข้า `deltest` ค้างไว้อีกจอแล้วลองลบ · ลอง `aipc2030`
5. หน้า Login › ลบบัญชี › `deltest` → ถ่ายรูปใบยืนยัน
6. ตรวจแยก (เกณฑ์ข้อ 2–3):
   ```
   getent passwd deltest; ls -ld /home/deltest
   sudo ls /var/lib/aipc/recovery /var/lib/aipc/password-checks /var/lib/aipc-vision/face-login
   sudo find / -xdev -uid <UID> 2>/dev/null; sudo find /tmp /dev/shm /var/tmp -uid <UID>
   journalctl -t aipc-accounts --since -10min
   ```
7. สมัคร `deltest2` แล้ว `id -u deltest2` · ถ้าได้ `<UID>` เดิม ตรวจว่าไม่มีไฟล์เก่าโผล่ (เกณฑ์ข้อ 5)
