# ทำ image การ์ด Pi 5 + การ์ดสำรอง + กู้คืน (2026-10-05)

ทำไม: [ขอบเขตรอบ 3 หัวข้อ 8 ข้อ 10](../reviews/2026-09-28-scope-cut.md) "กันวันสอบพัง" · audit 2026-09-30 data-1 (high) ·
T10 ไฟดับ และ T13 ดิสก์เต็ม **ต้องทำบนการ์ดสำรองเท่านั้น** ([pi5-manual-tests](pi5-manual-tests.md))

ข้อเท็จจริงของเครื่อง (ตรวจทาง SSH 2026-10-05): การ์ดจริง `mmcblk0` **58.2 GB** (ป้าย 64GB) · ใช้ไป 32 GB ·
ไดรฟ์ D: ของโน้ตบุ๊กว่าง 71 GB · บน Pi มี `piclone` แต่เป็นโปรแกรมหน้าจอเดสก์ท็อป (เซสชัน V2 ไม่มีเดสก์ท็อป) → ใช้วิธีอ่านการ์ดบนวินโดวส์

> **image มีทุกอย่างในการ์ด:** home ของทุกบัญชี · แชท · แม่แบบใบหน้า · การเข้าสู่ระบบ Claude ของ pakon1 · hash รหัสผ่าน/PIN ·
> เก็บไฟล์ .img ไว้ในเครื่องหรือ USB ของ Pakon เท่านั้น **ห้ามใส่ OneDrive/คลาวด์** (THREAT_MODEL T4)

## ต้องมี

- เครื่องอ่าน microSD สำหรับโน้ตบุ๊ก · การ์ดสำรอง **ขนาดจริงไม่เล็กกว่า 58.2 GB** (การ์ด "64GB" ต่างยี่ห้อขนาดไม่เท่ากัน ดูได้ในขั้น 4)
- โปรแกรมบนวินโดวส์: **Win32 Disk Imager** (อ่านการ์ดเป็น .img) และ **Raspberry Pi Imager** (เขียน .img ลงการ์ด · ตรวจซ้ำหลังเขียนให้เอง)
- เวลา ~1.5–2 ชม. (อ่าน 58 GB + เขียน 58 GB · ขึ้นกับความเร็วเครื่องอ่าน)

## กู้คืนวันสอบ (การ์ดจริงเสีย)

1. ปิดเครื่อง → ใส่การ์ดสำรอง (ถ้ายังไม่ได้ใช้ทดสอบ T10/T13) **หรือ** เขียน .img ลงการ์ดใหม่ตามขั้น 5 (~45–60 นาที)
2. เปิด → ตรวจตามขั้น 6–7
3. ข้อมูลที่เกิดหลังวันทำ image จะไม่มี (แชท/นัด/สกิลใหม่) → ทำ image ใหม่หลังทุกครั้งที่ติดตั้งรุ่นใหม่ก่อนวันสอบ

**หลังทดสอบ T10/T13 การ์ดสำรองอาจเสียหาย** → เขียน .img ทับใหม่ก่อนเก็บเป็นตัวสำรองวันสอบ
