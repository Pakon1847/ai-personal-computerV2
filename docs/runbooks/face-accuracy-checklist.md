## 0. ก่อนเริ่ม (เพิ่มหลังตรวจ)

- [ ] แก้ความร้อนของ Pi 5 ก่อน: 2026-09-30 ขึ้น 84–86°C ตอน AI ทำงาน แม้พัดลม 8,400 รอบ/นาที และถูกลดความเร็ว (`throttled=0xe0008`) ·
  ตรวจว่า Active Cooler กดแน่น แผ่นนำความร้อนแนบชิป ❌
- [ ] หนังสือยินยอมสำหรับคนที่มาช่วยทดสอบ (ข้อมูลชีวภาพ · พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล มาตรา 26 · BRIEF: เก็บแยกนอกเครื่องใช้งาน
  และกำหนดวันลบ) ต้องมีก่อนข้อ 6 ❌

## 1. อุปกรณ์และสถานที่

- [ ] กล้อง USB ความละเอียด 640×480 ขึ้นไป วางนิ่ง และเช็ดเลนส์ ⚠️ ยังไม่ได้ทดสอบกล้องกับ Pi 5
- [ ] กล้องอยู่ระดับสายตา ห่างหน้าประมาณ 40–70 ซม.
- [ ] แสงอยู่ด้านหน้า สม่ำเสมอ ไม่มีหน้าต่างหรือไฟอยู่ข้างหลัง และไม่มีเงาครึ่งหน้า
- [ ] ลงทะเบียนและสแกนที่จุดเดียวกัน แสงแบบเดียวกัน

## 2. ผู้ใช้ตอนลงทะเบียน

- [ ] ถอดหมวกและหน้ากาก ผมไม่ปิดตาและคิ้ว
- [ ] ถ้าใส่แว่นเป็นประจำ ให้ลงทะเบียนแบบใส่แว่น
- [ ] ทำหน้าปกติ ไม่ยิ้มกว้าง
- [ ] หันช้า ๆ และค้างแต่ละท่าสักครู่: ตรง ซ้าย ขวา เงย ก้ม ✅ แอปบอกทีละท่า ⚠️ ท่าก้มทำไม่สำเร็จ 4/6 ครั้งบน Pi 4
  ([ผล](../benchmarks/2026-09-24-card0010-pi4-live/README.md))
- [ ] กดยินยอมก่อนบันทึก ✅

## 3. ระบบคัดภาพก่อนใช้

- [ ] หน้าเล็กกว่า 112 px = ทิ้ง ✅
- [ ] ภาพเบลอ (ความคมต่ำกว่า 60) = ทิ้ง ✅ ⚠️ ค่านี้ยังไม่ได้ปรับตามกล้องจริง
- [ ] มืดเกิน (ต่ำกว่า 60) หรือสว่างเกิน (เกิน 200) = ทิ้ง ✅ ⚠️ ค่านี้ยังไม่ได้ปรับตามกล้องจริง
- [ ] กันรูปปลอม: MiniFASNet 2 ตัวต้องให้คะแนนหน้าจริง ≥ 0.8 ✅ ❌ ยังไม่มีตัวเลขว่ากันรูปพิมพ์หรือรูปบนจอได้จริงไหม ·
  **เขียนในเล่มว่า "กันการโจมตีแบบง่าย" เท่านั้น** (BRIEF) · การวัดตามมาตรฐาน (APCER) ต้องประเภทละ ≥ 60 ครั้ง
- [ ] จัดหน้าตรงจาก 5 จุด (ตา จมูก มุมปาก) ✅

## 4. การทำแม่แบบ

- [ ] เก็บเฉพาะเฟรมคุณภาพดีที่สุด ท่าละ 2 เฟรม ✅
- [ ] เฉลี่ยให้ทุกเฟรมมีน้ำหนักเท่ากัน แล้วเก็บ 128 ค่าชุดเดียว ✅ (ตอนนี้ใช้ 3 ท่า: ตรง ซ้าย ขวา)
- [ ] ไม่เก็บรูป · ไฟล์ตั้งสิทธิ์ 0600 · จด sha256 ของรุ่นโมเดล ✅
- [ ] ตัดสินว่าจะใช้ 3 ท่าหรือ 5 ท่าจากผลวัดจริง ❌ ยังไม่ได้รัน `python -m aipc.vision.camera compare`

## 5. ตอนสแกน

- [ ] ใช้หลายเฟรมแล้วเฉลี่ย ไม่ตัดสินจากภาพเดียว ✅
- [ ] คะแนนต้อง ≥ เกณฑ์ (0.363) ✅ ⚠️ เกณฑ์นี้มาจาก LFW ยังไม่ได้ปรับตามกล้องจริง
- [ ] ต้องห่างจากคนอันดับสองอย่างน้อย 0.05 ถ้าไม่ห่างพอให้ตอบว่า "ไม่แน่ใจ" ✅
- [ ] ไม่ผ่านต้องมีทางอื่นเสมอ (รหัสผ่านหรือ PIN) ✅
- [ ] เวลาสแกนบน Pi 5 ขณะ AI กำลังทำงาน ⚠️ ยังไม่ได้วัด · เกณฑ์ BRIEF: มัธยฐาน ≤ 1.5 วิ · p95 ≤ 3 วิ ·
  จดอุณหภูมิและ `get_throttled` ทุกรอบ (ความร้อนทำให้ช้าได้)

## 6. พิสูจน์ความแม่น (สิ่งที่ต้องทำก่อนเขียนในเล่มว่า "แม่นยำ")

- [x] ตัวจดจำหน้า: LFW ได้ 99.35% ✅ ผลนี้วัดแค่การจับคู่หน้า
- [ ] เทียบแม่แบบ 3 ท่ากับ 5 ท่า โดยสแกน 20 ครั้ง ❌
- [ ] ทดสอบกับคนจริง 5 คนขึ้นไป (ต้องมีหนังสือยินยอมตามข้อ 0) ❌ แบ่งหน้าที่ดังนี้:
  - **FAR (จำผิดคน):** อ้างจาก LFW คู่สุ่ม 120,000 คู่ = 0.1% ที่เกณฑ์ 0.365 ([ผล](../benchmarks/2026-09-24-face-lfw/README.md)) ·
    คน 5 คนพิสูจน์ ≤ 0.1% ไม่ได้ (ต้องลองคนผิด ~3,000 ครั้งโดยไม่พลาดเลย · "rule of 3": ผิด 0 ใน N ครั้ง → FAR ≤ 3/N ที่ 95%) ·
    จากคนจริงให้รายงานตามจริงว่า "จับผิดคน 0 จาก N ครั้ง"
  - **FRR (จำเจ้าของไม่ได้):** วัดจากคนจริง · ใช้ดูว่าเกณฑ์ 0.363 เข้มเกินกับกล้องจริงไหม
- [ ] ทดสอบกันรูปพิมพ์และรูปบนจอมือถือ ❌ (ทดลองเบื้องต้น · จดจำนวนครั้งตามจริง)
- [ ] เก็บ log มุมก้ม/เงยที่ทำได้จริง แล้วค่อยปรับเกณฑ์ 8° (`POSE_SPLIT_DEG`) ❌
- [ ] ใส่แว่นกับไม่ใส่ และแสงเช้ากับแสงเย็น ถ้าสแกนไม่ผ่านบ่อย ค่อยพิจารณาเก็บแม่แบบชุดที่สอง ❌

## ลำดับที่แนะนำ (ก่อนล็อกงาน 9 ต.ค.)

1. แก้ความร้อน → ทดสอบกล้องกับ Pi 5 (ข้อ 0, 1)
2. เก็บค่าจริงจากกล้อง (ความคม ความสว่าง มุมก้ม/เงย) + `camera compare` 3 vs 5 ท่าในรอบเดียว → ตั้งเกณฑ์ใหม่ (ข้อ 3, 4, 6)
3. ทำระบบสแกนหน้าที่หน้า Login + ลงทะเบียนตอนสมัคร (การ์ด 0015 · รอ Pakon ตอบคำถาม 2 ข้อ)
4. หนังสือยินยอม → ทดสอบกับคน 5 คน: FRR + เวลาสแกน (ข้อ 5, 6)
5. ทดลองกันรูปปลอมเบื้องต้น (ถ้ามีเวลา)
