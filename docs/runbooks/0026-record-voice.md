# อัดเสียงชุด D/H สำหรับการ์ด 0026 (Pakon ทำ · ~40–60 นาที · หยุดพักได้)

ทำไม: ตัวเลขเสียงทุกตัวที่มีตอนนี้มาจากเสียงสังเคราะห์ (Piper) · ต้องมีเสียงคนจริงถึงจะบอกได้ว่าระบบสั่งด้วยเสียงแม่นแค่ไหน ·
ยินยอมแล้ว 2026-10-14 (การ์ด 0026 หัวข้อ 5): เสียงเก็บนอก git · ใช้ทดสอบเท่านั้น · ลบหลังส่งเล่ม

## เตรียม

- **ไมค์ตัวที่จะใช้สาธิตกับ Pi** (ไมค์ USB) · ณ 2026-10-14 ตี 3 Pi ไม่มีไมค์เสียบอยู่ (`arecord -l` ว่าง) และเอกสารไม่ได้บันทึกรุ่นไว้ → เขียนรุ่นไมค์ลงท้ายไฟล์นี้ด้วย
- **แนะนำ: ถอดไมค์จาก Pi มาเสียบโน้ตบุ๊ก แล้วอัดใน Chrome บนโน้ตบุ๊ก** — ไมค์ตัวเดียวกัน · หน้าอัดปิดตัวช่วยของเบราว์เซอร์ (ตัดเสียงสะท้อน/ลดเสียงรบกวน/ปรับความดัง) จึงได้เสียงดิบแบบที่ Pi อัด ·
  ไม่ต้องย้ายไฟล์เสียงไปมาบน Pi ที่มีหลายบัญชี
- ห้องเงียบตามปกติที่จะสาธิต · นั่งห่างไมค์เท่าตอนใช้งานจริง (ระยะไมค์ชี้ขาดผล · ผล 2026-10-01)

## อัด

1. เปิด Chrome → ลากไฟล์ `docs/benchmarks/2026-10-14-voice-precise/record.html` ใส่หน้าต่าง (หน้าทำงานในเครื่อง ไม่ใช้เน็ต)
2. กด **"ขอใช้ไมค์"** → อนุญาต → เลือกไมค์ USB ในรายการ → **"เริ่มอัด"**
3. อ่านข้อความบนจอ → กด **Space** แล้วพูด → เงียบ 0.8 วิ หน้าหยุดเองและไปข้อถัดไป
   - ข้อแบบ "พูดด้วยคำของตัวเอง" = พูดแบบที่คุณจะพูดจริง ไม่ต้องตรงตัวอักษร
   - เตือน "ดังจนแตก" / "ไม่ได้ยินเสียงพูด" → กด ← แล้วอัดข้อนั้นใหม่
   - ปิดหน้าแล้วเปิดใหม่ได้ ข้อที่อัดแล้วยังอยู่ (เก็บในเบราว์เซอร์)
4. ครบ 180 ข้อ (D 60 + H 120 · ลำดับสุ่มแต่คงที่) → กด **"ส่งออก"** → ได้ไฟล์ `voice-pakon-YYYY-MM-DD.json` ใน Downloads
5. บอกผู้ช่วย · **อย่าใส่ไฟล์นี้ใน git**

ตรวจหน้าอัดแล้ว 2026-10-14 ด้วยไมค์ปลอมบน Pi 5 (`aipc.spikes.voice_record_check` · หยุดเองเมื่อเงียบ · ไปข้อถัดไปเอง · ส่งออก WAV 16 kHz ถอดกลับได้ตรงเสียงต้นฉบับ) ·
ยังไม่เคยลองกับไมค์จริง

## หลังอัด (ผู้ช่วยทำ)

```bash
python -m aipc.spikes.voice_real_unpack voice-pakon-….json ~/voice-data --sets D   # แกะเฉพาะ D (ใช้ปรับได้)
# ปรับ/เลือกด้วย D → ล็อกระบบ (commit) → แล้วค่อยแกะ H และรันครั้งเดียว
python -m aipc.spikes.voice_real_unpack voice-pakon-….json ~/voice-data --sets H
```

เสียงอยู่ที่ `~/voice-data` (0700) บนโน้ตบุ๊กและ Pi · **ลบทั้งหมดหลังส่งเล่ม** (ไฟล์ส่งออก · ~/voice-data · ข้อมูลในเบราว์เซอร์: เปิดหน้าอัด → ล้างข้อมูลเว็บไซต์)
