# เช็กลิสต์ทดสอบที่ค้าง (ต้องมีคนอยู่หน้าจอ Pi 5) · ~45 นาที

เตรียม 2026-10-14 (ผู้ช่วย · Pakon เลือก "ทำเช็กลิสต์สั้น") · ทำตามลำดับ (เรียงให้ไม่ต้องสลับบัญชี/สายไปมา) ·
แต่ละข้อจด **ผ่าน / ไม่ผ่าน + สิ่งที่เห็น** ในช่องผล แล้วส่งรูปหรือข้อความให้ผู้ช่วยบันทึกเป็นหลักฐาน ·
ผู้ช่วยดู log ทาง SSH ให้เองหลังแต่ละช่วง (ไม่ต้องพิมพ์คำสั่ง) · ข้อที่ไม่ได้ทำ = เขียนในเล่มว่า "ไม่ได้ทดสอบ" ไม่ใช่ "ผ่าน"

**ก่อนเริ่ม:** ต่อ hotspot · กล้อง USB เสียบอยู่ · ให้เครื่องเย็น (แถบบน < 70°C) · บอกผู้ช่วยว่าจะเริ่ม (ผู้ช่วยจะไม่ restart อะไรระหว่างนี้)
