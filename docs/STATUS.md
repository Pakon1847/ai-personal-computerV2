# สถานะ

**ไฟล์นี้คือที่เดียวที่บอกสถานะ** · ระดับหลักฐานตาม [BRIEF หัวข้อ 9](BRIEF.md#9-การทดสอบและระดับหลักฐาน)

| ระดับ | ความหมาย | หลักฐานขั้นต่ำ |
|---|---|---|
| 0 | ยังไม่ทำ | — |
| 1 | ออกแบบแล้ว | ลิงก์ spec หรือ ADR |
| 2 | ต้นแบบ | commit + วิธีรัน |
| 3 | ผ่านบนเครื่องพัฒนา | ผลเทสต์ + commit |
| 4 | ยืนยันบน Pi 5 | รายงานใน `docs/benchmarks/` (วันที่, commit, ฮาร์ดแวร์, ค่าดิบ) |
| 5 | ผ่าน pilot | รายงาน pilot |

กฎ: ระดับ ≥ 3 ต้องมีลิงก์หลักฐานที่มีไฟล์อยู่จริง · โค้ดส่วนนั้นเปลี่ยน → หลักฐานต้องตรวจซ้ำ · ผลบน Pi 4 เขียนกำกับว่า "(Pi 4)" และไม่นับเป็นระดับ 4

อัปเดตล่าสุด: 2026-09-24 (ดึก, เอกสารตามโค้ด `14f6bed`) · เฟสปัจจุบัน: **0**
