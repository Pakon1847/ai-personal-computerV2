## วิธีนับ (ล็อกก่อนรัน · `aipc.spikes.voice_h_eval.judge`)

| ผล | ความหมาย |
|---|---|
| ok | ชนิดและค่าตรงทุกคำสั่ง · ค้นหา = คำค้นมีคำใน `has` ครบ (ไม่สนวรรค) |
| wrong | ทำคำสั่ง แต่ผิดชนิดหรือผิดค่า · **คำค้นไม่มีคำหลัก = ผิดค่า** (นับเข้มงวด · แสดงแยกเป็น "ผิดแค่คำค้น") |
| miss | ประโยคคำสั่งแต่ไม่ทำ (ไปแชท) |
| neg_do | ไม่ใช่คำสั่งแต่ทำ |

เวลา = จากส่งไฟล์เสียงถึงได้ข้อความ (ตัวแปลแบบกฎใช้เวลาไม่ถึง 1 ms) · ไม่รวมรอเงียบ 1 วิ · ตัวถอดอุ่นแล้ว (เหมือนกดคีย์ลัดแล้วพูด)

## เกณฑ์ (การ์ด 0026 หัวข้อ 8 · Pakon อนุมัติ 2026-10-14)

1. wrong ≤ 2 จาก 120 · neg_do ≤ 1
2. ok ≥ 90% ของ 80 ประโยคคำสั่ง (≥ 72)
3. เวลา median ≤ 1.5 วิ · p90 ≤ 2.5 วิ
4. ไม่แย่กว่า whisper: (wrong + neg_do) ไม่มากกว่า และ ok ไม่น้อยกว่า
5. เทสต์ทั้งชุดผ่าน (วินโดวส์ + Pi) · ตัวถอดอยู่ในกล่องตัดเน็ต · คีย์ลัดทั้งสองปุ่มใช้ได้ (Pakon ลองที่หน้าจอ)

รันครั้งเดียวต่อรุ่น · ไม่ผ่าน = บันทึกตามจริง ไม่แก้แล้วรันซ้ำบน H

### ข้อที่ Zipformer พลาด 18 ข้อ แยกตามสาเหตุ

| สาเหตุ | จำนวน | ข้อ (พูด → ได้ยิน) |
