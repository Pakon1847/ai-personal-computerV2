# กฎคำสำคัญ "ถามสถานะเครื่อง" ก่อนถึง AI · ไม่ผ่าน ไม่ได้ใช้ · 2026-10-01

ที่มา: ชุดเลือกสกิล 58 ข้อบน Pi 5 · Gemma ตอบเอง 3 ข้อที่ควรอ่านค่าจริงของเครื่อง ("คอมหน่วงมาก เป็นอะไร") = เดาค่า

ลอง: กฎ `machine_intent` (อาการ ช้า/ร้อน/ค้าง + คำว่าเครื่อง/คอม/ระบบ · หรือ แรม/พื้นที่/ดิสก์ + เป็นคำถาม · ไม่นับคำถามความรู้/อากาศ/รถติด)
ปรับด้วยชุดพัฒนาที่ผู้ช่วยเขียนเอง (ผ่าน 9/9 · หลอก 0/11) แล้ววัดครั้งเดียวกับชุดอิสระที่ Claude เขียน (`tests/data/machine_status_heldout.json` · commit ก่อนเขียนกฎ)

| เกณฑ์ (ประกาศก่อนวัด) | ผล |
|---|---|
| คำถามเรื่องเครื่อง จับได้ ≥ 80% | **12/20 (60%)** ✕ |
| ประโยคหลอก จับผิด ≤ 5% | **3/20 (15%)** ✕ (แรมของ iPhone · พื้นที่ในห้องนอน · คอมพิวเตอร์ควอนตัมร้อนไหม) |
| ชุดเดิมไม่เสีย | ✕ ชุดสอบจบ: "CPU ย่อมาจากอะไร" "RAM ต่างจาก SSD ยังไง" "ประเทศไทยมีพื้นที่กี่ ตร.กม." ถูกส่งไปสกิลสถานะเครื่อง |

พลาด เช่น "สถานะเครื่องตอนนี้เป็นไงบ้าง" "ดิสก์เต็มรึยัง" "เมื่อกี้เครื่องแฮงค์ไปพักนึง" "โปรแกรมอะไรกินทรัพยากรเยอะสุด"

**สรุป:** กฎคำสำคัญแยกเรื่องนี้ไม่ได้ (คำเดียวกันใช้ได้หลายความหมาย) → ถอดออก ไม่มีในแอป ·
ทางต่อไปที่ต้องวัดกับ AI จริง: ปรับคำอธิบายสกิลสถานะเครื่อง (ชุดพัฒนาแยก) แล้ววัดชุดนี้กับ Gemma บน Pi
