## วิธีนับ

| ผล | นิยาม |
|---|---|
| same | ทางเดียวกับแอปเดิม |
| intended | ตั้งใจเปลี่ยนตามการ์ด: chat → unknown/needs_browser · command (เปิดเบราว์เซอร์) → open_browser |
| **new_action** (อันตราย) | เดิมไม่ทำอะไรกับเครื่อง ตอนนี้ทำ (browser/open_browser/command) |
| lost (ไม่ทำ · ปลอดภัย) | เดิมทำ ตอนนี้ไม่ทำ |
| changed | เปลี่ยนแบบอื่น (เช่น command → browser) |
