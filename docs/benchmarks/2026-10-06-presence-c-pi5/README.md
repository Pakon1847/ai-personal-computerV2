## ข้อจำกัด (เขียนในเล่ม)

- **ใช้เครื่องอื่นข้าง Pi (หันหน้าออกจากกล้อง) = ถูกล็อกและออก** ภายใน ~70 วิ
- ตอนลุก หน้าเอียงอาจถูกนับเป็น "คนอื่น" → เหตุผลบนจอผิด (ผลยังเป็นล็อก)
- เจ้าของถูกบังบางส่วน + มีหน้าอื่น → ความคล้ายใกล้เกณฑ์ (0.32–0.36) · ทดสอบ 1 คน 1 รูป 1 สภาพแสง → ไม่ใช่ตัวเลขทั่วไป
- เกณฑ์ M3 (ขั้น B) ยังไม่ผ่าน → คงกฎ "เห็นคนอื่น = ล็อกอย่างเดียว · ออกเมื่อไม่มีใครต่อเนื่องเท่านั้น"
- ปลดล็อกด้วยรหัสผ่านเท่านั้น (การ์ด 0015) · เปิดเองต่อบัญชี (ค่าเริ่มต้นปิด) · ต้องมี "ใบหน้าของฉัน"
