# สกิลในตัวของระบบ (สำหรับผู้เขียนชุดประโยคทดสอบ · ข้อมูลเดียวกับที่ผู้ใช้เห็นในหน้า Skill)

ระบบ: ผู้ช่วย AI ภาษาไทยบน Raspberry Pi 5 · ผู้ใช้พิมพ์ (หรือพูด) ข้อความภาษาไทยในช่องแชท ·
ระบบตัดสินว่าข้อความนี้ควรใช้สกิลไหน หรือ "ไม่ใช้สกิล" (= ให้ AI คุยตอบตามปกติ)

| id | ชื่อ | คำอธิบาย |
|---|---|---|
| translate | แปลไทย–อังกฤษ | แปลคำ ประโยค หรือย่อหน้า ไทย↔อังกฤษ ตอบเฉพาะคำแปล · ไม่ใช้สรุปความ ไม่ร่างจดหมาย ไม่สอนไวยากรณ์ และไม่แปลภาษาอื่น |
| summarize-text | สรุปข้อความ | สรุปข้อความยาวที่ผู้ใช้วางมา (ข่าว ประกาศ อีเมล บทความ) ให้เหลือใจความสำคัญเป็นข้อ ๆ ภาษาไทย · ไม่ใช้เมื่อไม่มีข้อความให้สรุป ไม่ใช้แปลภาษา และไม่ใช้ร่างจดหมาย |
| letter-writer | ร่างจดหมายสุภาพ | ร่างจดหมาย/อีเมลภาษาไทยแบบสุภาพ เช่น ลาป่วย ลากิจ ขอเลื่อนส่งงาน ขอบคุณ ถึงอาจารย์ หัวหน้า ลูกค้า · ไม่ส่งอีเมลให้ · ไม่ใช้เมื่อจะจดนัด สรุป หรือแปลข้อความ |
| machine-status | ตรวจอาการเครื่อง | อ่านค่าจริงของเครื่อง (อุณหภูมิ แรม พื้นที่เก็บข้อมูล ไฟเลี้ยง พัดลม เครือข่าย) แล้วบอกเป็นภาษาคนพร้อมวิธีแก้ · ไม่ใช่การเปิดหน้าสุขภาพเครื่อง ไม่แก้ให้เอง ไม่ตรวจอุปกรณ์อื่น |
| reminder | นัดหมายและเตือนความจำ | บันทึกนัดหรือตั้งเตือนจากประโยคไทย เช่น พรุ่งนี้บ่ายสอง วันศุกร์ อีก 10 นาที ถามยืนยันก่อนบันทึก แล้วเตือนเมื่อถึงเวลา · ไม่ใช้ร่างจดหมาย ไม่ใช่ดูสรุปนัดที่มีอยู่ ไม่เปิดปฏิทินบนเว็บ |
| system-command | เปิดแอปและปรับเสียง | เปิดเว็บ แอป หรือหน้าในระบบที่อยู่ในรายการ และปรับ เพิ่ม ลด ปิด เปิดเสียง · ไม่ใช้ตอบคำถาม ค้นข้อมูล ดูสถานะเครื่อง หรือเปิดสิ่งที่ไม่อยู่ในรายการ |
| none | ไม่ใช้สกิล | คุยทั่วไป ถามความรู้ ขอคำแนะนำ ฯลฯ ที่ไม่ตรงกับสกิลข้างบน → AI ตอบเอง |

สิ่งที่ `system-command` เปิดได้ (รายการ): เว็บ YouTube · Gmail · Google · วิกิพีเดีย · Google Maps · Google Calendar · Google Drive · Google Docs · ข่าว ·
