# ด่านกันสกิลไม่ดี · ขั้น 0 (การ์ด 0074) · **สถานะ: ประกาศก่อนรัน** (2026-11-05 · ผลจะเติมด้านล่างโดยไม่แก้ส่วนนี้)

การ์ด: [0074](../../design/0074-skill-guard.md) · ที่มา: คำแนะนำอาจารย์และกรรมการข้อ 10 ([บันทึก](../../reviews/2026-11-05-committee-advice.md))

## คำถาม

- **S1** ด่านตรวจสกิลที่มีอยู่ (ทางปุ่มนำเข้าสกิลจากไฟล์ = ทางที่สกิลจากคนอื่นจะเข้ามา) กันสกิลเสียที่คนอื่นเขียนได้แค่ไหน และปฏิเสธสกิลดีผิดกี่ตัว
- **S2a** เมื่อผู้ใช้มีสกิลของตัวเอง 0 / 20 / 50 ตัว ระบบยังเลือกสกิลในตัวถูกเท่าเดิมไหม
- **S2b** เมื่อมี 50 ตัว สกิลของผู้ใช้ถูกเลือกเจอไหม

ขั้น 0 = วัดของเดิมก่อนเขียนโค้ด · ไม่มีเกณฑ์ผ่าน/ไม่ผ่าน (การ์ดหัวข้อ 11) · ผลใช้ตัดสินว่าต้องแก้ช่องไหน

## วิธีนับ (นิยามก่อนรัน)

**S1**

| ผล | นิยาม |
|---|---|
| สกิลเสียหลุด | ป้าย `bad` และตัวตรวจยอม (ติดตั้งได้) |
| สกิลดีถูกปฏิเสธผิด | ป้าย `good` และตัวตรวจไม่ยอม |

- รายงานแยกหมวด A B C และชนิด steps / prompt / site · จดเหตุผลที่ตัวตรวจให้ทุกข้อ
- ป้ายของผู้เขียน = เฉลย · ถ้าผู้วัดเห็นว่าป้ายข้อไหนผิด (เช่น "เสีย" แต่ไม่เสียจริง หรือ "ดี" แต่ผิดกติกาในเอกสาร) → **ไม่แก้ตัวเลข** · เขียนเป็นข้อสังเกตแยก
- สกิลเสียที่หลุด: วิเคราะห์ต่อว่าชั้นอื่นตอนใช้งานกันได้ไหม (เช่น prompt ไม่มีเครื่องมือ · ขั้นที่สั่งเครื่องถามยืนยัน) · เป็นการวิเคราะห์ ไม่ใช่ตัวเลขที่วัด

**S2**

| ผล | นิยาม |
|---|---|
| ถูก (top-1) | สกิลที่ระบบเลือก (กฎ หรือเครื่องมือที่ AI เรียก) = `expect` · AI เรียกชื่อที่ไม่อยู่ในรายการ = ไม่ใช้สกิล (แบบแอป) |
| เรียกสกิลทั้งที่ไม่ควร | `expect = none` แต่ระบบเลือกสกิล |
| ไปสกิลผู้ใช้ (S2a) | ระบบเลือกสกิลผู้ใช้ ทั้งที่ประโยคเป็นของสกิลในตัวหรือไม่ใช้สกิล · นับเป็นผิด และรายงานจำนวนแยก |

- รายงานทุกรอบ + ค่าเฉลี่ย 3 รอบ · แยกตาม `kind` (ตรง · อ้อม · คุยทั่วไป · กับดัก)
- **ผล S2a ตอน 0 ตัว = ค่าเกณฑ์ top-1 ที่จะกรอกใน BRIEF 5.8** ("ไม่แย่กว่าเดิม" · Pakon ตกลง 2026-11-05)
- ถ้าการ์ด 0074 **ไม่แก้** ทางเลือกสกิลหลังขั้นนี้ → ผล S2 ขั้น 0 ใช้เป็นผล G5/G6 ได้ (ชุดไม่ได้ใช้ปรับอะไร) · ถ้าแก้ → ต้องชุดอิสระรอบ 2
