# ความจำผู้ใช้ · R2 ความเร็วค้น 100,000 ข้อ (การ์ด 0079)

- **เครื่อง:** Pi 5 8GB (`ai-pc`) · บัญชี aipc2030 · 2026-11-07 · โค้ด `aipc.chat.memory` + `aipc.spikes.memory_bench` จากสาขา `feature/0079-user-memory` (คัดลอกแค่ 2 ไฟล์ไปโฟลเดอร์ชั่วคราว · ไม่ได้ติดตั้ง · ฐานข้อมูลชั่วคราว ไม่แตะความจำจริง)
- **อุณหภูมิ:** ก่อน 59.8°C → หลัง 68.6°C · `get_throttled` = `0xe0000` ทั้งก่อนและหลัง (เคยถูกลดความเร็วตั้งแต่บูต · ตอนวัดไม่ได้ถูกลดอยู่)
- **ข้อมูล:** ข้อความสังเคราะห์ 100,000 ข้อ สุ่มจากคำไทย ~70 คำ (seed 7) · คำถาม 8 แบบ วน 200 ครั้ง
- **ทำซ้ำ:** `python3 -m aipc.spikes.memory_bench --n 100000`

**สาเหตุที่คาด (ยังไม่ได้พิสูจน์):** ข้อมูลสังเคราะห์มีคำแค่ ~70 คำ ชิ้น 2 ตัวอักษรทุกชิ้นจึงอยู่ในหลายพันข้อ ฐานข้อมูลต้องให้คะแนน (bm25) เกือบทั้งฐาน ·
ลองแก้ 1 ครั้ง: หาผู้สมัครด้วยชิ้นที่หายากที่สุด 8 ชิ้น → บนโน้ตบุ๊กที่ 20,000 ข้อ 11.1 → 11.5 ms (ไม่ดีขึ้น เพราะชิ้นที่หายากที่สุดก็ยังมีในหลายพันข้อ) → ย้อนการแก้ ไม่ใส่ในโค้ด ·
ข้อมูลจริงของผู้ใช้น่าจะมีคำหลากหลายกว่านี้มาก แต่**ยังไม่มีหลักฐาน** จึงรายงานว่าไม่ผ่านตามเกณฑ์ที่ตั้งไว้
