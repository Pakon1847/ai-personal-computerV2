## ทำอะไร

ป้ายใหม่ในแถบบน (ทุกหน้าในเซสชัน · หน้า Login ไม่มี) แสดงค่าจริงจากเครื่อง:

| ส่วน | อ่านจาก | แสดง |
|---|---|---|
| AI ในเครื่อง | `systemctl --user show aipc-llm -p MainPID` → `/proc/<pid>/status` (`Seccomp: 2`) และ `/proc/<pid>/ns/net` ต่างจากของหน้าจอ | ล็อกครบ 2 ชั้น = "AI ในเครื่อง: ต่อเน็ตไม่ได้" · ไม่ครบ = "AI ในเครื่อง: ไม่ได้ล็อกเน็ต" (เตือน) · อ่านไม่ได้ = ไม่แสดงส่วนนี้ (ไม่เดา · H5) |
| ข้อมูลที่ออกวันนี้ | `outbound.json` (บันทึกส่งออกตัวเดิม) · นับรายการของวันนี้ | "ส่งออกวันนี้ N ครั้ง" · **ป้ายเปลี่ยนสีราว 3 วิ ทุกครั้งที่มีรายการใหม่** |
| ปิดทั้งหมด | สวิตช์ Claude + สวิตช์อากาศ (ใหม่) | ปิดทั้งสอง = "ส่งออก: ปิดทั้งหมด" |

- แตะป้าย = ไปหน้าตั้งค่า (มีรายการสิ่งที่ส่งออกตามตัวอักษรอยู่แล้ว)
- **สวิตช์อากาศ** (ใหม่ · ค่าเริ่มต้นเปิดเหมือนเดิม): ปิด = ถามอากาศแล้วไม่ส่งชื่อเมืองไป Open-Meteo · บอกตรง ๆ ว่าปิดอยู่และเปิดได้ที่ไหน · ไม่ส่งต่อไปทางอื่นแทน
- อ่านบันทึกส่งออกทุก 2 วิ (ดูแค่เวลาแก้ไฟล์ · อ่านเมื่อเปลี่ยน) · อ่านสถานะ AI ทุก 15 วิ

- ป้ายบอกสถานะของ AI ในเครื่องกับทาง 3 ทางที่ประกาศเท่านั้น · การเชื่อมต่ออื่นของตัว Claude Code ไม่อยู่ในตัวนับ (วัดแยกใน T6 แบบใหม่)
