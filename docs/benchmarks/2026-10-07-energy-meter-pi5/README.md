ที่มา: Pakon เลือกข้อ ค (2026-10-07) · ต่อจาก[ผลวัดพลังงาน 2026-10-01](../2026-10-01-energy-pi5/README.md) (ตอบ 1 ข้อ ≈ 187 J เพิ่มจากตอนว่าง) ·
ใช้ตัวอ่านเดิม `aipc.bench.energy.read` (`vcgencmd pmic_read_adc` · ผลรวม V×I ทุกรางบนบอร์ด) · ลองแล้ว: บัญชีผู้ใช้ทั่วไป (`pakon`) อ่านได้โดยไม่ต้องใช้ root

## ทำอะไร

- ระหว่าง AI **ในเครื่อง**ตอบ: อ่านวัตต์บนบอร์ด **ทุก 1 วิ** ในเธรดแยก · จบคำตอบ → พลังงาน = พื้นที่ใต้กราฟ (สี่เหลี่ยมคางหมู) · ระยะเวลา · วัตต์เฉลี่ย
- แสดงใต้คำตอบ (ในช่อง "ทำไมได้คำตอบนี้"): "ไฟที่บอร์ดใช้ระหว่างตอบ ≈ X J (Y วิ · เฉลี่ย Z W · ไม่รวมอะแดปเตอร์)"
- **ไม่แสดง** เมื่อ: ไม่ใช่ Pi 5 / อ่านค่าไม่ได้ / ได้ค่าน้อยกว่า 2 ครั้ง / คำตอบจาก Claude (ไฟของเครื่องเราไม่ใช่พลังงานของคำตอบนั้น) / คำตอบจากสกิลที่ไม่ใช้ AI
- เป็นพลังงาน**ทั้งบอร์ด**ระหว่างตอบ (รวมตอนว่างของเครื่อง) · ไม่ใช้สูตรแก้ของผู้อื่น · ไม่เทียบกับ Cloud (ไม่มีตัวเลขที่ตรวจได้)
