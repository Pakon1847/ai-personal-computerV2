## ข้อควรระวัง (ต้องเขียนในเล่มพร้อมตัวเลข)

1. **เทียบกับตัวเลข LFW ที่ตีพิมพ์ไม่ได้** — ตัวเลขที่เทียบได้อยู่ที่ [LFW มาตรฐาน 6,000 คู่: 99.35%](../2026-09-24-face-lfw-standard/README.md) · · งานตีพิมพ์ใช้ชุด 6,000 คู่มาตรฐาน (pairs.txt, 10-fold) · ที่นี่สุ่มคู่เอง
   คู่ impostor ที่สุ่มข้ามคนส่วนใหญ่ "ต่างกันง่าย" (คนละเพศ/วัย) จึงให้ FAR ต่ำกว่าชุดมาตรฐาน
2. **คนใน LFW อาจอยู่ในชุดที่ใช้ฝึก SFace** (ชุดฝึกขนาดใหญ่มักมีคนดัง) → ตัวเลขอาจดีเกินจริง · ไม่ได้ตรวจการซ้อนกัน
3. **ภาพ LFW ไม่เหมือนภาพจากกล้อง USB บน Pi** (แสง มุม ความคมต่างกัน) · ตัวเลขนี้วัดแค่ "โมเดลแยกคนได้ดีแค่ไหน"
   ผลของทั้งระบบต้องวัดชั้นที่ 2: คนจริง ≥ 5 คน × ≥ 50 ครั้ง บนกล้องจริง Pi 5 (ตามตาราง BRIEF) พร้อมหนังสือยินยอม
4. genuine สุ่มจากทุกคู่ของคนเดียวกัน → คนที่มีภาพมาก (เช่น George W. Bush 530 ภาพ) มีน้ำหนักมาก
5. FAR ที่วัดได้ละเอียดสุด = 1/100,000 = 1e-5 · ช่วงต่ำกว่านั้นในกราฟไม่มีความหมาย

**ข้อสรุปที่ใช้ต่อได้:** threshold 0.363 ของ OpenCV (ค่าใน config ตอนนี้) อยู่ใกล้จุด FAR 0.1% บนข้อมูลนี้ →
ใช้เป็นจุดเริ่มต่อได้ แต่ต้อง calibrate ใหม่จากข้อมูลคนจริงบนกล้องจริง (ชั้นที่ 2)

## ทำซ้ำ

```bash
curl -L -o lfw.tgz https://ndownloader.figshare.com/files/5976018   # sha256 055f7d9c…8d536c0
tar -xzf lfw.tgz                                                     # เก็บนอก repo (BRIEF: ข้อมูลทดสอบแยกไว้)
python -m aipc.vision.models fetch
python -m aipc.vision.evaluate lfw --pick centre --out <โฟลเดอร์> --plot-title "LFW all, random pairs (seed 0), centre face"
```

LFW (Labeled Faces in the Wild, UMass Amherst) ใช้ในงานศึกษา · ภาพไม่ได้อยู่ใน repo มีแค่ชื่อไฟล์และคะแนน
