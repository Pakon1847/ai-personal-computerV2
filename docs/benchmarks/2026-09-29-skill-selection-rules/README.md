## ข้อสังเกต

- กฎรับประโยคพูดอ้อมได้ 2/16 และประโยคหลอก 0/6 → เหตุผลที่ต้องมีชั้น AI เลือกสกิล (ความต้องการของอาจารย์)

  **ไม่ได้แก้กฎจากชุดนี้** เพราะชุดนี้ใช้วัด ถ้าจะแก้ต้องมีเหตุผลทั่วไปและรายงานผลก่อน/หลังแยกไว้
