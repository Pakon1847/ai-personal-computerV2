## W1 · Claude เขียนสกิล

("เล่นต่อ" ตอนเล่นอยู่ = หยุด) → **เปลี่ยนลำดับจากการ์ด:** คำสั่งของระบบมาก่อน (คำเดียวกันทำแบบเดิมทุกเว็บ · ของเดิมไม่เปลี่ยน) ·
สกิลประจำเว็บมาก่อนทางที่ AI เดา (นัด · งานภาษา) · ผล: คำพูด 68/90 ถึงสกิล · 22 ระบบเดิมทำแทน (ทำงานเทียบเท่า ยกเว้น "เดินหน้าหน่อย" = ไปหน้าถัดไปของเบราว์เซอร์ ไม่ใช่ข้าม 10 วิ)

## ข้อจำกัด

- เสียงสังเคราะห์ ไม่ใช่เสียงคน · ไม่ได้ล็อกอิน (ไลก์/Spotify ยังไม่ได้วัด) · คลิปเดียวต่อรอบ
- คีย์ `k` / `Space` เป็นปุ่มสลับ: "หยุดก่อน" ตอนหยุดอยู่แล้ว = เล่นต่อ (คำพูดหลักของหยุด/เล่น ระบบเดิมรับไปและไม่สลับ)
- ตัวเลือกปุ่มผูกกับหน้าตาเว็บตอนนี้ · เว็บเปลี่ยน = หาไม่เจอ แล้วบอกตามจริง ไม่กดอย่างอื่นแทน
