## T12 สองบัญชี · ผ่าน 14/14

สร้าง `t12a` และ `t12b` ผ่านตัวช่วยสมัครจริง (`sudo -u _greetd sudo -n /usr/local/sbin/aipc-accounts` = ทางเดียวกับหน้าสมัคร) ·
home ทั้งคู่ `drwx------` · ไม่อยู่กลุ่ม sudo (กลุ่ม: ตัวเอง, audio, video, render) ·
ใส่แชท นัด และแม่แบบใบหน้าตัวอย่างใน home ของ `t12b` แล้วให้ `t12a` ลอง:

| ลอง | ผล |
|---|---|
| อ่านแชท · ดูรายชื่อไฟล์ใน home · อ่านนัด · อ่านแม่แบบใบหน้าในเซสชัน | ทำไม่ได้ ✅ |
| เขียนไฟล์ลง home · ลบแชท | ทำไม่ได้ ✅ (แชทของ t12b ยังอยู่ครบ) |
| อ่านแม่แบบใบหน้าของหน้า Login (`/var/lib/aipc-vision`) · อ่านที่เก็บ PIN (`/var/lib/aipc/recovery`) | ทำไม่ได้ ✅ |
| `sudo -n true` · เรียกตัวช่วยบัญชีเอง | ทำไม่ได้ ✅ |
| ต่อ socket ตั๋วใบหน้าของ root | Permission denied ✅ |
| ปิดใบหน้าของ t12b ผ่าน visiond **แม้รู้รหัสผ่านของ t12b** | ปฏิเสธ ("ทำได้เฉพาะบัญชีของตัวเอง") ✅ |
| สั่ง visiond สแกนหน้า | ปฏิเสธ (เฉพาะหน้า Login) ✅ |
| เข้า `/run/user/1003` (socket AI ของ t12b) | ทำไม่ได้ ⚠️ **แต่ตอนทดสอบ t12b ไม่ได้ login จึงไม่มีโฟลเดอร์นี้** → ต้องทดสอบซ้ำตอน t12b login อยู่ |

สคริปต์: ผู้ช่วยรันจาก `/tmp/t12.sh` (เนื้อเดียวกับตารางนี้) · บัญชีทดสอบ t12a/t12b ยังอยู่ (ลบได้ด้วย `sudo userdel -r`)
