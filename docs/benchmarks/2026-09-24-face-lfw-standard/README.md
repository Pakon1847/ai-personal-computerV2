## วิธีวัด (เขียนในเล่มได้ตรง ๆ)

1. ตรวจหน้าด้วย YuNet บนภาพ LFW 250×250 เต็มภาพ · ภาพที่มีหลายหน้า **เลือกหน้าที่ใกล้กลางภาพที่สุด**
   (LFW ตั้งคนที่ติดป้ายชื่อไว้กลางภาพ) · ถ้าเลือกหน้าใหญ่สุดแทน ได้ 98.93% ± 0.42% เพราะ 37 ภาพเลือกผิดคน
2. align 5 จุด → 112×112 → SFace → L2-normalize → cosine
3. ทีละ fold: หา threshold ที่ถูกมากสุดจาก 9 fold ที่เหลือ แล้ววัดความถูกต้องกับ fold นั้น · รายงานค่าเฉลี่ยและ SD
4. ภาพที่หาหน้าไม่เจอ → คะแนน −1 (ไม่ตัดทิ้ง) · รอบนี้ไม่มี

## ข้อควรระวัง

- คนใน LFW อาจอยู่ในชุดที่ใช้ฝึก SFace → อาจดีเกินจริง (ข้อจำกัดเดียวกับทุกงานที่รายงาน LFW)
- ภาพ LFW ≠ ภาพกล้อง USB บน Pi · ความแม่นยำของทั้งระบบต้องวัดกับคนจริง (ชั้นที่ 2)
- threshold ที่ LFW เลือก (~0.31) ต่ำกว่าค่าใน config (0.363) เพราะ LFW ถ่วงคู่ genuine/impostor เท่ากันและนับถูก/ผิดเท่ากัน ·
  ระบบ Login ให้ความสำคัญกับ FAR มากกว่า → ใช้จุด FAR 0.1% (0.365 จากชุดคู่สุ่ม) ไม่ใช้จุดนี้
