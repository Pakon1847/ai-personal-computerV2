  เมื่อเชื่อมต่อปฏิทิน Google แล้ว · ช่วงวันและรายการนัดต้องตรงเฉลยทุกรายการ
- **เกณฑ์ผ่าน (จากการ์ด 0014 หัวข้อ 8 ข้อ 2):** **20/20** · แต่ละข้อผ่านเมื่อ ดึงสำเร็จ · ขาด 0 · เกิน 0 · บรรทัดที่อ่านไม่ออก 0
- **ชุดวัด:** `tests/data/gcal_eval/calendar.ics` (19 นัด · 22 VEVENT) + `set.json` (นัดในเครื่อง 5 · คำถาม 20 ข้อ)
  - เขียนโดยผู้ช่วยอีกตัว (subagent) ที่**ไม่ได้เปิดโค้ดหรือเทสต์ของโปรเจกต์** · คำนวณเฉลยด้วยมือตามกติกาที่ผู้ช่วยหลักเขียนให้ (ช่วงสำเนา −1/+60 วัน ·
    นัดคาบเกี่ยวช่วงวันนับ 1 ครั้งต่อคำถาม · นัดถัดไป = ยังไม่เริ่ม / ทั้งวันที่ยังไม่จบ · ไม่เกิน 10 รายการ · เขตเวลา Asia/Bangkok)
  - ครอบ: EXDATE · ย้ายเวลา/ย้ายวันเฉพาะครั้ง (RECURRENCE-ID) · ยกเลิกเฉพาะครั้ง · ยกเลิกทั้งนัด · ทั้งวันหลายวัน · เขตเวลานิวยอร์ก/ลอนดอนที่เปลี่ยนวันที่ ·
    UTC ที่เปลี่ยนวันที่ · นัดข้ามเที่ยงคืน · วันเกิดรายปี · รายเดือน · รายวันแบบ COUNT · รายสัปดาห์แบบ UNTIL · นัดยาว 0 นาที · ขอบสัปดาห์ (ถามวันอาทิตย์/จันทร์) · คำตอบว่าง
