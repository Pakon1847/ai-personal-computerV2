## ข้อที่ Zipformer ประโยคเต็ม ×5 พลาดบน V4 (รันครั้งเดียว · บันทึกตามจริง)

| พูด | ได้ยิน | ผล |
|---|---|---|
| เปิดลิงก์ที่สี่ | เปิดลิงก์ที่สาม | **เปิดผิดลิงก์** (ผิดจริง · ย้อนกลับได้) |
| ค้นหาร้านซ่อมรถใกล้ๆ | ค้นหาร้านซ่อมรถใกล้ค้นหาร้านซ่อมรถใกล้ | ค้นด้วยคำซ้ำ 2 รอบ |
| ค้นหาตารางบอลคืนนี้ | ค้นหาตารังบอนคืนนี้ | คำค้นเพี้ยน |
| ค้นหาวิธีลดน้ำหนักให้หน่อย | …น้ํา… (นิคหิต + สระอา แทนสระอำ) | คำค้นตัวอักษรต่าง (ความหมายถูก) |
| ปิดแท็บ | แปลก | ไม่ทำ (ไปแชท) |

แก้ได้ 2 จุด (รวม "ํา" → "ำ" · ตัดประโยคที่พูดซ้ำทั้งประโยค) **แต่พบจากชุดทดสอบ** → ไม่รัน V4 ซ้ำเพื่ออ้างผลดีขึ้น · ยืนยันกับเสียงคน (D แล้ว H)
