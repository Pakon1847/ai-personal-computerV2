## สาเหตุจากค่าดิบ

1. **K2/K3:** AI ในเครื่องเลือก "ตอบเอง" แทนเรียกสกิลความรู้ (22/27) · สกิลความรู้ได้ก็ต่อเมื่อ AI เลือกเครื่องมือเอง หรือคำสำคัญตรงเป๊ะ · เมื่อไปถึงสกิล ตอบถูก 4/4
2. **K7 + เรื่องที่เจอเพิ่ม (สำคัญ):** แอปที่**ไม่มี**สกิลของผู้ใช้ ถึงคำแรกมัธยฐาน 1.5 วิ · แอปที่มีสกิลความรู้ 9 ตัว ~37 วิ **ทุกข้อความ** (รวมข้อที่ตอบเอง) ·
   สาเหตุที่คาด: รายการสกิลที่ส่งให้ AI เลือก 5 สกิลของผู้ใช้ตามข้อความ (การ์ด 0018) → ส่วนต้นของ prompt เปลี่ยนทุกข้อความ → แคชใช้ไม่ได้ → อ่าน prompt ใหม่ทั้งหมด ·
   **น่าจะเกิดกับเครื่องจริงที่มีสกิลของผู้ใช้อยู่แล้ว (Pakon มี 3 ตัว)** · ยังไม่ได้ยืนยันในแอปจริง
3. **K8:** ป้ายหัวข้อตรงกัน ≥ 2 คำหลวมเกิน: `dog-bite-first-aid` ~ `snake-bite-first-aid` · `thai-id-first-digit` ~ `lost-thai-id-card` · `blood-type-o-donation` ~ `blood-donation-preparation` ·
   ส่วนความคล้ายตัวอักษรอย่างเดียวจับเรื่องเดียวกันได้แค่ 1/10 (ชุด test ใช้คำพ้องความหมาย)
