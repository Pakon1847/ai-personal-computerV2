## สิ่งที่เจอระหว่างทำ

- **Google ขอยืนยันว่าไม่ใช่บอตทุกครั้ง** จากเน็ตฮอตสปอตมือถือ (IP 1.47.x · CGNAT) ทั้งตอนเปิดแบบมีหน้าต่างและพิมพ์ในช่องค้นหาเอง →
  ระบบค้นด้วย Bing แทนและพูดบอก · **ทางผลค้นหาของ Google (ตัวเลือกลิงก์) ยังไม่เคยทดสอบกับหน้าจริง** · วันสอบถ้าใช้เน็ตอื่นอาจได้ Google
- Chromium บน Pi เปิดแบบ X11 เองแล้วปิดทันทีถ้าไม่มี `$DISPLAY` → ใส่ `--ozone-platform=wayland` เมื่อมี `WAYLAND_DISPLAY`
- `os.pipe()` ได้เลข fd 3/4 เอง → คำสั่งปิด fd ต้นทางไปปิด pipe ของ Chromium → ไม่ปิด
- ย้อนกลับใช้เวลา 12 วิ: หน้าเดิมกลับมาจากแคชของ Chromium พร้อมเครื่องหมายเก่า → ใช้เลขใหม่ทุกครั้ง → ~1 วิ
- เบราว์เซอร์ของผู้ช่วยใช้**โปรไฟล์แยก** (Chromium ไม่ยอมให้คุมโปรไฟล์หลัก) → ล็อกอิน Gmail ฯลฯ ต้องทำในเบราว์เซอร์นี้อีกครั้ง
- คำค้นที่ส่งไป Google/Bing จดในหน้า "สิ่งที่ส่งออกนอกเครื่อง" (ชนิดใหม่ "ค้นเว็บด้วยเสียง")
