## สิ่งที่วัด

- **เครื่อง:** Pi 5 8GB · แอปจริงจากสาขา `feature/0085-dislike-review` (ติดตั้งเมื่อ Pakon อนุมัติ · กฎเหล็กข้อ 2) · AI ในเครื่อง Gemma 4 E2B ค่าเดียวกับแอป
- **Claude:** `claude -p` (sonnet) ในบัญชีของ Pakon · บัญชี Pro (ใช้โควตา · **ถามก่อนรัน**) · 1 ครั้งต่อการกดไม่ชอบ
- **วิธีรัน (คำแนะนำ · Pakon ตัดสินวันรัน):** Pakon พิมพ์เองที่หน้าจอ ต่อข้อ: พิมพ์คำสั่ง → ดูผล → กด "ไม่ชอบ" → รอการ์ดผลการตรวจ → พิมพ์คำสั่งเดิมอีกครั้ง → ดูผล →
  กรอกใบตรวจ · ผู้ช่วย AI อ่านสมุดบัญชีคลาวด์ (`~/.local/share/aipc/outbound.json`) ก่อน/หลังแต่ละข้อ · เหตุผลที่ไม่เขียนตัววัดอัตโนมัติ:
  "ดีขึ้นไหม" ต้องให้คนตัดสินอยู่แล้ว และการกดปุ่มจริงทดสอบหน้าจอไปพร้อมกัน

## วิธีนับ (ต่อข้อ · นิยามก่อนรัน)

| ค่า | นิยาม |
|---|---|
| `outcome` | การ์ดผลการตรวจ: แก้สกิล / สร้างสกิลใหม่ / ไม่ต้องแก้ / ไม่สำเร็จ (จดข้อความบนการ์ด) |
| `better` | Pakon ตัดสินในใบตรวจ: ผลครั้งที่สองดีกว่าครั้งแรก (ใช่ / ไม่) · "ไม่ต้องแก้" แล้วผลเท่าเดิม = ไม่ |
| `again_ledger_added` | รายการในสมุดบัญชีคลาวด์ที่เพิ่มระหว่างสั่งซ้ำ · ต้อง 0 |
| `wrong_action` | คำสั่งเครื่องที่ทำโดยไม่มีการ์ดยืนยัน ในข้อนั้น (นับจากหน้าจอ + การ์ด) |
| D4 ผ่านข้อนี้ | `better` = ใช่ **และ** `again_ledger_added` = 0 |
