# ตัดเสียงทุ้ม (high-pass) ก่อนถอดเสียง ช่วยกันเสียงรอบข้างไหม · 2026-10-01

ที่มา: Pakon เสนอ "ให้เก็บเบสน้อย เพื่อไม่ให้เสียงรอบข้างเข้าไมค์แล้วทำให้คำเพี้ยน" ·
เสียงรบกวนในบ้านส่วนใหญ่เป็นความถี่ต่ำ (พัดลม แอร์ ไฟหึ่ง 50 Hz รถ) · เสียงพื้นฐานของเสียงพูดอยู่ราว 85–255 Hz → ตัดสูงเกินจะเสียเสียงพูด

## ประกาศก่อนวัด (H9)

- ประโยค: คำสั่งภาษาไทยล้วน 44 ประโยคจาก `tests/data/command_sentences_heldout.json` (มีเฉลย action/params) · เสียงสังเคราะห์ Piper
- เสียงรบกวน (สังเคราะห์ · SNR 5 dB): `brown` (ทุ้ม แบบแอร์/พัดลม/รถ) · `hum` (50 Hz + ฮาร์มอนิก แบบไฟหึ่ง) · `pink` (กว้างทุกความถี่) · และ `clean`
- ตัวกรอง (ffmpeg): `none` · `hp100` · `hp200` · `hp300` (highpass ตัดต่ำกว่า … Hz) · `afftdn` (ตัวลดเสียงรบกวนของ ffmpeg)
- ถอด: Thonburian distill-small f16 `-ac 512` (รุ่นที่ผ่านความเร็ว · [ผล](../2026-10-01-voice-small/README.md))
- วัด: **คำสั่งถูก** (ตัวแปลคำสั่ง `aipc.skills.command` ได้ action/params ตรงเฉลย · นับรวมที่ถามก่อน) · **ทำผิดโดยไม่ถาม** (อันตราย) · CER เทียบข้อความต้นฉบับ
- **เกณฑ์รับตัวกรองเข้าแอป:** คำสั่งถูกใน brown+hum รวมดีกว่า `none` · และ clean/pink แย่ลงไม่เกิน 1 ประโยค (จาก 44) · ทำผิดโดยไม่ถามไม่เพิ่ม
- ข้อจำกัด: เสียงพูดและเสียงรบกวนเป็นของสังเคราะห์ · ต้องยืนยันด้วยไมค์จริง
