## 2. บังคับรูปแบบด้วย grammar อย่างเดียว (whisper-cli `--grammar`)

| พูด (เสียงสังเคราะห์) | ถอดอิสระ | บังคับรูปแบบ |
|---|---|---|
| เข้าลิงก์แรก | เข้าหลิงแรก | เข้า ลิงก์แรก ✓ |
| กลับไปแอป | กลับไปแอค | กลับ ไป แอพ ✓ |
| โหลดใหม่อีกที | โรสใหม่อีกที | โหลดใหม่อีกที ✓ |
| เปิดยูทูบ | เปิดยูทูก | เปิดยูทูบ ✓ |
| ปิดแท็บ | ไปด้วย ไปด้วย | ไป ลิ้งค์ ✗ |
| ตอนนี้กี่โมงแล้ว (ไม่ใช่คำสั่ง) | ตอนนี้ขี่โมงแล้ว | **ปิดแท ✗ (บังคับประโยคอื่นให้เป็นคำสั่ง)** |

→ grammar อย่างเดียวใช้ไม่ได้ · ต้องเทียบคะแนนกับการถอดอิสระ (หัวข้อ 3)

## 3. ให้คะแนนคำสั่ง (`tools/whisper-score` · ฟังครั้งเดียว)

ตัวช่วย C++ บน whisper.cpp 1.9.4: ถอดอิสระ 1 ครั้ง แล้วให้คะแนน (log ความน่าจะเป็นทั้งประโยค + จบประโยค) ของประโยคที่เป็นไปได้ โดยใช้ผลเข้ารหัสเสียงชุดเดิม ·
เจอระหว่างทำ: (1) whisper.cpp ถอดเพี้ยนเมื่อเปลี่ยนขนาดหน้าต่างเสียงบน state เดิม → แยก state ตามขนาด (สร้าง 8 ms) ·
(2) `whisper_decode` คืนค่าเฉพาะคำสุดท้าย → แก้ 1 บรรทัดใน whisper.cpp ให้คืนทุกคำ (คำนวณอยู่แล้ว แค่ไม่คัดลอก) → ให้คะแนน 1 ประโยค ~25 ms แทน ~14 ms × จำนวนคำ ·
(3) ตัดกลางตัวอักษรไทยได้ → ตัดไบต์ไม่ครบทิ้ง

ตัวอย่าง (คะแนนยิ่งใกล้ 0 ยิ่งตรงกับเสียง):

| เสียง | ถอดอิสระ | คำสั่งที่ถูก | คำสั่งอื่นที่ดีที่สุด |
|---|---|---|---|
| เข้าลิงก์แรก | «เข้าหลิงแรก» −1.0 | −14.9 | −35.1 |
| ตอนนี้กี่โมงแล้ว (ไม่ใช่คำสั่ง) | «ตอนนี้ขี่โมงแล้ว» −1.3 | (ข้อความจริง −2.3) | −36.6 |
| ปิดแท็บ (Piper) | «ไปเรื่อยล่ะ» −7.3 | −25.8 | «ไปด้วย» −4.6 → เสียงสังเคราะห์คำนี้ไม่ชัดจริง |

(ผลทั้งชุดเติมหลังรันเสร็จ)
