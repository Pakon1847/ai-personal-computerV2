## พบแต่ไม่ได้แก้ (ให้ Pakon ตัดสิน หรือเป็นข้อจำกัด)

- **ความร้อน:** ระหว่างรัน AI ต่อเนื่อง อุณหภูมิขึ้นถึง 83°C (พัดลม ~6,600 rpm) · `get_throttled=0xe0000` = เคยถูกลดความเร็วเพราะร้อน (ไม่เคยไฟตก) · ตรงกับ T11 (82.9°C) · ตรวจว่าฮีตซิงก์แนบชิปและช่องลมเคสไม่ถูกบัง
- **บัญชีค้างในเครื่อง:** `t12a` `t12b` (ทดสอบ T12) และ `pakon2` (ชื่อที่แสดง "pakon") ยังอยู่ · บัญชีหลัก `pakon` แสดงชื่อ "pakon1" → หน้า Login วันสอบจะมี 4 ชื่อ และชื่อ "pakon" ไม่ใช่บัญชีหลัก · ลบได้ด้วย `sudo userdel -r` (ผู้ช่วยไม่ลบเอง) · `t12a` ใช้แทน `deltest` ในเกณฑ์ลบบัญชีข้อ 4 ได้
- สั่งที่ระบบไม่รองรับ AI ตอบว่าทำไม่ได้ (ตรงตามจริง): "เปิดเฟซบุ๊ก" (มีแค่ 5 เว็บ) · "ปิดเครื่อง" · "รีสตาร์ท" · "ล็อกหน้าจอ" · "open the browser" (กฎสั่งงานเป็นภาษาไทย)
- AI ในเครื่องถามกลับแทนที่จะทำ: "แนะนำเมนูอาหารเย็นง่ายๆ" · "ช่วยคิดชื่อร้านกาแฟ 5 ชื่อ" · "ช่วยเขียนอีเมลขอบคุณลูกค้า" · "เขียนกลอนเรื่องฝน" (ชุดพัฒนา 9/16 ข้อถามกลับ · แก้ด้วย prompt ไม่ได้ · การ์ด 0023)
- ตอบผิดแบบมั่นใจ: "ใครเป็นนายกคนแรกของไทย" → ตอบรัชกาลที่ 1 (ข้อจำกัดเดิมของการ์ด 0022) · **"Raspberry Pi คืออะไร" → "ใช้ไมโครคอนโทรลเลอร์" (ผิด · ตอบแบบนี้ 2/2 ครั้ง)** = เรื่องของตัวระบบเอง กรรมการถามได้ · แก้ได้ด้วยการเพิ่มข้อเท็จจริงใน ABOUT ของ system prompt แต่ต้องวัดชุดสอบซ้ำ (แบบการ์ด 0023) → ให้ Pakon ตัดสิน
- "ข้อมูลของฉันถูกส่งออกไปไหนบ้าง" → AI ไม่รู้ว่ามีหน้า "สิ่งที่ส่งออกนอกเครื่อง" (ABOUT ใน system prompt ไม่มีเรื่องนี้ · แก้ได้แต่เปลี่ยน prompt ที่ใช้วัดชุดสอบ)
- ค้นไฟล์คืนไฟล์คะแนนต่ำมาก (0.03) ด้วยเมื่อมีไฟล์น้อย (ไฟล์ที่ถูกยังอยู่อันดับ 1)
- AI ในเครื่องตอบยาวจนช้า: คำถามทั่วไป 60–100 วิ (ร้อน 83°C ระหว่างนั้น) · ปรับความยาวคำตอบ = เปลี่ยนค่าที่ใช้วัดชุดสอบ จึงไม่แก้เอง
- "เตือนส่งการบ้านวันจันทร์" (ไม่บอกเวลา) AI ในเครื่องถามกลับแทนเลือกสกิลนัด · "เตือนให้ดื่มน้ำทุกชั่วโมง" ยังจดไม่ได้ (บอกตรง ๆ)
- เลื่อนนัดเองยังไม่ได้ (บอกวิธียกเลิกแล้วจดใหม่)
