# ค้นไฟล์ในเครื่องด้วยเนื้อหา · 2026-10-01

ผู้ใช้พิมพ์ "ใบเสร็จร้านซ่อมแอร์อยู่ไหน" แล้วได้ไฟล์ที่ตรงพร้อมข้อความตัวอย่าง · ทำงานในเครื่องทั้งหมด ไม่ใช้โมเดล (Pi เร็ว · ไม่แย่ง RAM AI)

## ประกาศก่อนเขียนตัวค้น (H9)

- **ข้อมูล:** Claude (claude -p sonnet) เขียนเอกสาร 30 ไฟล์ + คำค้น 60 ข้อ (ส่วนใหญ่พูดอ้อม ไม่คัดลอกคำจากไฟล์) ·
  สุ่มแบ่ง (seed 20261001) → ชุดพัฒนา `tests/data/file_search_dev.json` 20 ข้อ (ผู้ช่วยดูได้) ·
  ชุดอิสระ `tests/data/file_search_heldout.json` 40 ข้อ (ผู้ช่วยไม่ได้เปิดอ่านคำค้น · เอกสารชุดเดียวกัน)
- **เกณฑ์ชุดอิสระ (วัดครั้งเดียว):** ไฟล์ที่ถูกอยู่ใน 3 อันดับแรก ≥ 85% · อันดับแรก ≥ 70%
- **ความเร็ว (Pi 5):** ค้น 1 ครั้งในไฟล์ 30 ไฟล์ ≤ 0.5 วิ (สร้างดัชนีครั้งแรกรายงานแยก)
- เทียบกับแบบง่าย (นับคำที่ตรง) เพื่อดูว่าตัวค้นช่วยจริง
