### ที่ต้องเขียนในเล่ม

- **ไฮบริดแก้คำตอบผิดได้จริง 2 ข้อ:** A08 แม่น้ำที่ยาวที่สุด (ในเครื่อง: เจ้าพระยา · Claude: มูล พร้อมบอกว่าแต่ละแหล่งนับต่างกัน) ·
  C06 อีกกี่วันถึงปีใหม่ (ในเครื่อง: 175 วัน **ผิด** · Claude: 88 วัน ถูก) — ทั้งสองข้อในเครื่องติดป้าย "ให้คนตรวจ" อยู่แล้ว ·
  **เพิ่ม 2026-10-07:** A08 ยังไม่แน่ — วิกิพีเดียไทยว่าแม่น้ำชียาวที่สุด (~765 กม.) และความยาวที่ Claude ให้ (มูล 750 · ปิง 740) ไม่ตรงวิกิพีเดีย (640 · 658) → รอ Pakon ตรวจ ([factcheck](review/factcheck.md))
- **คำถามข้อมูลสด 12/12 ถูกส่งต่อ** แต่ Claude ไม่ได้ได้ข้อมูลสดทุกข้อ (เช่น B10 หุ้น PTT วันนี้: "ยังยืนยันไม่ได้") → คนตรวจต้องดูว่าตอบได้จริงกี่ข้อ
- **การเลือกสกิลถอย 1 ข้อเมื่อมีเครื่องมือ ask-cloud:** E08 "เขียนอีเมลขอเลื่อนวันส่งรายงาน" ในเครื่องล้วนไป letter-writer · ไฮบริด AI ถามรายละเอียดกลับเอง
- ในเครื่องล้วนดีขึ้นจากรอบ 30 ก.ย. (89 → 93 · สกิล 19 → 23) หลังแก้ prompt รุ่น 3 · ยังมีคำตอบผิดที่ตัวตรวจอัตโนมัติให้ผ่าน
  (A20 "Raspberry Pi … ใช้ไมโครคอนโทรลเลอร์") → ตัวเลข "ผ่านอัตโนมัติ" คือขอบบน ต้องมีคนสุ่มตรวจตามหัวไฟล์ `exam.py`
- เทียบงานที่เกี่ยวข้อง: ระบบเราส่งต่อ 16% ของคำถามโดยไม่มีตัวเลือกที่ฝึก (โมเดลเล็กตัดสินเองผ่าน tool call + กฎ "ตอบว่าไม่รู้") ·
  FrugalGPT / Hybrid LLM ใช้ตัวเลือกที่ฝึกจากข้อมูล → วัดเทียบตรง ๆ ไม่ได้ (ชุดข้อมูลต่างกัน) เขียนเป็นแนวคิดเดียวกัน ไม่ใช่ตัวเลขเทียบ
