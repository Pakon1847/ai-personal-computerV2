- **ชุดวัดผล:** ชุด 58 เดิม (`tests/data/skill_selection.json`) · **ไม่เปิดดูผลรายข้อระหว่างปรับ** · วัดครั้งเดียวหลังปรับเสร็จ
  (รันซ้ำอีกรอบเพื่อดูความแกว่งจาก temperature 0.6 · ตัดสินจากรอบแรก)

  `TOOL_RULE` / `TOOLS_HINT` · **ห้ามแก้:** ชุด 58 · โมเดล · ค่า sampling · วิธีวัด (`--mode ai-first` เหมือนเดิม)

- ไม่ผ่าน = คืนคำอธิบายเดิมหรือเก็บไว้ตามผล และรายงานตามจริง
