## ลองความเป็นไปได้ก่อนประกาศ (ไม่ใช่ผล · ใช้เลือกวิธีเท่านั้น)

2026-10-07 07:3x · Pi 5 · systemd 257 (257.13-1~deb13u1) · บัญชีผู้ดูแล aipc2030 ทาง SSH (ไม่มีใครเข้าระบบที่หน้าจอ) ·
`systemd-run --user --wait --pipe -p <ค่า> python3 <สคริปต์ลองเปิด socket + ต่อ 1.1.1.1:443>`:

| ค่า | ผล |
|---|---|
| ไม่จำกัด | เปิดได้ทุกชนิด · ต่อออกได้ |
| `RestrictAddressFamilies=AF_UNIX` | AF_INET · AF_INET6 · UDP · AF_NETLINK = `EAFNOSUPPORT` · AF_UNIX ได้ |
| `PrivateNetwork=yes` | เปิด socket ได้แต่ต่อออก = `ENETUNREACH` |
| `IPAddressDeny=any` | **ไม่มีผลใน user service** (ต่อออกได้) → ห้ามใช้ห้ามอ้าง |

## เปลี่ยนอะไร

`scripts/pi/session/aipc-llm.service` เพิ่ม 2 ชั้น:

1. `RestrictAddressFamilies=AF_UNIX` — ชั้นหลัก (seccomp ของเคอร์เนล: สร้าง socket เครือข่ายไม่ได้เลย)
2. `PrivateNetwork=yes` — ชั้นที่สอง (network namespace ที่มีแค่ loopback) · **ใส่เฉพาะถ้าเกณฑ์ข้อ 2–3 ผ่านเมื่อเปิดทั้งสองชั้น** ·
   ไม่ผ่าน = ใช้ชั้นหลักอย่างเดียว (ตัดสินตามเกณฑ์ ไม่ใช่ตามความเร็ว)

ติดตั้งด้วย `install-llm.sh --apply` (คัด unit ไป `/etc/systemd/user/`) · มีผลกับเซสชันที่เริ่มหลังติดตั้ง
