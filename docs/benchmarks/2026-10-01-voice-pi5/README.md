# ความเร็วเสียงไทยบน Pi 5 (การ์ด 0019 ข้อ 6) · 2026-10-01 08:30–09:05

เครื่อง: Pi 5 8GB หลัง T11 จบ (มี AI ของ pakon1 เปิดค้าง) · `scripts/pi/measure-voice.sh` ·
STT = whisper.cpp v1.9.4 + `thonburian-medium-q5_0.bin` (539 MB · 4 thread) · TTS = piper-tts 1.8.0 + `th_TH-tsync2-medium`
เสียงทดสอบ = เสียงสังเคราะห์จาก Piper 10 ประโยคคำสั่ง → **อ้างได้แค่ความเร็ว** (ข้อความที่ถอดได้อยู่ใน `speed.json` ไว้ดูเท่านั้น)

| เกณฑ์ (ประกาศก่อนวัด) | ผล | |
|---|---|---|
| ถอดเสียงประโยค ~2–3 วิ ≤ 5 วิ | ค่าเริ่มต้น **34.9 วิ** (RTF 18) · `-ac 512` **11–14 วิ** · `-ac 256` 5–7 วิ แต่เพี้ยนอันตราย | ✕ |
| อ่านออกเสียง 1 ประโยค ≤ 2 วิ | เปิดโปรแกรมใหม่ทุกครั้ง 6.3 วิ · **โหลดค้างไว้ 0.4–0.8 วิ** (ประโยคแรก 3.8 วิ) | ✓ ถ้าเปิดค้าง |

รายละเอียด STT (ประโยค "เปิดยูทูบ"): โหลดโมเดล 0.2 วิ · **encoder 29.5 วิ** (Whisper ประมวลหน้าต่าง 30 วิเสมอ) · decode < 2 วิ →
เปิดค้างไว้ไม่ช่วย · `-ac` (ตัดหน้าต่าง) เร็วขึ้นแต่ `-ac 256` ได้ **"ปิด ยูทูป"** จาก "เปิดยูทูบ" (ความหมายกลับ) และพูดซ้ำ 6 รอบในอีกประโยค

ปัญหาติดตั้งที่เจอ (ต้นทุนจริง):
- Piper ไบนารี 2023.11.14-2 อ่านเสียง tsync2 ไม่ได้ ("Phonemes must be one codepoint") → ต้องใช้ piper-tts จาก pip
- ตัวแปลงหน่วยเสียงไทยของ piper-tts ใช้ `tltk` ซึ่งระบุ scikit-learn~=1.2 (build บน Python 3.13 ไม่ได้) → ติดตั้งแบบ --no-deps
  แล้วเติม nltk scikit-learn pandas sklearn_crfsuite requests gensim unicode_rbnf เอง

**ข้อเสนอ:** ทำ "อ่านคำตอบออกเสียง" ได้ (เปิดตัวอ่านค้างไว้ในเซสชัน) · "สั่งด้วยเสียง" ด้วย Thonburian medium บน CPU ของ Pi 5 ช้าเกิน
→ ต้องลองโมเดลเล็กกว่าที่ฝึกภาษาไทย (ยังไม่มีไฟล์ ggml สำเร็จรูป ต้องแปลงเอง + วัดความแม่นด้วยเสียงคนจริง) หรือไม่ทำในรุ่นนี้
