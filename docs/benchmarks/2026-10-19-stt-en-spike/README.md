# การ์ด 0040 ระยะ D1 · เลือกตัวถอดเสียงภาษาอังกฤษบน Pi 5 (spike) · **สถานะ: ประกาศก่อนรัน**

- **คำถาม:** whisper.cpp ภาษาอังกฤษล้วนตัวไหนเร็วพอบน Pi 5 · และแม่นพอสำหรับคำสั่ง (เทียบกับตอนพิมพ์ประโยคเดียวกัน)
- **โมเดล (ไลเซนส์ MIT ทั้งโค้ดและน้ำหนัก · ตรวจ README ของ openai/whisper + HF `ggerganov/whisper.cpp` 2026-10-19 · ตรวจ sha256 ตอนดาวน์โหลด):**
  `ggml-tiny.en.bin` (77.7 MB) · `ggml-base.en.bin` (148.0 MB) · `ggml-small.en-q5_1.bin` (190.1 MB) · ดาวน์โหลดไว้ที่ `~/voice-bench/en-stt/` (ไม่แตะ `/opt` จนกว่าเลือกแล้ว)
- **เสียงทดสอบ:** เสียงสังเคราะห์ `en_US-ljspeech-medium` อ่าน 75 ประโยคของชุด C1 รอบ 1 (ชุดพัฒนาแล้ว) แปลงเป็น 16 kHz ·
  **ข้อจำกัด:** เสียงสังเคราะห์ชัดกว่าคนจริง (ไม่มีสำเนียง/เสียงรบกวน) → ตัวเลขความแม่น = เพดาน ใช้เลือกโมเดลเท่านั้น · ความแม่นจริงวัดใน D2 ด้วยเสียง Pakon
- **ตัววัด:** `aipc/spikes/stt_en_spike.py` · ธง whisper เดียวกับตัวถอดไทยของแอป (`-t 4 -nt -ac 512`) · เวลา = ทั้งโปรเซส (รวมโหลดโมเดล เหมือนในแอป)
- **กติกาเลือก (ประกาศก่อนรัน · การ์ด 0040 หัวข้อ 8 D1):** โมเดล**เล็กสุด**ที่มัธยฐานเวลาถอด **≤ 2.5 วิ** และคำสั่งที่ช่องข้อมูลตรงกับตอนพิมพ์ **≥ 90%** และไม่ใช่คำสั่งถูกแปลง **0** ·
  ไม่มีตัวไหนผ่าน = รายงาน Pakon (ไม่ปรับธง/ชุดแล้ววัดซ้ำเอง)
- **รันครั้งเดียว** บน Pi 5 · บันทึกอุณหภูมิ/throttled ก่อน-หลัง
