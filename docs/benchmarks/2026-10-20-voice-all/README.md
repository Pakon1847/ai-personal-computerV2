**ที่ผิดในชุดทดสอบ (เขียนตรง ๆ):** คำสั่ง 5 ข้อไม่รู้จัก ("พักวิดีโอไว้" · "หยุดเพลงแป๊บนึง" · "ไปหน้าถัดไปของเว็บ" · "เลื่อนขึ้นไปบนสุด") และ 1 ข้อผิดทาง ("ร่างอีเมลขอลางานพรุ่งนี้" → ตั้งเตือน) ·
**ไม่ใช่คำสั่ง 2/20 ได้การ์ดถามตั้งเตือน** ("วันนี้อากาศร้อนมาก" · "เต็มที่เลยวันนี้") = ไม่ได้ทำอะไรเอง (ต้องตอบ "ใช่" ก่อน) จึงไม่นับใน V2 แต่เป็นการถามที่ไม่ควรเกิด ·
**สาเหตุ:** กฎตั้งเตือนรับ "ประโยคที่บอกวัน/เวลา" อย่างเดียวได้ (ไม่ต้องมีคำของสกิลนัด) · คำลงท้าย "ไว้" "แป๊บนึง" และ "บนสุด/ล่างสุด" "หน้าถัดไปของเว็บ" ยังไม่อยู่ในกฎ

V3 ระหว่างพัฒนา (ก่อนวัดชุดทดสอบ) จับปัญหาได้ 1 เรื่อง: "เลื่อนนัด…/ลบนัด…" ไปทางตั้งเตือนใหม่ → แก้แล้ว (เลื่อน/ลบ/ยกเลิก = แก้นัดเดิม · โค้ดตอบเดิมทำก่อน)
