## เกณฑ์ (การ์ด 0036 หัวข้อ 8 ข้อ 2)

- ค้นถูกบริการ**และ**คำค้นถูก **≥ 18/20** · ค้นผิดบริการ **0** · ประโยคใกล้เคียงไม่เข้า **10/10**
- วิธีเทียบ (อยู่ในตัวรันที่ commit ก่อนมีชุดวัด): คำค้นเทียบแบบ**ไม่สนช่องว่างและตัวพิมพ์เล็ก/ใหญ่** (ตัวแปลรวมคำไทยที่เว้นวรรคและแปลงเป็นตัวเล็ก ·
