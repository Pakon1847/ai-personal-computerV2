**ไม่ผ่านเกณฑ์หัวข้อ 8 ข้อ 1 และ 2** · ชุดพัฒนา 91% → H2 49%

### ทำไมตกมาก: คอขวดคือตัวแปลแบบกฎ ไม่ใช่ตัวถอดเสียง

- ต่อให้ถอดถูกทุกตัวอักษร ตัวแปลทำถูกแค่ 47/80 · ตัวถอดเสียงทำให้พลาดเพิ่มแค่ ~9 ข้อ (ส่วนใหญ่คำค้นเพี้ยน)
- H2 เขียนโดยผู้ช่วยอีกตัวด้วยสำนวนหลากหลาย (ขอ… · รบกวน… · ลอง…ดู · …ได้ไหม · …ที · ในเน็ต · ไปที่… · เข้ากูเกิล · สกรอลล์ · หน้าต่อไป · หน้าเมื่อกี้ · อันที่สองขอดูหน่อย) ·
  ชุดพัฒนาเขียนโดยผู้ช่วยหลักด้วยสำนวนแคบแบบเดียวกับกฎ → **ผลชุดพัฒนาสูงเกินจริง** (นี่คือเหตุผลที่ต้องมีชุดทดสอบอิสระ)
- ไม่ใช่คำสั่งแต่ทำ 2 ข้อมาจากกฎ "หา…": «หาแว่นตาไม่เจอเลย วางไว้ไหนนะ» · «หาเพื่อนคุยหน่อย เหงาจัง» → ค้นเว็บ
- Typhoon ไม่ได้ช่วยมาก (สองขั้นดีกว่า Zipformer เดี่ยว +2 แต่ไม่ใช่คำสั่งแต่ทำ +1)

ข้อที่ผู้ช่วยหลักเห็นในรายงานของผู้เขียน H2 ก่อนรัน (h2-074 · h2-073 · h2-080 · "ค้นกูเกิลเรื่อง…" · ยูทูบเบอร์/กูเกิลเป็นบริษัท…) — ตัวแปลไม่ได้ถูกแก้ให้ตรงข้อเหล่านี้ (ทั้ง 3 ข้อแรกยัง miss)
