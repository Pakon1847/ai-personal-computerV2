# เริ่มเรียนออนไลน์

พิมพ์ว่า "เริ่มเรียนออนไลน์" แล้วเครื่องจะเปิดเบราว์เซอร์ เปิด Google และตั้งเสียงไว้ที่ระดับพอดี (40) พร้อมเข้าเรียน

## ขั้นตอน
1. เปิดแอป เบราว์เซอร์
2. เปิดเว็บ google
3. ปรับเสียง 40
4. บอก: เปิดเบราว์เซอร์และตั้งเสียงให้พร้อมเรียนแล้ว
