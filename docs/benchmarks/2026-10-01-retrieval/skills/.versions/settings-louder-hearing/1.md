# ตั้งค่าและเพิ่มเสียงเมื่อหูไม่ค่อยได้ยิน

เปิดหน้าตั้งค่าของแอป แล้วเพิ่มเสียงเครื่องให้ดังขึ้นในครั้งเดียว สำหรับคนที่หูไม่ค่อยได้ยิน

## ขั้นตอน
1. เปิดหน้า ตั้งค่า
2. เพิ่มเสียง 20
3. บอก: เปิดหน้าตั้งค่าและเพิ่มเสียงให้แล้วค่ะ ถ้ายังเบาไปบอกให้เพิ่มอีกได้
