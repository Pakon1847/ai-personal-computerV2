# เช็กที่เก็บข้อมูลเต็มหรือยัง

เปิดหน้าสุขภาพเครื่องให้ดูค่าที่เก็บข้อมูล แล้วเปิดตัวจัดการไฟล์ต่อเพื่อดูว่าไฟล์อะไรกินที่

## ขั้นตอน
1. เปิดหน้า สุขภาพเครื่อง
2. เปิดแอป ตัวจัดการไฟล์
3. บอก: เปิดให้แล้ว ดูค่าที่เก็บข้อมูลในหน้าสุขภาพเครื่อง และดูไฟล์ในตัวจัดการไฟล์ได้เลย
