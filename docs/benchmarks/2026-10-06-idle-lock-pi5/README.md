## 3. ปัญหาที่พบ (ไม่ใช่ของขั้น A แต่เจอระหว่างทดสอบ · รอ Pakon ตัดสิน)

1. **เข้าด้วยใบหน้า = keyring ล็อก:** PAM ของ greetd ให้ใบหน้าผ่านก่อน (`success=done`) จึงไม่ถึง `pam_gnome_keyring` ที่ใช้รหัสผ่านปลด ·
   Chromium (เก็บคุกกี้/รหัสผ่านเว็บผ่าน keyring) ถามรหัสผ่านตอนเปิดครั้งแรก · **หน้าต่างถามรหัสไปอยู่ด้านหลัง** → ผู้ใช้ทั่วไปติด
   ทางเลือก: (ก) คงไว้ (ด่านที่สองของบัญชีเว็บเมื่อกล้องถูกหลอก) + ทำให้หน้าต่างขึ้นหน้าสุด + บอกผู้ใช้ · (ข) Chromium `--password-store=basic` (ไม่ถาม · คุกกี้อ่านได้ถ้าถอด microSD)
2. **กู้รหัสด้วย PIN (คาดการณ์ · ยังไม่ได้ลอง):** chpasswd เปลี่ยนรหัส แต่ keyring ยังล็อกด้วยรหัสเก่า → ต้องล้าง keyring ตอนกู้คืน
3. **ข้อสังเกต:** `gnome-keyring-daemon` ของ pakon1 รันต่อเนื่องตั้งแต่ 23:30 ข้ามการออก/เข้า 2 ครั้ง (เข้าใหม่ภายใน ~5 วิ) ·
   น่าจะเพราะ user manager ของ systemd รอก่อนปิดหลังออก (ค่าเริ่มต้น UserStopDelaySec · ยังไม่ได้ยืนยันค่าบนเครื่อง) ·
   ไม่ข้ามบัญชี (โปรเซสของ pakon1 เอง) แต่ T4 ควรวัดหลังออกเกิน 10 วิ
