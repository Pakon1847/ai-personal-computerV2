# สมุดประชุมในเครื่อง · S1 ถอดเสียงไทยยาว (ประกาศก่อนวัด 2026-11-08 · **ยังไม่ได้วัด**)

การ์ด: [0082](../../design/0082-meeting-notes.md) หัวข้อ 8 · ผล S1 ตัดสินว่าจะสร้างฟีเจอร์ต่อหรือหยุด

## วิธีวัด

เครื่องมือ: `python -m aipc.spikes.meeting_s1` (เทสต์ `tests/test_meeting_s1.py`) · ค่าเดียวกับเสียงกดค้างของแอป (Thonburian distill-small · `-t 4 -nt -ac 512`) ·
ตัดเป็นท่อน ≤ 30 วิที่ช่วงเงียบ · Pi 5 · ไมค์ตัวที่ใช้จริง · **ห้าม commit เสียงของคน** (กฎเหล็กข้อ 4)

| ชุด | อะไร | เฉลย |
|---|---|---|
| A | อ่านออกเสียงตาม [`script-a.txt`](script-a.txt) ≥ 20 นาที | ตัวบทเอง · ที่มา: วิกิพีเดียภาษาไทย (กรุงเทพมหานคร แม่น้ำเจ้าพระยา อาหารไทย ประเทศไทย) สัญญาอนุญาต CC BY-SA 4.0 · เลือกเฉพาะประโยคที่ไม่มีตัวเลขและอักษรโรมัน |
| B | พูดธรรมชาติ ≥ 10 นาที | คนพิมพ์บทถอดด้วยมือ |

ระยะห่างจากไมค์ ≤ 1 เมตรเป็นค่าหลัก · รายงานระยะ 3 เมตรแยกต่างหาก ไม่ใช้ตัดสิน

## คำสั่ง (บน Pi ในเซสชันที่หน้าจอ · ต้องมี PipeWire ของผู้ใช้)

```bash
pw-record --rate 16000 --channels 1 --format s16 ~/s1-a.wav     # กด Ctrl+C เมื่ออ่านจบ
cd ~/aipc-0082 && PYTHONPATH=src ~/aipc/.venv/bin/python -m aipc.spikes.meeting_s1 run --audio ~/s1-a.wav --ref docs/benchmarks/2026-11-08-meeting-s1/script-a.txt --label A-1m --out ~/s1-a.json
```
