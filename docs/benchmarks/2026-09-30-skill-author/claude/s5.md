# จัดไฟล์

เปิดหน้าไฟล์ของฉันในระบบ แล้วเปิดตัวจัดการไฟล์ให้ด้วย เพื่อให้คุณจัดไฟล์ได้เอง สกิลนี้ไม่แตะต้องไฟล์ใด ๆ

## ขั้นตอน
1. เปิดหน้า ไฟล์ของฉัน
2. เปิดแอป ตัวจัดการไฟล์
3. บอก: เปิดไฟล์ของฉันและตัวจัดการไฟล์ให้แล้ว ลากไฟล์เข้าโฟลเดอร์เพื่อจัดได้เลย
