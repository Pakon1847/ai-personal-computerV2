# Audit: โปรเจกต์นี้ดีที่สุดสำหรับ Pi 5 8GB แล้วหรือยัง (2026-09-29/30)

- **คำถาม (Pakon):** ดูทุกด้านว่าดีที่สุดสำหรับ Pi 5 8GB แล้วหรือยัง ควรแก้ตรงไหน · ทุกข้อต้องมีการทดสอบจริงและหลักฐานจริง · ไม่มีหลักฐาน = ส่งให้ทดสอบเองบน Pi 5
- **วิธี:** ตรวจ 9 ด้าน + ช่องว่าง (19 agent อ่านโค้ด/ผลวัด) → ตรวจแย้งทุกข้อ (ไม่มีข้อไหนถูกหักล้าง) → 98 ข้อ ·
  วัดเพิ่มบน Pi 5 จริงทาง SSH ในคืนเดียวกัน · ชุดทดสอบที่เหลือ: [runbook ทดสอบบน Pi 5](../runbooks/pi5-verify.md) (62 ชุด)
- **ระดับหลักฐาน:** ระดับ 4 = วัดบน Pi 5 มีไฟล์ใน `docs/benchmarks` · Pi 4 / PC ไม่ใช่ระดับ 4

## 1. คำตอบสั้น

**ทางหลักถูกแล้ว แต่ยังไม่ "ดีที่สุด" และยังพิสูจน์ไม่ครบ**

- ถูกแล้ว (มีหลักฐาน): Pi 5 8GB + OS 64-bit · โมเดลชั้น 4B (7–8B ช้าเกินใช้) · llama.cpp build บนเครื่อง · Unix socket ต่อผู้ใช้ ·
  สกิล `.md` ที่โค้ดทำตามขั้นตอน · ตัวแปลคำสั่งเครื่องแบบกฎ · Claude สร้างสกิล (`claude -p` ไม่มีเครื่องมือ) · อัปเดตแบบโฟลเดอร์ต่อรุ่น + rollback
- เปลี่ยนแล้วจากการวัดคืนนี้: template ของโมเดล · การเลือกสกิลแบบ AI ก่อน (ข้อ 2)
- ต้องแก้ต่อ: memory cgroup · ความร้อน · เวลาตอบข้อความแรก · image การ์ดสำรอง · ข้ออื่นในข้อ 4
- ยังไม่มีหลักฐานบน Pi 5: T1–T14 ส่วนใหญ่ · GPU · กล้อง · ไฟดับ · ผู้ใช้จริง → runbook

## 6. ต้องให้ Pakon ตัดสิน

1. ADR-007 ข้อ 4 นับ RAM แบบไหน (anon อย่างเดียว หรือรวมไฟล์โมเดล) · ต้องตัดสินก่อนวัดโมเดลอื่น (H9)
2. ADR-007 ข้อ 2: เวลาถึงคำแรก 12.3 วิ ไม่ผ่าน ≤ 10 วิ · รับเกณฑ์ใหม่ หรือหาโมเดล/ตัวเลือกที่เร็วกว่า (runbook: Q4_0 · flash attention)
3. เปิด `cgroup_enable=memory` ในไฟล์บูต (runbook หมวด C · ต้องรีบูต)
4. คำว่า "ไฮบริด" ในเล่มขัดกับข้ออ้างที่ 1 และ T6 (เครื่องไม่ต่อเน็ต) · ต้องเขียนขอบเขตให้ตรงกับที่อาจารย์ขอ
5. จำกัด SSH เมื่อเปิดสมัครเสรี (Pi Connect ของ aipc2030 ปิดแล้ว · ตรวจ 2026-09-30)
