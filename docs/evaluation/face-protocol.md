# แผนทดสอบระบบใบหน้ากับคนจริง (การ์ด 0005 ชั้นที่ 2) — ร่าง รอ Pakon ตรวจ

> ร่างโดยผู้ช่วย 2026-09-24 · **ยังไม่ได้อนุมัติ** · ต้องใช้ Pi 5 + กล้องที่จะใช้จริง · เกณฑ์มาจากตาราง BRIEF 5.1

## 1. อะไรที่วัด (เกณฑ์ประกาศก่อนวัด · ตาราง BRIEF)

| ตัวชี้วัด | เกณฑ์ | จำนวนขั้นต่ำ |
|---|---|---|
| เวลาระบุตัว (เริ่มสแกน → ได้ผล) | median ≤ 1.5 วิ · p95 ≤ 3 วิ | ≥ 50 ครั้ง × ≥ 5 คน |
| FRR เจ้าของถูกปฏิเสธ (แสงห้องปกติ) | ≤ 5% | 5 คน × 50 ครั้ง = 250 |
| FRR แยกสภาพ: สว่าง / สลัว / ย้อนแสง / ใส่แว่น | รายงานแยก (ไม่มีเกณฑ์ผ่าน) | ≥ 20 ครั้งต่อคนต่อสภาพ |
| จับคู่ผิดคน (ในกลุ่มที่ลงทะเบียน) | 0 จาก N (รายงาน N) | ทุกคนสแกนเทียบแม่แบบทุกคน |
| APCER: รูปพิมพ์ / รูปบนจอ / วิดีโอบนจอ | ต้องกรอกเกณฑ์ก่อนวัด (BRIEF เว้นไว้) | ≥ 60 ครั้งต่อประเภท |
| BPCER คนจริงถูกปัดว่าปลอม | ≤ 5% | ใช้ชุดเดียวกับ FRR |
| ถอดกล้องระหว่างสแกน | ไม่ค้าง แสดงทางรหัสผ่านใน 3 วิ | ≥ 5 ครั้ง |

**ต้องตัดสินก่อนวัด:** เกณฑ์ APCER (เสนอ ≤ 10% ต่อประเภท สำหรับโหมดส่วนตัว — กล้อง RGB + PAD แบบ passive กันได้แค่การโจมตีง่าย)

## 2. ขั้นตอน (ต่อคน ~20 นาที)

1. อ่านและเซ็นหนังสือยินยอม (ข้อ 4) · ให้รหัสผู้เข้าร่วม P01–P05 (ไม่ใช้ชื่อจริงในผล)
2. ลงทะเบียน: `python -m aipc.vision.camera enroll` · แสงห้องปกติ · บันทึกว่าต้องลองกี่ครั้ง
3. สแกนเจ้าของ: `python -m aipc.vision.camera scan --times 50` · ลุกออกแล้วกลับมาทุก 10 ครั้ง (ไม่ใช่นั่งนิ่งตลอด)
4. สภาพแสง: สลัว (ปิดไฟหลัก) / ย้อนแสง (หน้าต่างหลังผู้ทดสอบ) / ใส่แว่น (ถ้ามี) · สภาพละ 20 ครั้ง
5. สแกนข้ามคน: ผู้ทดสอบแต่ละคนสแกนเทียบแม่แบบของทุกคนในกลุ่ม (1:N)
6. การปลอม (ผู้ทดสอบ 1–2 คนที่ยินยอมเรื่องนี้เฉพาะ): รูปพิมพ์ A4 · รูปบนมือถือ · วิดีโอบนมือถือ · ประเภทละ 60 ครั้ง
7. ถอดกล้องระหว่างสแกน 5 ครั้ง

ทุกครั้งบันทึกอัตโนมัติใน `face-scans.log` (เวลา ผล คะแนน เหตุผล เวลาต่อขั้น · **ไม่มีภาพ**) · ผู้วัดจดสภาพแสง/รอบลงตาราง

## 3. ข้อมูลที่เก็บ และการลบ

| ข้อมูล | เก็บ? | ลบเมื่อ |
|---|---|---|
| ภาพจากกล้อง | **ไม่เก็บ** (ระบบไม่บันทึกภาพ) | — |
| แม่แบบใบหน้า (ตัวเลข 128 ค่า) | ระหว่างทดสอบเท่านั้น | ทันทีหลังคนนั้นทดสอบเสร็จ (`camera delete`) · ตรวจว่าไม่มีไฟล์เหลือ |
| log คะแนน + รหัสผู้เข้าร่วม | ใช้เขียนผลในเล่ม | หลังสอบปากเปล่าผ่าน หรือไม่เกิน 31 ธ.ค. 2026 |
| หนังสือยินยอม (กระดาษ) | ผู้วิจัยเก็บ | ตามระเบียบมหาวิทยาลัย |

ถ้าจำเป็นต้องมีภาพสำหรับการปลอม (รูปพิมพ์/วิดีโอ) → ใช้ภาพที่ผู้เข้าร่วมให้เอง ลบทั้งไฟล์และกระดาษหลังทดสอบวันเดียวกัน

> 2. **เก็บอะไร:** ระบบ**ไม่บันทึกภาพหรือวิดีโอ** · เก็บตัวเลข 128 ค่าที่สรุปจากใบหน้า (แม่แบบ) ระหว่างทดสอบเท่านั้น และบันทึกผลแต่ละครั้ง (ผ่าน/ไม่ผ่าน คะแนน เวลา) ภายใต้รหัส ไม่ใช้ชื่อ
