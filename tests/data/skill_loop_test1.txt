# - คำสั่ง = ประโยคที่จะพิมพ์สั่งเครื่องจริง ๆ (เขียนแบบที่พูดกับคนปกติ)

# - ทุกข้อต้องเป็นงานที่เครื่อง "ยังทำไม่เป็น" (Pakon ตัดสิน 2026-11-18) เช่น งานสั่งเครื่องหลายขั้นที่อยากให้จำไว้ใช้ซ้ำ
#   ("โหมด…" "เตรียมเครื่องสำหรับ…" = เปิดเว็บ/แอป + ปรับเสียง + ตั้งเตือน ฯลฯ รวมกันในคำสั่งเดียว)
# - ไม่ใส่งานที่เครื่องทำได้อยู่แล้ว: งานภาษาที่ AI ในเครื่องตอบเองได้ (สรุป แปล เขียน แต่งแคปชัน …)
#   และคำสั่งที่มีอยู่แล้ว (เปิด YouTube · ตั้งเตือนธรรมดา · ปรับเสียงอย่างเดียว) เพราะระบบจะไม่สร้างสกิลซึ่งถูกต้องอยู่แล้ว
# - เขียนเสร็จแล้ว ห้ามแก้หลังเห็นผลของระบบ · บรรทัดที่ขึ้นต้นด้วย # คือคำอธิบาย ระบบไม่อ่าน
