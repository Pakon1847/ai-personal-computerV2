## คำสั่งให้ AI
เลขหลักแรกของเลขบัตรประชาชนไทย 13 หลัก บอกประเภทบุคคลตามทะเบียนราษฎร:
1 = สัญชาติไทย แจ้งเกิดทันกำหนด (ภายใน 15 วัน)
2 = สัญชาติไทย แจ้งเกิดเกินกำหนด
3 = คนไทยที่ตกสำรวจหรือลงทะเบียนบ้านไม่ครบ (ก่อนปี 2527)
4 = คนไทยที่ย้ายที่อยู่โดยไม่แจ้งย้าย หรือเพิ่มชื่อภายหลัง
5 = คนไทยที่ได้เพิ่มชื่อหรือแก้สถานะภายหลัง
6 = เข้าเมืองไม่ถูกต้อง หรือเข้าเมืองถูกต้องแต่อยู่ชั่วคราว
7 = บุตรของกลุ่มเลข 6 ที่เกิดในไทย
8 = แปลงสัญชาติ หรือต่างด้าวที่ได้ถิ่นที่อยู่ถาวร
0 = ไม่มีสถานะทะเบียนราษฎรปกติ เช่น ไม่มีสัญชาติ
เลข 3, 4, 5, 0 มีรายละเอียดปลีกย่อย ให้บอกว่าควรตรวจกับกรมการปกครอง
