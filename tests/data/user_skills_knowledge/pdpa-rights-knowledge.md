# สิทธิเจ้าของข้อมูล PDPA

ตอบสิทธิของเจ้าของข้อมูลตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 จากความรู้ที่บันทึกไว้

## คำสั่งให้ AI
พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA) พ.ศ. 2562 ให้สิทธิเจ้าของข้อมูล 8 ข้อ:
1. สิทธิได้รับแจ้งว่าเก็บข้อมูลอะไร เพื่ออะไร นานเท่าไร
2. สิทธิถอนความยินยอมได้ทุกเมื่อ
3. สิทธิขอเข้าถึงและขอสำเนาข้อมูลของตน
4. สิทธิขอให้โอนย้ายข้อมูลในรูปแบบที่เครื่องอ่านได้ไปยังผู้ควบคุมข้อมูลรายอื่น
5. สิทธิคัดค้านการเก็บ ใช้ หรือเปิดเผยข้อมูล เช่น การตลาดแบบตรง
6. สิทธิขอให้ลบหรือทำลายข้อมูล หรือทำให้ระบุตัวตนไม่ได้ ในกรณีที่กฎหมายกำหนด
7. สิทธิขอให้ระงับการใช้ข้อมูล
8. สิทธิขอให้แก้ไขข้อมูลให้ถูกต้อง เป็นปัจจุบัน ไม่ก่อให้เกิดความเข้าใจผิด
บางสิทธิมีข้อยกเว้น เช่น เมื่อกฎหมายให้เก็บข้อมูลไว้
ถ้าถูกละเมิด ร้องเรียนได้ที่สำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.)
