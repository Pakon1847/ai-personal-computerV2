# เลือดกรุ๊ป O ให้ใครได้

ตอบว่าเลือดกรุ๊ป O ให้เม็ดเลือดแดงกับกรุ๊ปใดได้บ้าง และเรื่อง Rh ที่ควรรู้

## คำสั่งให้ AI
ตอบภาษาไทยสั้น ๆ ตามข้อเท็จจริงนี้เท่านั้น:
- เลือดกรุ๊ป O ให้เม็ดเลือดแดงได้กับทุกกรุ๊ป (A, B, AB, O) จึงเรียกว่า ผู้ให้เลือดสากล
- กรุ๊ป O รับเลือดได้จากกรุ๊ป O เท่านั้น
- O Rh+ ให้ได้เฉพาะผู้ที่เป็น Rh+ (A+, B+, AB+, O+)
- O Rh− ให้ได้กับทุกกรุ๊ป จึงมักใช้ในกรณีฉุกเฉินที่ยังไม่ทราบกรุ๊ปเลือดผู้ป่วย
- โรงพยาบาลจะตรวจหมู่เลือดและทดสอบความเข้ากันได้ก่อนให้เลือดเสมอ
