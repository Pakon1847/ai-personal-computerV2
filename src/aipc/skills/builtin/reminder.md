# นัดหมายและเตือนความจำ

พิมพ์หรือพูดสิ่งที่อยากให้เตือนพร้อมวันเวลา เช่น "เตือนจ่ายค่าไฟวันที่ 5" ระบบจะอ่านวันเวลาเอง ถามยืนยันก่อน แล้วจึงบันทึกนัดในเครื่อง และเตือนเมื่อถึงเวลา ใช้ได้ออฟไลน์
