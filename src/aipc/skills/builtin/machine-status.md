# ตรวจอาการเครื่อง

บอกอาการ เช่น ช้า ค้าง ร้อน หรือถามค่าของเครื่อง ระบบจะอ่านค่าจริงจากเครื่อง แล้วบอกว่าเป็นอะไรเป็นภาษาง่าย ๆ พร้อมวิธีแก้ทีละข้อ

สิ่งที่ตรวจ: อุณหภูมิ · แรม · พื้นที่เก็บข้อมูล · ไฟเลี้ยง/ไฟตก · พัดลม · เครือข่าย

สกิลนี้อ่านค่าอย่างเดียว ไม่เปลี่ยนการตั้งค่าและไม่ลบไฟล์ให้เอง
