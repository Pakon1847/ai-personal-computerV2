## คำสั่ง
- <คำพูด> | <คำพูดแบบอื่น> → กดคีย์ <คีย์ลัดของเว็บ เช่น j · Shift+N · ArrowRight · Space>
- <คำพูด> → คลิก <ตัวเลือก CSS ของปุ่ม เช่น button[aria-label="Like"]>
- <คำสั่งที่ย้อนไม่ได้/แตะบัญชี เช่น ยกเลิกสมัคร ลบ ส่ง โพสต์ ซื้อ> → คลิก <ตัวเลือก> · ยืนยันก่อน
- <คำพูดที่หมายถึงงานของตัวเบราว์เซอร์หรือคำสั่งที่ระบบมีอยู่แล้ว> → ทำคำสั่ง <ประโยคคำสั่งของระบบ>

- ใช้คีย์ลัดที่เว็บมีจริงก่อน (ทนกว่าเพราะเว็บไม่ค่อยเปลี่ยน) · คลิกเฉพาะเมื่อไม่มีคีย์ลัด · ตัวเลือกต้องเป็นปุ่มที่มีจริงและเฉพาะเจาะจง
- คีย์ได้: ตัวอักษร ตัวเลข ArrowUp ArrowDown ArrowLeft ArrowRight Space Enter Escape Tab PageUp PageDown Home End
  , . / ; ' [ ] = - < > ? · นำหน้าด้วย Shift+ Ctrl+ Alt+ ได้ · ห้ามคีย์ของตัวเบราว์เซอร์ (ปิดแท็บ เปิดหน้าต่างใหม่ ฯลฯ)
- ห้ามพิมพ์ข้อความ ห้ามตัวเลือกช่องรหัสผ่าน/ชำระเงิน · คำพูดภาษาไทยที่คนพูดจริง สั้น ไม่เกิน 40 ตัวอักษร
- เว็บที่ใช้ได้: เว็บในรายการยกเว้น gmail calendar drive docs (ยังไม่รับสกิลประจำเว็บของบัญชี Google)
- เพิ่มคำสั่งในสกิลเดิม = เขียนไฟล์ทั้งไฟล์ใหม่ คงคำสั่งเดิมไว้ครบ แล้วเพิ่มคำสั่งใหม่
- "ทำคำสั่ง" = คำพ้องของคำสั่งที่ระบบทำได้อยู่แล้ว · ใช้เมื่อเป็นงานของตัวเบราว์เซอร์ (แท็บใหม่ ปิดแท็บ ย้อนกลับ)
  หรือเมื่อคำพูดหมายถึงคำสั่งของระบบ · ประโยคปลายทางเลือกจากรายการนี้เท่านั้น (เปลี่ยนได้แค่ชื่อเว็บและเลข):
  เปิดยูทูบ · เปิดยูทูบอีกแท็บ · ปิดแท็บ · ย้อนกลับ · เดินหน้า · รีเฟรช · เลื่อนลง · เลื่อนขึ้น · หยุดคลิป · เล่นต่อ ·
  คลิปถัดไป · คลิปก่อนหน้า · เต็มจอ · ข้ามโฆษณา · เปิดคลิปแรก · เปิดลิงก์ที่ 2 · กลับไปหน้าผู้ช่วย ·
  ต่อกัน 2 ข้อด้วย "แล้ว" ได้ (เช่น หยุดคลิปแล้วเลื่อนลง) · ห้ามค้นหา ห้ามปิดทุกแท็บ ห้ามเข้าสู่ระบบ
- คำพูดที่ระบบรู้จักอยู่แล้ว (เช่น หยุด หยุดคลิป เล่นต่อ คลิปถัดไป เต็มจอ ย้อนกลับ เลื่อนลง ข้ามโฆษณา ปิดแท็บ
  เพิ่ม/ลด/ปิด/เปิดเสียง) ระบบทำเองก่อนเสมอ · ไม่ต้องใส่คำพูดพวกนั้นซ้ำ · แต่คำพูดอื่นที่ผู้ใช้ขอและหมายถึงคำสั่งพวกนี้
  ให้ใส่ด้วย → ทำคำสั่ง <ประโยคของระบบ>

## กติกา

- ขั้นตอนเขียนได้เฉพาะ: $steps · ขั้นตอนที่สั่งเครื่องต้องมี permissions: run_actions ·
  ขั้น "บอกนัด…" (โค้ดอ่านนัดของผู้ใช้ในเครื่อง · คุณไม่เห็นนัด) ต้องมี permissions: read_agenda · ใช้ได้ 1 ครั้ง
- เว็บในรายการ: $sites · แอปที่มี: $apps · หน้าในระบบ: $pages
- สิทธิ์ที่ขอได้: $perms · ขอเท่าที่จำเป็น
- สกิลงานภาษา: worker: llm · needs: llm · คำสั่งให้ AI ≤ 1,200 ตัวอักษร สั้นที่สุดที่ทำงานได้ · สั่งให้ตอบภาษาไทย
  และห้ามแต่งข้อมูลที่ไม่มีในข้อความของผู้ใช้
- ห้ามอ้างว่าใช้กับทุกเรื่อง · id และคำสำคัญห้ามซ้ำหรือชนกับสกิลที่มีอยู่ (ระบบเทียบคำแบบ "มีอยู่ในประโยค")
- ประโยคที่บอกวันหรือเวลา (วันนี้ พรุ่งนี้ 9 โมง ฯลฯ) และไม่ใช่คำถาม ระบบส่งไปสกิลนัดหมายก่อนเสมอ อย่าพึ่งคำพวกนี้
